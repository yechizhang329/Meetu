# 小红书内容数据驱动检查清单

## 核心原则

**爆款不是艺术品，是工业品。** 算法看不懂内容好坏，只看数据——封面点击率、阅读时长、点赞、评论、收藏、转发。每条帖子的每个元素都必须针对至少一个数据指标做优化。

## 觅遇社内容红线（在检查清单之前先过）

- **不是产品介绍帖**：不走"平台是什么→能干什么→来试试"的套路。功能可以一个字都不提
- **不夸大不编造**：不编造故事、数据、包含项。"后台私信炸了""一晚认识7个新朋友"这类违规
- **不用"搭子"**：全平台去"搭子"，用自然语言替代，不给关系贴标签
- **品牌灰度70-80%**：有态度同龄人语气，偏有趣/自由，酷=敢说话

## 帖子产出检查清单（发布前必过）

### 一、吸引力（封面+标题+开头）— 决定生死

算法逻辑：给了曝光，点击率低=浪费流量=不再推

| # | 检查项 | 通过标准 |
|---|--------|---------|
| A1 | 封面0.5秒可识别 | 用户在信息流里滑过时，0.5秒能看懂封面在说什么 |
| A2 | 标题给确定感 | 直接给结论，不铺垫。"我有答案"而非"来看看吧" |
| A3 | 第一句=全文最有价值的一句 | 把最颠覆认知、最值钱的结论放在开头 |
| A4 | 标题≤20字符 | 硬性限制 |
| A5 | 封面文字大且醒目 | 在信息流缩略图中清晰可读 |

**标题公式参考：**
- 结论前置型：`大学交朋友最大的误区 不是你社恐`
- 数字清单型：`武汉大学生周末去处 8个不踩雷的`
- 身份锚定型：`华科/武大/理工的 这条只有你们看得懂`
- 反常识型：`认识的人越多 越孤独 大学社交的真相`

### 二、互动性（点赞+评论+收藏+转发）— 决定推流力度

算法逻辑：用户不互动=平台是死水。转发=帮平台免费拉新，最有价值

| # | 检查项 | 通过标准 | 对应指标 |
|---|--------|---------|---------|
| B1 | 至少1句金句 | 短小有力，用户点赞的理由（替用户说/反常识/态度宣言） | 点赞 |
| B2 | 结尾有互动问题 | 具体的评论钩子（投票/征集/争议/共情） | 评论 |
| B3 | 收藏价值 | 有清单/合集/地图/指南/信息密度大到记不住（如不适用可跳过） | 收藏 |
| B4 | 至少1个破绽/争议点 | 故意留的不完美，让人想纠正或讨论 | 评论 |
| B5 | 自评已设计好 | 置顶评论带节奏/补充信息/降低评论门槛 | 评论 |
| B6 | 身份标签感 | 内容让特定群体觉得"这代表我"（转发理由） | 转发 |

**金句设计公式：**
- 替用户说：`微信3000人 周末能约出来的还是那三个`
- 反常识：`不是你社恐 是大学根本没给你认识人的机会`
- 态度宣言：`我们一条营销帖都不会写 也请不起博主`

**评论钩子公式：**
- 投票型：`A还是B？评论区站队`
- 征集型：`评论你的学校+推荐一个地方`
- 争议型：`室友≠朋友 你同意吗`
- 共情型：`有跟我一样的吗`

### 三、停留（价值密度）— 最有价值也最难

算法逻辑：用户多停留一分钟=平台多赚一份钱

| # | 检查项 | 通过标准 |
|---|--------|---------|
| C1 | 无冗余句子 | 删除了所有可有可无的句子 |
| C2 | 每段有新信息/新情绪 | 没有重复表达、没有注水 |
| C3 | 正文≤1000字符 | 长度匹配内容密度，不为了长而长 |

### 四、合规（平台规则+觅遇社红线）

| # | 检查项 | 通过标准 |
|---|--------|---------|
| D1 | 无引流敏感词 | 无"搜索""下载""链接"+app名 |
| D2 | 无推广关键词 | 无"产品上线""新品发布""功能介绍" |
| D3 | 无站外引导 | 无"微信""小程序"等（引导走评论区/私信） |
| D4 | app名≤2次 | 且以自我介绍形式出现，非推广 |
| D5 | 标签无地域限制 | 如需要触达全国用户 |
| D6 | 无禁用词 | 无"搭子""拼团""觅途"等已标记禁用词 |
| D7 | 非产品介绍帖 | 骨子里不是在走"平台是什么→能干什么→来看看" |
| D8 | 无夸大/编造 | 无虚假数据、编造故事、不真诚表述 |
| D9 | Lucy敏感词审核 | 经过Lucy筛一遍平台关键词 |

## 检查清单输出格式

对每条帖子审核时，按以下格式输出：

```
【数据驱动检查】<帖子标题>

吸引力：
- [x] A1 封面0.5秒可识别
- [x] A2 标题给确定感：<说明为什么>
- [ ] A3 第一句非最有价值 → 建议：<具体修改>
- [x] A4 标题字符数：<N>/20
- [x] A5 封面文字醒目

互动性：
- [x] B1 金句："<引用金句>"

- [x] C1 无冗余
```

## 数据复盘模板（发布24小时后）

| 指标 | 数据 | 行业基准 | 判断 |
|------|------|---------|------|
| 曝光（小眼睛） | | 新号>300 | |
| 封面点击率 | | >5% | |
| 点赞率 | | >3% | |
| 评论数 | | | |
| 收藏率 | | >2% | |
| 转发数 | | | |
| 新增粉丝 | | | |

**诊断路径：**
- 曝光低+点击率低 → 封面/标题问题 → 下条优化A1-A5
- 曝光OK+互动低 → 没触发情绪 → 下条优化B1-B6
- 互动OK+停留低 → 有废话 → 下条优化C1-C3
- 全部OK → 复制这条模式

## 使用场景

1. **写完文案后自查**：Lucy写完后按清单逐项过
2. **PM审核把关**：Fiona对Lucy提交的文案做检查清单review
3. **优化已有帖子**：对存量内容按清单诊断并改进
4. **发布前最终门禁**：不过清单不发布
