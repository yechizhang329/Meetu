# Meetu Logo Concept D1 v1

> 方向：**M 主 icon + Meetu 定制字标**  
> 用途：给 `#设计讨论Design / #产品讨论Product` 快速评审第一推荐方向  
> 当前阶段：概念稿，不是最终定稿

---

## 1. 方案一句话

把 `M` 做成一个更像**召集信号 / 场域入口 / 正在发生的事情**的主 icon，而不是“两个元素连接”的可爱图解；再用更有时代感的 `Meetu` 定制字标，把品牌从“幼态陪伴”拉到“会玩、有判断、有号召力”。

---

## 2. 为什么是 D1

这个方向最符合当前已经确认的三件事：

1. **App icon 需要短而硬的主符号**
- 小程序 icon 在 64x64 甚至更小的尺寸下，角色型 logo 会丢细节。
- `M` 作为单字符主 icon，更稳、更容易一眼认出。

2. **品牌语气已经升级**
- 现在要传达的是：**有趣、自由、时尚、多元、酷**
- 还要有：**自信、有态度、有号召力**
- 所以 logo 不能再主打“陪伴感”，而要主打“这里有好玩的事在发生”。

3. **传播需要双系统**
- icon 负责缩小时的识别
- wordmark 负责海报、banner、H5、封面的传播感

---

## 3. D1 的设计逻辑

### 3.1 `M` 主 icon

`M` 不是在画“连接”，而是在画：
- 一个正在发出信号的入口
- 一个有态度的聚场
- 一个会让人想点进去的年轻平台

具体结构：
- 两根外侧粗笔画：像舞台灯牌/标识立柱，稳定、够硬
- 中间内折：形成记忆点，不走普通几何 `M`
- 中部橙色短横：不是连接说明，而是一个“就是这里”的高亮焦点

### 3.2 `Meetu` 字标

字标不追求花哨，而追求两件事：
- 更现代
- 更有传播力

处理思路：
- 用更紧的字距，让 `Meetu` 更像一个整体品牌名，而不是普通系统字
- 让首字母 `M` 跟 icon 的结构气质一致
- 保持圆角和轻微切角，让它年轻但不幼态

---

## 4. 颜色策略

### 主方案
- Charcoal：`#121317`
- Ivory：`#F6F0E8`
- Signal Orange：`#FF7422`

### 为什么这样配
- 黑 / 奶油 保证高级和稳定
- 橙色不再铺满，而是只做**高能焦点**
- 这更符合“70-80% 传达有趣 / 自由 / 酷，而不是温暖 / 陪伴”的灰度尺

### 可扩展性
- 夜生活 / 前卫场景里，icon 可以切成黑底霓虹点缀版
- 校园 / 说明 / banner 场景里，可以切成奶油底深色字版

---

## 5. 使用场景

### 小程序 icon
- 只用 `M` 主 icon
- 不带 mascot
- 不带长文案
- 缩小后仍要能看出“中部高亮 + 双侧强结构”

### 海报角标
- 用 icon + `Meetu` 字标的组合锁定
- 字标优先横向展开，增强传播感

### 封面水印
- 只用 icon
- 允许低透明度单色使用
- 不依赖复杂颜色，保证压在图上也成立

---

## 6. 跟旧 logo 的核心差异

旧：
- 可爱
- 陪伴
- 幼态
- 焦点分散

新：
- 更短
- 更硬
- 更时尚
- 更有态度
- 更像“会玩的年轻平台”

---

## 7. 当前稿的自检

### 是否符合 DavidC / Jonathan 方向
- 容易辨识：**是**
- 符合大学生偏好：**是**
- 有趣 / 自由 / 时尚 / 多元 / 酷：**基本成立**
- 不低幼：**成立**

### 还不是最终定稿的地方
- `Meetu` 字标目前是结构方向，细节还可继续精修
- `M` 中央高亮的形状，还可以继续试更聪明的切法
- 后续可以再出一个更偏夜生活的深色高对比变体，以及一个更偏校园海报的浅底版

---

## 8. 下一步建议

如果这版方向确认成立，下一步建议出：

1. **D1-v2 精修版**
- 优化 `M` 的中心切角
- 优化字标细节

2. **单色版 / 反白版**
- 验证缩小和压图能力

3. **应用规范页**
- icon
- wordmark
- 最小尺寸
- 安全留白
- 错误示例
