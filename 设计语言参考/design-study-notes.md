# DESIGN.md 学习笔记（第一轮）

## 1. 学习范围

- 参考仓库：本地学习用 `awesome-design-md` 克隆（未作为子仓库入库）
- 当前本地 `DESIGN.md` 数量：58
- 第一轮重点拆读：
  - Airbnb
  - Notion
  - Figma
  - Pinterest
  - Linear
  - Stripe
  - Spotify

这 7 个样本覆盖了 Meetu 目前最需要补的 4 类能力：
- 温暖生活方式感
- 编辑感与留白
- 元素系统与信息包装
- 深色前卫 / 夜生活场景

## 2. 先说结论

Jonathan 指出的三个问题，本质上不是“没加够元素”或者“字体不够多”，而是：

1. **元素没有角色**
- 现在我们的元素经常只是贴上去，起不到导视、分层、打断节奏、制造记忆点的作用。

2. **字体没有形成真正的系统**
- 不是换成两套字体就算完成。真正有效的是 display / body / micro / mono 各司其职，再配合字重、字距、行高和块级留白。

3. **颜色使用太保守**
- 不是品牌主色不对，而是缺少“在哪一块可以突破、为什么突破”的策略。

4. **场景没分型**
- 同一个品牌可以有多种风格子系统。温暖校园、规则说明、夜生活、二次元活动，不应该只靠一套暖橙卡片硬撑。

## 3. 代表产品拆读

### Airbnb

**核心设计理念**
- 温暖、可信、摄影优先，像在翻一本可以直接下单的生活方式杂志。
- UI 自己退后，让内容和场景成为主角。

**可直接借鉴**
- 单一品牌强调色 + 大面积留白，让主内容自己发光。
- 卡片阴影不重，但有层次，显得柔和而不飘。
- 导航 / 分类条适合做成可滑动的胶囊系统，而不是死板表格。
- 大图、圆角、温暖阴影一起用时，会自然产生“可进入”的感觉。

**适合 Meetu 的场景**
- 平台介绍页
- 主理人招募页
- 联系我们页
- 校园生活 / City Walk / 轻活动场景

### Notion

**核心设计理念**
- 极度克制，但不是冷。它的高级感来自留白、边界、字距和排版秩序。
- 视觉不是靠花哨元素，而是靠“内容自己像被编辑过”。

**可直接借鉴**
- 边框可以非常轻，但结构必须清楚。
- 标题和正文的关系，不靠颜色，而靠压缩字距和节奏差。
- 模块之间要像“章节”而不是“卡片堆”。
- 小标签不需要很多，只要在关键节点出现。

**适合 Meetu 的场景**
- 活动收费说明
- 社区规则
- 联系我们里的说明段
- 任何信息密度高但不适合太花的页面

### Figma

**核心设计理念**
- 界面本身保持黑白秩序，颜色交给内容。
- 类型、字重、标签和图形都像工具，不像装饰。

**可直接借鉴**
- mono 小标签可以承担“技术性 / 导视性 / 注释性”角色。
- 不是所有标题都要很重，有时轻一些反而更有设计感。
- 圆形按钮、pill 标签、虚线提示线这些元素，必须像系统，不像贴纸。
- 黑白结构层可以让彩色内容更显得高级。

**适合 Meetu 的场景**
- 主理人工具感 / 发起活动流程
- 图片生成 prompt 文档视觉规范
- 需要强调“系统感”的说明页面

### Pinterest

**核心设计理念**
- 视觉驱动、灵感先行、年轻而不低幼。
- 色彩不是平铺使用，而是让局部内容板块形成情绪峰值。

**可直接借鉴**
- “种草”类场景需要更强的图像板块感，不要只是普通卡片。
- 高饱和色块可以用在兴趣内容上，但必须和大片留白配对。
- 标题不一定居中，不对称会更像内容平台。
- 卡片瀑布感适合灵感展示，不适合规则说明。

**适合 Meetu 的场景**
- 广场置顶帖
- 兴趣活动专题页
- 二次元 / 手作 / 展览 / 种草相关内容页

### Linear

**核心设计理念**
- 高密度信息也可以很优雅，关键是秩序、权重和边界处理。
- 现代感不是靠噪音，而是靠精确。

**可直接借鉴**
- 510/590 这类中间字重的思路值得学习：不是只有 regular/bold 两档。
- 微标签、正文、标题之间要有真正的层次差。
- 暗色系统里，边界和阴影都要极度克制。
- 信息模块可以密，但每一层的职责必须稳定。

**适合 Meetu 的场景**
- 后续如果做产品规则 / 后台说明 / 主理人工具页
- 高信息密度的专题活动页
- 前卫 / 科技感活动场景

### Stripe

**核心设计理念**
- 技术与信任同时成立。高级感来自克制、轻字重和品牌色的精确落点。
- 它不是“安全保守”，而是“精密自信”。

**可直接借鉴**
- 规则页、价格页不一定要无聊，关键在排版和局部强调色。
- 大标题可以很轻，但必须有足够的间距和清晰的内容层次。
- 品牌色不要 everywhere，只在关键动作和关键认知点出现。
- 金融/规则模块更适合“少图 + 强排版 + 少量高质图形”。

**适合 Meetu 的场景**
- 活动收费说明
- 信任机制说明
- 商家合作 / 联系我们
- 需要“靠谱”感的所有模块

### Spotify

**核心设计理念**
- 深色沉浸、内容主导、品牌绿只做功能强调。
- UI 自己尽量退后，让气氛、封面、场景成为主角。

**可直接借鉴**
- 夜生活 / 前卫活动页适合深底强反差，而不是继续暖橙化。
- 彩色内容最好来自主视觉本身，不是页面处处加色。
- pill / circle 的按钮几何很适合做活动氛围。
- 标题和按钮可以更像“演出海报”而不是“说明文档”。

**适合 Meetu 的场景**
- 夜生活活动
- 派对 / 前卫 / 潮流场景
- 需要更强情绪包裹感的专题页

## 4. 可直接借鉴到 Meetu 的具体技法

至少 10 条，这里给 16 条：

1. **元素先定义角色，再决定要不要放。**
- 导视、状态、分层、打断节奏、品牌记忆点，这五种角色至少要先明确一种。

2. **一个页面里 micro-label 不要铺满。**
- 只有真正需要打节奏、做章节提示、做局部对比的地方才保留。

3. **Display / Body / Micro / Mono 四层明确分工。**
- Display 负责情绪
- Body 负责信息
- Micro 负责提示
- Mono 负责系统感 / 注释感

4. **标题大小不是唯一层次工具。**
- 字重、字距、行高、上下留白都要参与建立等级。

5. **不要让所有卡片一样大、一样亮、一样重。**
- 至少有主卡、辅卡、轻卡三层。

6. **颜色要按模块突破，不要整页平均分布。**
- 一个页面里只允许 1-2 个色彩高峰点。

7. **图片不能只是填空。**
- 图像要么是主视觉，要么是证据图，要么是氛围图，不能三者混着来。

8. **规则页优先用排版建立可信感。**
- 图像只是辅助，不是主角。

9. **深色风格只在需要情绪包裹的场景使用。**
- 夜生活、派对、前卫活动适合；
- 平台说明、规则说明不适合整页深色化。

10. **高饱和色只用于兴趣和情绪页面。**
- 二次元、种草、专题活动适合；
- 收费说明、信任说明不适合。

11. **Mono 标签适合技术性、状态性、系统性信息。**
- 不适合大段标题。

12. **贴纸 / 飘带 / 路径线必须成系统出现。**
- 不能一处用、一处不用，导致像临时补丁。

13. **复杂模块在微信 CMS 里优先图片化。**
- 9 宫格、3 图步骤、复杂视觉拼贴，都不该硬靠 HTML/CSS 扛。

14. **卡片里的元素必须服从可读性。**
- 任何装饰都不能压住主信息。

15. **不同活动类型要有不同风格储备。**
- 暖橙校园
- 深色前卫
- 高饱和兴趣
- 编辑感说明

16. **MVP 页面也要有记忆点。**
- 哪怕只有一个贴纸标签、一个标题切法、一个深浅区块，也比通用模板式“整齐”更重要。

## 5. Meetu 当前页面的主要问题对照

### A 主理人招募

当前问题：
- 容易写成普通功能页
- “当主理人很酷”这个感受还不够强

改进方向：
- 借 Airbnb 的温暖招募感 + Figma 的系统标签
- 少解释，多做“主理人气场”包装

### B 平台介绍

当前问题：
- 最容易变成信息堆砌页
- 复杂模块在微信里兼容性差

改进方向：
- 借 Airbnb / Pinterest 的图像主导方式
- 复杂信息块图片化，文本只保留稳定结构

### C 活动收费说明

当前问题：
- 一不小心就会显得太“客服”或太“金融”

改进方向：
- 借 Stripe / Notion
- 轻标题、强排版、少图、多秩序

### D 女生专场

当前问题：
- 容易落入 generic picnic / generic girls poster
- 安全感会被做成模板化温柔

改进方向：
- 不做“普世女性海报”，而要做“低压力、轻松、可信”的专属氛围
- 可借 Pinterest 的生活方式感，但不要 stock-photo 审美

### E 联系我们

当前问题：
- 一开始太中庸，像通用客服页

改进方向：
- 已经开始往 Soul / 小红书式包装感走
- 后续还可以继续强化“真人 / 初创 / 愿意聊”的态度，而不是继续企业化

## 6. Meetu 的风格储备矩阵

### 1. 温暖校园型
- 参考：Airbnb / 部分 Notion
- 适用：平台介绍、主理人招募、联系我们
- 关键词：暖橙、留白、生活方式、可信、轻松

### 2. 编辑说明型
- 参考：Notion / Stripe
- 适用：收费说明、规则说明、FAQ、商家合作
- 关键词：秩序、轻字重、边界清楚、少量强调色

### 3. 前卫夜生活型
- 参考：Spotify / 更暗色的 Linear 取向
- 适用：夜生活、派对、先锋活动、潮流主题页
- 关键词：深色沉浸、强反差、内容发光、少量功能色

### 4. 兴趣高饱和型
- 参考：Pinterest / Figma 的内容色彩逻辑
- 适用：二次元、手作、展览、种草内容页
- 关键词：兴趣驱动、局部高饱和、板块感、年轻

### 5. 系统工具型
- 参考：Figma / Linear
- 适用：主理人工具、流程说明、复杂状态模块
- 关键词：mono、标签、精确、系统感、信息层次

## 7. 下一轮设计执行规则

在继续做 Meetu 页面前，设计侧先执行这 7 条：

1. 先判断页面属于哪一种风格类型，再开始画。
2. 先定义元素角色，再决定元素数量。
3. 先定义字体层级，再开始排模块。
4. 先定义色彩高峰点，再放辅助色。
5. 复杂模块优先判断是否应该图片化。
6. 每页只保留 1 个主记忆点，不要平均发力。
7. 任何页面都要回答一句话：**这页最想让用户先看到什么？**

## 8. 第一轮吸收结果

当前不是“把 58 份 DESIGN.md 看完了”，而是已经形成了可落地判断：

- 元素不能继续“贴上去”
- 字体不能继续“一个思路撑全页”
- 颜色不能继续“只有安全色”
- 风格不能继续“所有页面一个调”

第一轮学习已经足够支持下一阶段工作：
- 如果做 **暖橙校园页**，有 Airbnb / Notion 方向
- 如果做 **规则/收费说明页**，有 Stripe / Notion 方向
- 如果做 **夜生活 / 前卫活动页**，有 Spotify / Linear 方向
- 如果做 **兴趣 / 二次元 / 种草页**，有 Pinterest / Figma 方向
