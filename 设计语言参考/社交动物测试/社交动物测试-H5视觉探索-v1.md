## 1. 设计判断

这不是心理测评工具，也不是活动转化页。它更像一个可以被大学生截图、转发、互相对号入座的 **社交人格梗图 H5**。

所以首版视觉目标不是“权威感”，而是：

1. 结果卡发出去不尴尬；
2. 动物名和一句话能被朋友接话；
3. 视觉有手作感，但不是粗糙；
4. 成人化，不像儿童绘本、萌宠贴纸或心理诊断网站；
5. 前端 3-5 天能落地 P0。

推荐主方向：**桌面便签动物园**。

## 3. 三个 Art Direction 对比

### A. 桌面便签动物园（推荐）

**一句话**：像大学生桌上的便签、贴纸、草稿线和社交观察笔记，被整理成一张好看的结果卡。

**视觉元素**：暖白纸张、黑色手绘线、荧光贴纸、胶带、手写批注、朋友锐评框。

**优点**：传播性强；不像广告；动物和文字都能成为记忆点；前端可用 CSS/SVG 快速落地。

**风险**：如果手作感过头，会变成廉价手账；需要严格控制留白和字体层级。

### B. 群聊截图动物局

**一句话**：像把社交动物测试做成一组群聊梗截图。

**视觉元素**：聊天气泡、消息时间、群昵称、弹幕、表情包式动物。

**优点**：梗感强，适合传播；容易触发“这不就是你”。

**风险**：H5 产品感会弱，容易像单张 meme，不适合承载完整测试流程。

### C. 标本卡动物档案

**一句话**：把每只社交动物做成“社交行为观察档案”。

**视觉元素**：编号、档案卡、印章、标签、观察笔记、分区严谨。

**优点**：系统感强，16 只动物可扩展；适合结果页深度信息。

**风险**：容易偏严肃，传播轻松感不足。

### 结论

P0 推荐用 **A 桌面便签动物园** 做主系统，吸收 B 的“朋友锐评/群聊感”，少量吸收 C 的“编号/标签系统”。

## 4. 首版视觉系统

### 4.1 色彩

| Token | 用途 | 色值 |
|---|---|---|
| `paper` | 主背景纸色 | `#FFF8EA` |
| `paper-deep` | 次背景 | `#F6EBDD` |
| `ink` | 主文字/线稿 | `#1F1F1F` |
| `muted` | 次文字 | `#70685E` |
| `line` | 描边 | `#2B2B2B` |
| `orange` | Meetu 暖橙点睛 | `#FF7A3D` |
| `green` | 荧光贴纸 | `#C8FF5A` |
| `pink` | 轻粉贴纸 | `#FFB7C5` |
| `blue` | 轻蓝贴纸 | `#9DD7FF` |
| `brown` | 桌面/阴影 | `#B7926B` |

原则：入口/答题页克制，结果页释放动物主色；每张结果卡只用 1 个动物主色 + 1 个辅助贴纸色。

### 4.2 字体

- H5 正文字体：系统中文字体，优先 `PingFang SC` / `Noto Sans SC`，不依赖外部字体。
- 标题：粗黑体，字重 800-900，略紧字距。
- 手写感：不使用真实手写字体，改用倾斜贴纸、手绘线、圈选、划线表达，避免中文可读性掉线。

CSS 建议：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
```

### 4.3 组件语言

| 组件 | 视觉描述 | 用途 |
|---|---|---|
| 便签卡 | 暖白底、黑线描边、轻微旋转 | 入口说明/结果模块 |
| 贴纸标签 | 荧光色、圆角胶囊、黑描边 | 关键词/进度/状态 |
| 朋友锐评框 | 像群聊截图的一条吐槽 | 结果卡传播点 |
| 手绘动物 | 黑色简笔线 + 1 个主色块 | 记忆点 |
| 纸胶带 | 半透明米色/粉色横条 | 装饰但不抢信息 |
| 圈选按钮 | 选项像被笔圈住 | 答题交互 |

## 5. 四只动物小样方向

| 动物 | 气质 | 线稿动作 | 主色 | 传播点 |
|---|---|---|---|---|
| 省电猫 | 内向省电、慢热观察 | 蜷着坐，尾巴像电量条 | 深蓝灰 | “不是不社交，是电量需要精打细算” |
| 整活猴 | 外放整活、临场有梗 | 举着香蕉麦克风/表情包 | 明黄 | “空气冷掉前，它先出手” |
| 边界刺猬 | 外刺内软、边界清楚 | 抱着小牌子“先问问” | 棕灰 | “可以靠近，但别突然贴脸” |
| 社交蝴蝶 | 圈层游走、轻松切换 | 带路线虚线飞过几个贴纸 | 紫粉 | “哪都有朋友，但不一定都很深” |

动物画法要避免：大眼萌宠、儿童绘本比例、过度软糯表情。线条可以笨拙一点，但姿态要准。

## 6. 页面小样说明

首版 HTML 样式稿包含：

1. **入口页**：大标题 + 4 个动物贴纸 + 开始按钮，强调“测着玩，但可能有点像”；
2. **答题页**：单题单屏，选项像被笔圈选的纸条；
3. **结果页**：省电猫示例，包含动物、一句话、关键词、常见模式、朋友锐评；
4. **分享卡**：3:4 传播卡结构，优先让结果名、一句话和关键词可截图。

预览文件：`docs/social-animal-test-style-v1/index.html`

## 7. 前端落地建议

1. 插画优先用内联 SVG，按动物结果切换颜色变量；
2. 结果卡和页面组件分开写，方便 `html2canvas` 或 Canvas 导出；
3. P0 先实现 4 只动物线稿 + 16 个动物的文字结果，剩余动物可用统一线稿占位；
4. 动效克制：贴纸轻贴、选项圈选、脚印进度、结果卡弹出即可；
5. 页面宽度按 375/390 优先，分享卡固定 1080×1440 输出比例；
6. 不出现下载/报名/加群 CTA，底部只保留“测着玩，但可能有点像”。

---

## 8. 评审关注点

第一轮请优先看：

1. 是否成人化，不像儿童动物卡；
2. 结果卡是否适合截图传播；
3. 4 只动物是否能靠姿态区分社交气质；
4. 页面是否像完整 H5，而不是单张海报；
5. 梗感是否来自文字和排版，而不是堆 emoji；
6. 前端是否能在 3-5 天内落地静态 P0。
