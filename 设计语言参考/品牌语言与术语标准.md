> 所有对外内容（文案、Banner、H5页面、小红书、广场帖、系统提示等）统一遵守。
> **语言体系权威来源：** Common Sense/品牌共识/语言体系.md

## 2. 语言体系定位

### 营销基调

**我们的客户：** 18-24岁在校大学生。周末想出去玩但找不到人，对陌生社交有点紧张但渴望新鲜感。

**语气人设：** 像朋友圈里那个总在张罗局的人——自信、热情、随和，不是品牌在对消费者喊话。

**基调规则：**
- 像朋友在微信群里说"走不走"，不是广告在教你做事
- 自信但不傲慢——"我们这儿挺好的，你来试试"
- 轻松、直接、带点俏皮——大学生的语感，不是广告公司的语感
- 安全感是前提不是卖点——认证这些事轻轻带过就够，不反复强调
- 鼓励出发，不施加压力也不表现冷淡

**绝对不能出现的语气：**
- 居高临下："没人催你"、"爱来不来"、"不OK就划走"
- 说教式："你应该"、"你需要明白"
- 推开用户：任何让人觉得"这个品牌不在乎我来不来"的表达
- 过度卖惨/求关注："求求了"、"跪求"

### 搭子文化体系

我们不发明搭子文化，我们定义它的产品标准语言——类比得物标准化了"鉴别"这个概念。

**核心原则：**
- 不是所有词都要带"搭"——哪个自然用哪个
- 搭子文化体系是定位，具体词汇服从**自然口语优先**
- 费用不需要单独命名——活动定价就是定价

## 3. 核心术语表

### 搭子文化词汇（产品标准用语）

| 正式术语 | 含义 | 用法示例 | 说明 |
|---------|------|---------|------|
| **搭上** | 报名参加活动 | "搭上了周六密室，¥60" | 核心文化词，替代"报名/拼团" |
| **搭子** | 一起参加活动的伙伴 | "遇到一个超好的搭子" | 已有文化共识，保留 |
| **齐了** | 活动报名人数达到要求 | "齐了！出发" | 自然口语，替代"成团/满员" |
| **带搭** | 推荐 | "这个主理人带搭" | 搭子文化扩展词 |
| **神搭** | 特别好的搭子 | "遇到一个神搭" | 搭子文化扩展词 |
| **到了** | 到场/签到 | 自然语言 | 不造新词 |
| **觅友** | 用户身份 | "觅友们" | 品牌名+友（待最终确认） |

### 保留术语（已有认知，不替换）

| 术语 | 含义 | 备注 |
|-----|------|------|
| 主理人 | 活动的发起者和组织者 | 已有身份感和认知度 |
| 在校认证 | 通过学信网验证在校生身份 | — |
| 实名验证 | 通过实名信息验证真实身份 | — |
| 女生安心模式 | 仅限在校女生参与的活动模式 | 安全场景不玩梗，直白清晰 |
| 广场 | 社区内容板块 | — |
| 觅遇仔 | 品牌 Mascot | — |

### 主理人动作用语

| 动作 | 用语 | 说明 |
|------|------|------|
| 发起活动 | **开一场** / **发起** | 自然口语，不硬塞"搭"。"开搭"已废弃 |
| 发布第一场 | "发布你的第一场活动" | — |
| 定价 | 直接显示价格 | "¥60/人"或"¥0.01/人"，不单独命名费用 |

### 活动付费表述

**核心认知：** 活动费用由主理人定价，¥0.01仅为最低门槛。费用不一定退还。这是正常的活动定价，不是"押金"。

| 场景 | 正确表述 | 错误表述 |
|------|---------|---------|
| 活动价格展示 | "¥60/人""¥0.01/人" | "诚意金¥0.01" |
| 引导付费 | "搭上 ¥60" | "支付诚意金" |
| 低门槛活动 | "¥0.01起" | "免费""0成本" |
| 退款说明 | 按活动具体规则说明 | "到了就退你"（不是所有活动都退费） |

## 5. 品牌语气标准

### 总体定位

**像一个会玩的学长/学姐在跟你说话。**

- 亲切、直接、有态度
- 有一点鼓励感，但不鸡血
- 不端着，但也不低幼
- 不以恋爱/约炮为平台方向，但恋爱作为社交自然动力不刻意回避；禁止夜店化表达

### 分场景语气

| 场景 | 语气特征 | 示例 |
|------|---------|------|
| **品牌介绍** | 温暖、有世界观、内容感 | "一个人也能出发，因为搭子已经在等你了。" |
| **主理人招募** | 热血、身份感、号召力 | "会玩这件事，值得被认真对待。" |
| **活动付费说明** | 清晰、克制、可信 | "主理人定价，真实活动成本，搭上就出发。" |
| **社区/Banner** | 轻松、场景化、有参与感 | "这个周末，找个搭子一起出发。" |

### 语气边界

- **可以用：** "～"（适量）、轻松口语化表达、觅遇仔气泡对话
- **控制使用：** 感叹号（每屏最多1个）、网络梗（只用广泛认知的）
- **禁止：** 过度卖萌、堆叠波浪号/感叹号、暧昧化表达

## 7. 禁用词清单

### 废弃术语（曾用但已废弃）

| 禁用词 | 废弃原因 | 替代为 |
|-------|---------|-------|
| 诚意金 | 不自然，误导为"押金"，大学生不会这么说 | 直接显示活动价格 |
| 拼团 | 通用词，无文化辨识度 | 搭上 |
| 成团 | 同上 | 齐了 |
| 报名 | 同上 | 搭上 |
| 开搭 | 太生硬 | 开一场/发起 |
| 入局金/搭子契 | 金/契太老派 | — |
| 觅了/起觅/一场遇 | "觅"文言感太重 | — |
| 防鸽费 | 负面感强 | — |
| 觅途 | 历史名称 | 觅遇社 |
| 局长 | 旧称谓 | 主理人 |

### 内容导向提示

> 以下不是硬性红线，而是方向性提示——帮助判断内容是否偏离产品调性。

| 建议避免的表达 | 原因 |
|------------|------|
| 拼饭/约饭/火锅/美食/探店 | 产品定位不涉及餐饮 |
| 免费/0成本 | 最低¥0.01，不存在完全免费活动 |
| 到了就退你（作为通用文案） | 不是所有活动都退费，误导付费机制 |
| 约（单独使用） | 容易产生暧昧歧义 |
| 脱单（作为平台卖点引导） | 平台不以脱单/恋爱匹配为方向，但恋爱是社交自然动力，不刻意回避 |
| 最/第一/100%/绝对 | 广告法风险 |
| 保证/承诺 | 涉及服务质量的绝对表述，平台不做担保 |
| 微信号/加V/私聊 | 引流违规风险 |

### 语气导向

| 禁用模式 | 原因 |
|---------|------|
| 过度堆叠"～～～""！！！" | 显得不稳，损害品牌感 |
| 过度网络梗/缩写 | 降低信任感 |
| 约炮暗示/暧昧引导/夜店化措辞 | 偏离产品调性 |
| 小红书网红体（"姐妹们""家人们""宝子们"） | 差异化定位是真实校园感，不是网红感 |

## 8. 觅遇仔使用规范

| 使用场景 | 使用方式 |
|---------|---------|
| 子页/H5页面 | 使用觅遇仔PNG图片，一屏最多1个气泡 |
| Banner | 可作为画面元素，不喧宾夺主 |
| 系统提示 | 搭配提示文案，增加亲和力 |
| 广场帖 | 官方帖可以用觅遇仔口吻说话 |
| 表情包 | 已有6种基础表情，按需扩展 |

**重要：** 觅遇仔不是猫。禁止用🐱emoji代替觅遇仔。觅遇仔是白色身体+棕色面罩+橙色围巾的机器人形象，必须使用实际PNG素材。

**觅遇仔不说的话：** 不用觅遇仔的口吻说规则/法律/安全类硬性内容。
