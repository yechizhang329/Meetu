# 觅遇社品牌语言与术语标准 v0

> 本文档定义觅遇社（Meetu）的品牌语言规范，包括命名、术语、语气、CTA体系和禁用词。
> 所有对外内容（文案、Banner、H5页面、小红书、广场帖、系统提示等）统一遵守。

---

## 1. 品牌命名

| 项目 | 正式名称 | 备注 |
|------|---------|------|
| 中文品牌名 | 觅遇社 | 唯一正式中文名称 |
| 英文品牌名 | Meetu | 统一写法，不用 MEETU / MeetU / meetU |
| Mascot 昵称 | 觅遇仔 | 用于页面引导、气泡对话、表情包等场景 |
| 品牌定位语 | 大学生专属拼团社交平台 | 用于 footer、简介等需要一句话说明的场景 |

**组合使用：** 中英文组合（"觅遇社 Meetu"）按场景判断，暂不做硬性规定。

**历史名称处理：** "觅途"为历史版本，所有新内容中禁止出现。

## 4. 品牌语气标准

### 总体定位

**像一个会玩的学长/学姐在跟你说话。**

- 亲切、直接、有态度
- 有一点鼓励感，但不鸡血
- 不端着，但也不低幼
- 不走恋爱社交、暧昧社交、夜店化表达

### 分场景语气

| 场景 | 语气特征 | 示例 |
|------|---------|------|
| **品牌介绍** | 温暖、有世界观、内容感 | "一个人也能出发，因为搭子已经在等你了。" |
| **主理人招募** | 热血、身份感、号召力 | "会玩这件事，值得被认真对待。" |
| **规则/安全说明** | 清晰、克制、可信 | "一点小小的诚意，换来每一个人的到场。" |
| **社区/Banner/活动宣传** | 轻松、场景化、有参与感 | "这个周末，找个搭子一起出发。" |

### 语气边界

- **可以用：** "～"（适量）、轻松口语化表达、觅遇仔气泡对话
- **控制使用：** 感叹号（每屏最多1个）、网络梗（只用广泛认知的）
- **禁止：** 过度卖萌、堆叠波浪号/感叹号、暧昧化表达

## 6. 禁用词清单

### 品牌禁用

| 禁用词 | 原因 |
|-------|------|
| 觅途 | 历史名称，已弃用 |
| 局长 | 旧称谓，统一用"主理人" |
| 防鸽费 | 负面感强，统一用"诚意金" |

### 内容禁用

| 禁用词/表达 | 原因 |
|------------|------|
| 约（单独使用） | 容易产生暧昧歧义 |
| 脱单 | 觅遇社不是交友/恋爱平台 |
| 拼饭/约饭/火锅/美食/探店 | 产品定位不涉及餐饮 |
| 最/第一/100%/绝对 | 广告法风险 |
| 免费 | 最低0.01元诚意金，不存在完全免费活动，避免误导 |
| 保证/承诺 | 涉及服务质量的绝对表述，平台不做担保 |
| 微信号/加V/私聊 | 引流违规风险 |

### 语气禁用

| 禁用模式 | 原因 |
|---------|------|
| 过度堆叠"～～～""！！！" | 显得不稳，损害品牌感 |
| 过度网络梗/缩写 | 降低信任感 |
| 恋爱/暧昧/夜店化措辞 | 偏离产品定位 |
| 小红书网红体（"姐妹们"/"家人们"/"宝子们"） | 差异化定位是真实校园感，不是网红感 |

## 7. 觅遇仔使用规范

| 使用场景 | 使用方式 |
|---------|---------|
| 子页/H5页面 | 气泡对话形式出现，一屏最多1个气泡 |
| Banner | 可作为画面元素，不喧宾夺主 |
| 系统提示 | 搭配提示文案，增加亲和力 |
| 广场帖 | 官方帖可以用觅遇仔口吻说话 |
| 表情包 | 已有6种基础表情，按需扩展 |

**气泡对话格式：** 🐱 "对话内容"

**觅遇仔不说的话：** 不用觅遇仔的口吻说规则/法律/安全类硬性内容。
