# 觅遇社拼图 Motif 使用规则（v0）

拼图 motif 是觅遇社当前最有识别度的辅助视觉元素之一。本文件用于把它从“零散出现的元素”升级为“可控的品牌图形语言”。

## 一、角色定位

拼图 motif 的含义建议统一为：

- 连接
- 匹配
- 找到合适的人
- 让局真正发生

它服务的是“人与人被拼在一起”的品牌心智，而不是单纯的装饰图案。

## 二、标准形态

### 1. 基础外形

- 使用圆角拼图，不用机械尖角拼图
- 边缘轮廓厚实、稳定、易识别
- 角和凹槽都保持饱满感

### 2. 标准数量

- mascot 标准姿态：固定两块拼图
- 页面背景 / 海报 / Banner 中：建议单组 1-3 块为宜
- 不要大面积无规律堆满整屏

### 3. 推荐颜色

- 深橙：`#D66D32`
- 金黄：`#FFC03A`
- 品牌橙：`#FF7422`
- 若做弱化背景，可使用低透明度浅橙

## 三、允许的使用场景

### A. 作为 mascot 道具

- 标准姿态双手持拼图
- sticker / system notice 里可根据动作轻微变化位置
- 但不改变拼图核心形态

### B. 作为背景漂浮元素

- Splash Screen
- Banner
- H5 hero 区
- 活动专题页氛围背景

要求：

- 低透明度
- 数量少
- 不抢文字信息主体

### C. 作为品牌辅助图形

- 页面分隔小图标
- 标签装饰角标
- 卡片边缘小元素
- 状态成功 / 匹配成功的视觉提示

## 四、不建议的使用方式

- 不把拼图做成复杂图案拼贴墙
- 不把拼图密集铺满页面
- 不把拼图当成每个组件都必须出现的装饰
- 不把拼图换成锐利、科技感、金属感造型
- 不与过多其他几何符号混杂，避免品牌识别稀释

## 五、使用层级建议

### 1. 强使用

- Logo / mascot 主视觉
- Splash Screen
- 品牌海报

### 2. 中使用

- Banner
- H5 / 子页 hero
- system notice 插图

### 3. 弱使用

- 小程序 UI 内部普通页面
- 规则说明页
- 组件级元素

结论：拼图 motif 应以“品牌符号”身份出现，不应变成到处乱贴的装饰贴纸。

## 六、与其他品牌元素的关系

- 与 mascot 同时出现时：拼图是辅助，mascot 是主体
- 与 Logo 同时出现时：以 Logo 为主，拼图不要重复造成拥挤
- 与按钮 / 标签 / icon 同时出现时：优先保证功能信息清晰，拼图不干扰点击理解

## 七、后续建议

后续如果要继续深化，可以再补：

1. 拼图的标准比例模板
2. 拼图单色版 / 描边版
3. 拼图背景 pattern 模板
4. “匹配成功 / 成团成功”专属拼图动效或插画资产
