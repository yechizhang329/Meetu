# 觅遇仔变体系统（v0）

本文件用于定义觅遇仔后续扩展时的优先级和变体结构，避免每次单独生图导致风格漂移。

## 一、目标

把觅遇仔从一个“标准姿态单图”，扩展为一套可服务于：

- 小程序系统提示
- Sticker / 表情包
- Banner / 海报
- H5 / 子页
- 活动宣传图

的统一角色系统。

## 二、变体层级

### Level 1：上线前高优先变体

优先服务真实使用场景，建议最先补齐：

1. 欢迎 / 迎新
2. 认证成功
3. 报名成功
4. 成团成功
5. 无网络 / 加载失败
6. 温和提醒

这些变体优先用于：

- system notice
- 空状态页
- onboarding / welcome 视觉

其中：

- `报名成功` 属于个人动作确认，情绪应更轻快、更明确，重点是“你已经完成这一步”
- `成团成功` 属于集体结果达成，情绪应更强烈、更有庆祝感，重点是“这场局真的成了”

### Level 2：品牌传播型变体

1. 招手欢迎
2. 举牌 / 举标题牌
3. 奔跑 / 出发
4. 点赞 / 鼓励
5. 举拼图庆祝

这些变体优先用于：

- Banner
- 品牌海报
- 主理人招募页
- 小红书图片

### Level 3：情绪表达型变体

1. 开心
2. 害羞
3. 疑问
4. 惊讶
5. 委屈
6. 加油

这些变体优先用于：

- 聊天表情包
- 社区互动素材
- 节日 / 活动传播

## 三、每个变体必须保持不变的部分

- 角色名称：觅遇仔
- 基础头身比
- 双耳 / 双角轮廓
- 面罩区域形态
- 围巾存在
- 主描边体系
- 米白本体 + 橙黄配色逻辑

## 四、允许变化的部分

- 手势
- 道具
- 拼图位置
- 表情细节
- 站姿 / 动作
- 附加小元素（星星、对话气泡、成功标记等）

## 五、禁止变化的部分

- 不改成其他物种 / 玩偶 / 真人
- 不去掉围巾
- 不去掉面罩
- 不大幅改变体型比例
- 不加入过多复杂服装层次
- 不进入赛博、金属、重潮玩材质风格

## 六、建议的首批变体清单

如果按“最值得先做”的顺序，我建议是：

1. 欢迎版
2. 认证成功版
3. 成团成功版
4. 温和提醒版
5. 无网络版
6. 举牌版
7. 招手版
8. 加油版

## 七、使用建议

- system notice：优先用 Level 1
- 页面氛围 / 海报：优先用 Level 2
- 聊天表情 / 社区互动：优先用 Level 3

结论：后续扩展时，不是“想画什么画什么”，而是按场景从这套变体层级里拿对应版本。
