# 觅遇仔画法参数（v0）

本文件用于锁定觅遇仔的标准姿态和统一画法，避免后续继续出现 AI 生成漂移。

## 一、角色定位

- 名称：觅遇仔
- 类型：品牌 mascot / 小程序形象角色
- 气质关键词：
  - 友好
  - 可靠
  - 年轻
  - 有陪伴感
  - 不低幼

## 二、标准姿态定义

当前标准主版本：

- 站立正面
- 双手各持一块拼图
- 面带轻微微笑
- 围巾明显可见

该姿态作为：

- Logo full version 的 mascot 基础
- Splash Screen 的主视觉 mascot
- 后续 sticker / system notice / 页面插画的母版参考

## 三、造型参数

### 1. 头身比例

- 整体为大头短身比例
- 头部（含帽状外轮廓）约占整体高度的 48% - 52%
- 身体与腿部合计约占整体高度的 48% - 52%

### 2. 轮廓特征

- 外轮廓为圆角、饱满、胶囊感轮廓
- 顶部双耳/双角必须保留，作为识别点
- 面罩区域为横向圆角矩形 / 椭圆矩形
- 手脚短而圆，不做细长真人手脚

### 3. 五官规则

- 眼睛为竖向圆角短条
- 嘴部为轻微上扬弧线
- 不使用夸张大眼、动漫高光眼、写实眼睛
- 不加鼻子

### 4. 围巾规则

- 围巾必须保留，作为角色识别的一部分
- 围巾主体用暖橙 / 金橙色
- 不做过长飘带，不做复杂布料褶皱

### 5. 拼图规则

- 拼图是角色的核心辅助元素
- 标准姿态中固定为两块拼图
- 拼图边缘圆润，不用机械尖角
- 主建议色：
  - 深橙：`#D66D32`
  - 金黄：`#FFC03A`

## 四、线条与上色

### 1. 描边

- 主描边偏深棕：建议 `#6E3F2D`
- 线条稳定、厚实、均匀
- 不要出现不同部位线粗忽粗忽细

### 2. 主色建议

- 品牌橙：`#FF7422`
- 金橙：`#FFB12D`
- 粉色辅助：`#FEB5C0`
- 面罩深灰紫：`#57494D`
- 本体米白：`#FFF8EE`

### 3. 阴影

- 阴影轻量即可
- 不做写实高光 / 金属材质 / 复杂体积光
- 整体仍然是平面卡通 + 轻微立体感

## 五、禁止事项

- 不改成真人、毛绒玩偶、3D 渲染公仔
- 不删除围巾
- 不删除顶部双耳/双角识别
- 不把拼图替换成无关道具
- 不随意增减拼图数量，标准姿态固定为双手各持一块拼图
- 不使用过冷、过科技、过赛博的材质效果
- 不随意改变肤色/本体白色体系

## 六、后续扩展建议

后续基于本母版扩展时，优先扩展：

1. 开心 / 鼓励 / 欢迎 / 提醒 / 认证 / 报错 表情
2. system notice 场景姿态
3. chat sticker 表情包
4. banner / H5 中的简化半身版与头像版
