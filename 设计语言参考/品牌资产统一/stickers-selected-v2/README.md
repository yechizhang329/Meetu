# stickers-selected-v2

基于 `品牌资产统一/stickers v1/` 的第二轮筛选结果。

目标不是收录所有 sticker，而是留下：
- 与觅遇仔身份更一致的版本
- 中文主体明确、符合 Common Sense 的版本
- 适合直接贴进 H5 / CMS 页面，不会因为信息过密而污染版面

## 分类

### `welcome/`
用于欢迎、招呼、品牌开场。

### `cta/`
用于行动引导，如“搭上”“开一场”“开始这一场”。

### `trust/`
用于认证、放心、规则透明、安全感等语义。

### `status/`
用于“齐了出发”“已经成局/可出发”的状态提示。

### `vibe/`
用于轻松、好玩、情绪提亮，不承担核心信息。

## 使用原则

1. Sticker 只做辅助视觉，不替代主标题、正文或 CTA。
2. Sticker 不得遮挡文字信息。
3. 优先放在页面边角、卡片留白区、按钮附近的安全位置。
4. 深色区块优先用边界干净、主体明确的 sticker，避免大面积浅底贴纸发灰。
5. 同一屏最多使用 1-2 个 sticker，避免回到“贴纸板”而不是页面设计。
6. 如果 sticker 自带底色与页面底色冲突，优先换 sticker，不强行硬贴。

- C 活动收费说明：`trust/`、`status/`
- D 女生专场：`trust/`、`vibe/`
