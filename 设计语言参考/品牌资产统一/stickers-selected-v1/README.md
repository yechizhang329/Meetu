# stickers-selected-v1

这是从 `设计语言参考/品牌资产统一/stickers v1/` 中筛出的第一轮可入库 sticker 资产。

目录说明：

- `badges/`：徽章 / 信任标识 / 吉祥物章
- `capsules/`：胶囊标签
- `bubbles/`：对话气泡
- `routes/`：路径线 / 连接线
- `cards/`：说明卡 / 规则卡
- `ctas/`：动作按钮
- `ribbons/`：倾斜纸带 / 贴纸条

使用建议：

- 优先把这些 sticker 当作 **页面装饰系统** 来用，而不是单独当作“表情包”
- 中文为主，英文只做少量装饰
- 与现有 `觅遇仔`、页面路径线、CTA 按钮、trust tag 混用时，优先保持暖橙 / 奶油白 / 可可棕 / 柔和紫蓝的统一基调
