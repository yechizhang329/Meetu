# stickers-selected-v1

这是 `stickers v1` 的**第一轮干净可复用子集**，用于 CMS、Banner、H5、海报里的贴纸化装饰层。

## 本轮处理原则

- 直接从原始 5 张 sticker board 中重做 crop，不从旧的中间筛选目录继续裁
- 每个文件只保留一个目标元素
- 去掉相邻 sticker 的边角、分类标题、无关碎片和底纹污染
- 优先保留**中文为主、结构干净、能直接复用**的通用组件

## 当前入库范围

本轮共保留 **16 个**素材，分为 4 类：

- `badges/`：6 个
- `bubbles/`：3 个
- `ctas/`：3 个
- `routes/`：4 个

## 为什么这轮只做 16 个

这不是“从 5 张图里挑最好看的 sticker”，而是“先收一批真的能直接用的单体素材”。

本轮只保留同时满足以下条件的元素：

1. 中文优先，语义明确
2. crop 后仍是完整独立素材
3. 不依赖整张板子的上下文才能成立
4. 可以直接贴进页面，不需要再二次清理

因此，很多视觉上不错、但边缘粘连严重、分类标题混入、或 mascot 一致性不稳的元素，被这轮主动排除了。

## 来源说明

本轮最终入库主要来自：

- `1.png`：最适合先提取干净的 utility 元素（badge / bubble / CTA / route）

同时保留以下判断：

- `4.png`、`5.png`：仍然是下一轮 richer sticker / mascot-consistent 素材的最佳来源
- `2.png`：英文负载过高，不适合当前中文主导资产库
- `3.png`：mascot 结构不稳，不适合作为当前主来源

## 下一轮补充方向

这一版解决的是“先有一套干净通用件”，还没有覆盖更丰富的品牌表达。下一轮优先补：

- 女生专场专属贴纸
- 主理人招募专属贴纸
- 费用透明 / 规则优先贴纸
- 更大尺寸的 editorial 装饰件
