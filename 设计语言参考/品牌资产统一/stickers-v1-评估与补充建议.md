# stickers v1 评估与补充建议

## 结论

这批 `stickers v1` 已经可以作为第一轮品牌视觉资产库使用，但不是整包都适合直接入库。

设计侧结论：

- **最符合品牌要求的来源**：`4.png`、`5.png`
- **可局部吸收的来源**：`1.png`
- **暂不建议直接入库的来源**：`2.png`、`3.png`

原因：

- `4.png`、`5.png` 的装饰语言最稳定，已经具备目前 Meetu 需要的几类核心元素：
  - 厚描边圆角 sticker
  - 中文优先的 capsule trust tags
  - 路径线 / 节点 / 连接感元素
  - CTA 按钮型 sticker
  - 规则卡 / 说明卡
  - 与现有觅遇仔形象较接近的变体
- `1.png` 里有少量可用元素，但整体更像“素材混排页”，一致性不如 `4/5`
- `2.png` 英文比例偏高，且整体更偏装饰试验，不适合作为当前中文主导资产库的主来源
- `3.png` 虽然有一些中文元素，但 mascot 细节和构图稳定性不如 `4/5`，更适合作为补充参考，不适合直接入库

## 本轮筛选标准

本轮只保留同时满足以下条件的 sticker：

1. **中文优先**
   - 主信息以中文为主，英文只做少量装饰
2. **与现有品牌一致**
   - 暖橙 / 奶油白 / 可可棕 / 柔和紫蓝范围内
   - 觅遇仔保持既有身份，不重新想象
3. **贴近搭子社交语境**
   - 围绕 `搭上 / 齐了 / 求搭子 / 放心来 / 规则透明` 等现有语言体系
4. **可直接复用**
   - 能直接贴进 CMS / Banner / 海报 / H5，而不是只能当一整张情绪板看
5. **单体成立**
   - 从大图中 crop 出来后，仍然是一个完整的 sticker，而不是依赖整张板子的局部残影

## 当前仍然欠缺的元素

虽然 `stickers v1` 已经覆盖了基础组件，但还缺 4 组高优先级元素：

### A. 女生专场专属 sticker 组

当前问题：

- 现有 sticker 偏通用信任/CTA
- 缺一组真正属于“女生专场”的轻安全感元素
- 不能靠 generic 野餐图来替代这组情绪层

建议补充内容：

- `女生专场`
- `安心搭上`
- `全员认证`
- `轻松认识`
- `先看规则`
- `不赶时间`

### B. 主理人招募专属 sticker 组

当前问题：

- 有通用 `host energy` 气质
- 但没有足够多围绕“开一场 / 你来组织 / 平台帮你扛杂事 / 顺便赚点零花钱”的中文组件

建议补充内容：

- `开一场`
- `主理人带搭`
- `活动招募中`
- `时间地点费用`
- `人齐就开搞`
- `平台帮你扛`

### C. 费用透明 / 规则优先 sticker 组

当前问题：

- 现有信任标签有了
- 但缺一组更明确服务于 `活动收费说明` 页面的中文规则型 micro sticker

建议补充内容：

- `门槛价`
- `费用透明`
- `看清再搭上`
- `规则先说清`
- `没有隐藏费用`
- `按活动规则来`

### D. 大尺寸 editorial 装饰元素组

当前问题：

- 当前 stickers 更像小组件
- 缺大幅面页面真正需要的“版式材料”
- Jonathan 已明确指出：素材不只是图片，还包括装饰元素本身

建议补充内容：

- 大号倾斜标题条
- 大号路径线底纹
- 大号票据 / 便签 / notebook 撕纸
- 章节分隔用的 badge cluster
- 用于 hero 区的 oversized Chinese word blocks

## 对应补充 Prompt

以下 prompt 已按当前共同标准写成跨平台版本，适合继续走 `PNG master + prompt + 现有物料叠加` 模型。

### Prompt A：Girls-only sticker pack

Create a Chinese-first sticker pack for a girls-only social activity page of a youthful campus social brand.

Style:
- warm, safe, relaxed, not childish
- soft orange, cream white, cocoa brown, lavender purple accents
- rounded thick-outline stickers
- consistent with an existing warm campus social visual system
- Chinese is primary, English only as tiny decorative accent if needed

Required mood:
- safe but not overprotective
- soft but not weak
- low-pressure social energy
- feels like "I can join this without worrying"

Include sticker ideas such as:
- 女生专场
- 安心搭上
- 全员认证
- 轻松认识
- 先看规则
- 不赶时间

Also include:
- 1-2 route/path stickers
- 1-2 tilted ribbon stickers
- 2 trust badges
- 2 CTA-type chips

The output must feel compatible with an approved Meetu mascot and current brand assets.

### Prompt B：Host recruitment sticker pack

Create a Chinese-first sticker pack for a host recruitment page of a campus activity social brand.

Style:
- bold, energetic, editorial, slightly poster-like
- warm orange as anchor, cream white, cocoa brown, muted purple-blue as support
- thick outlines, rounded shapes, asymmetrical badge composition
- not childish, not corporate, not startup-generic

Target feeling:
- being a host feels cool
- you are the person who gets people moving
- the platform helps you with the messy parts

Include sticker ideas such as:
- 开一场
- 主理人带搭
- 活动招募中
- 时间地点费用
- 人齐就开搞
- 平台帮你扛

Also include:
- 2 tilted labels
- 2 note-card stickers
- 2 CTA chips
- 1 path strip showing momentum / gathering / starting

### Prompt C：Pricing and rules sticker pack

Create a Chinese-first sticker pack for an activity pricing and rules explanation page.

Style:
- clear, trustworthy, modern, not cold
- blue-gray and warm orange as core accents
- Chinese text should carry the main information
- English only as minimal decorative support

Goal:
- make pricing feel transparent
- make rules feel clear rather than bureaucratic
- reduce hesitation before joining

Include sticker ideas such as:
- 门槛价
- 费用透明
- 看清再搭上
- 规则先说清
- 没有隐藏费用
- 按活动规则来

Also include:
- rule badges
- mini note cards
- route strips
- small trust chips for FAQs and pricing modules

### Prompt D：Editorial decoration system pack

Create a Chinese-first editorial decoration system for a youthful campus social brand page system.

This is not a photo pack. It is a high-finish decorative element pack for layout building.

Style:
- packaging-oriented
- suitable for content pages, CMS pages, banners, and H5
- warm orange, cream white, cocoa brown, soft purple-blue
- hand-packed but refined, not messy

Need large-scale decoration assets such as:
- oversized tilted title strips
- large route/path background elements
- notebook / memo / ticket / tear-paper blocks
- chapter divider badges
- oversized Chinese word blocks for page rhythm

The system must work with existing mascot assets, trust tags, CTA chips, and current Meetu page language.

## 建议执行顺序

按当前优先级，建议继续这样做：

1. `A Girls-only sticker pack`
2. `B Host recruitment sticker pack`
3. `C Pricing and rules sticker pack`
4. `D Editorial decoration system pack`

原因：

- 前两组直接影响当前 CMS / Banner / 招募与女生专场页面
- 第三组能补全收费说明的信任表达
- 第四组是整套页面设计感提升的基础，会长期复用
