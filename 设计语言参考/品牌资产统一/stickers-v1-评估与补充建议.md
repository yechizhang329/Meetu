# stickers v1 评估与补充建议

## 当前结论

`stickers v1` 已经能支撑第一轮品牌贴纸体系，但不能把整包直接当作素材库。  
本轮按照 DavidC 的要求，重新从原始 5 张大图里直接裁切，先收出一批**真正干净、可独立复用**的基础件。

设计侧结论维持不变：

- **最佳来源**：`4.png`、`5.png`
- **可局部吸收**：`1.png`
- **暂不建议直接入库**：`2.png`、`3.png`

但执行上做了一个更保守的选择：

- 当前 `stickers-selected-v1/` 这一版最终入库，主要来自 `1.png`
- 原因不是 `1.png` 整体最好，而是它的 utility 元素最容易清理成干净单体
- `4.png`、`5.png` 继续保留为下一轮 richer / mascot-consistent sticker 的主来源

## 对 5 张大图的当前判断

### 1.png

优点：

- 中文主导
- badge / bubble / CTA / route 这类 utility 元素相对集中
- 适合先切出干净通用件

问题：

- mascot 本体比例不够稳定
- 更像混排情绪板，不适合作为整包直接入库

### 2.png

问题：

- 英文占比过高
- 当前与“中文为主、英文点缀”的共识不一致

结论：

- 暂不作为当前素材库来源

### 3.png

问题：

- 中间 mascot 的身体结构与 master 偏差明显
- 一致性风险高

结论：

- 暂不作为当前素材库来源

### 4.png

优点：

- 中文主导
- 觅遇仔一致性最好
- 色系、厚描边、路径感、贴纸化语言最成熟

结论：

- 仍然是下一轮主力来源

### 5.png

优点：

- 整体完成度高
- mascot 相对稳定
- 更适合做 richer sticker / hero decoration / badge cluster

结论：

- 同样保留为下一轮主力来源

## 本轮入库标准

这轮不追求“多”，只追求“干净能用”。

仅保留同时满足以下条件的素材：

1. 中文优先，含义明确
2. crop 后仍是完整单体
3. 不混入分类标题、邻近元素和边角残片
4. 可以直接贴进 CMS / Banner / H5 / 海报
5. 不依赖整张情绪板上下文才能成立

## 为什么没有保留更多类别

上一版中存在的 cards / ribbons / mascot-heavy stickers，没有进入这一轮最终库，原因很简单：

- crop 后容易带入无关碎片
- 单体完整性不够
- 视觉身份容易漂
- 入库后还需要二次清理，不能算“可直接复用”

所以这轮先把基础 utility layer 做干净，再向 richer asset 迭代。

## 当前仍欠缺的 4 组元素

### A. 女生专场专属贴纸

当前问题：

- 现有 sticker 偏通用
- 缺女生专场独有的轻安全感 / 柔和社交气质

建议补：

- `安心搭上`
- `全员认证`
- `轻松认识`
- `先看规则`
- `不赶时间`

### B. 主理人招募专属贴纸

当前问题：

- 有通用 CTA，但缺专门服务于“开一场 / 你来组织 / 平台帮你扛”的表达件

建议补：

- `开一场`
- `主理人带搭`
- `活动招募中`
- `时间地点费用`
- `人齐就开搞`
- `平台帮你扛`

### C. 费用透明 / 规则优先贴纸

当前问题：

- 现有 trust tag 够通用，但不够服务 `活动收费说明`

建议补：

- `门槛价`
- `费用透明`
- `看清再搭上`
- `规则先说清`
- `没有隐藏费用`
- `按活动规则来`

### D. 更大尺寸的 editorial 装饰件

当前问题：

- 现有 16 个素材更偏小组件
- 大幅内容页真正需要的版式材料还不够

建议补：

- 大号倾斜标题条
- 大号路径线底纹
- 票据 / 便签 / notebook 撕纸
- badge cluster
- oversized Chinese word blocks

## 对下一轮 prompt 的建议

下一轮不要继续做“整包都很好看但不方便用”的 sheet。  
目标应切换为：

1. 明确一张 sheet 服务哪一类缺口
2. 让每个元素有足够留白，方便后续干净裁切
3. 继续坚持：
   - 中文为主
   - PNG-first
   - mascot 与 master 一致
   - 贴纸即页面可用件，不只是情绪板素材

## 本轮最终判断

- `stickers-selected-v1/` 现在可以作为**第一轮干净基础件库**使用
- 下一轮 richer pack 应优先回到 `4.png`、`5.png` 的语言和完成度
- 但执行上仍然必须坚持“能干净裁切、能直接复用”优先，而不是先追整板好看
