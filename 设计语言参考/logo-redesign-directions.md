# Meetu Logo 重设计方向提案

> 用途：给 `#产品讨论Product / #设计讨论Design` 讨论品牌 logo 改版方向  
> 目标：用于小程序 icon、线上海报、图片角标、后续品牌系统扩展

---

## 1. 现状判断

当前参考 logo（`项目资料/REF_logo.jpg`）的问题，不只是“好不好看”，而是它在今天的使用场景里承担不了主品牌符号的任务：

### 现有问题

1. **幼态感过强**
- 主符号完全依赖圆润 mascot 角色，脸部表情和身体比例偏可爱吉祥物路线。
- 放到小程序 icon 尺寸时，传达的是“卡通陪伴感”，不是“有趣、自由、时尚、多元、酷”。

2. **识别核心不够集中**
- 现在同时有：角色、围巾、拼图、英文名、中文名、右侧方形 icon。
- 视觉焦点太散，传播时用户很难一句话记住“到底哪个是品牌主记忆点”。

3. **传播性偏弱**
- 角色型 logo 适合做补充人格，但不适合承担所有主品牌触点。
- 小程序 icon、海报角标、封面水印更需要一个**更短、更硬、更能缩小使用**的符号。

4. **气质与目标群体有偏差**
- 18-25 岁大学生要的不是“儿童陪伴感”，而是“这个东西看起来有趣、会玩、有态度”。
- `Common Sense` 明确的底线是：**年轻感 + 可信感 + 设计感**。当前 logo 的“年轻”有了，但“设计感”和“可信感”偏弱。

5. **旧中文名风险**
- 参考图里仍出现 `觅途`，这在现阶段已经是错误方向。
- 新 logo 方案必须彻底收口到 `Meetu / 觅遇社` 体系。

---

## 2. Common Sense 约束

结合现有 `Common Sense`，logo 改版要满足以下底层原则：

### 品牌气质底线
- 年轻感：不老气，不企业化，不政务感
- 可信感：不山寨，不廉价，不低幼
- 设计感：不是素材拼凑，不是通用 AI 萌系卡通

### 品牌弹性
- 暖橙是锚点，不是牢笼；logo 不必永远只用暖橙
- 但 logo 不能丢掉 Meetu 的“轻松、会玩、可接近”的品牌温度

### 场景适配
- **小程序 icon** 需要：缩到很小仍可辨识
- **海报 / banner / 物料** 需要：可以扩展成完整 wordmark 或组合标
- **后续视觉系统** 需要：能长出 badge、章、状态标、子品牌锁定方式

---

## 3. 可选方向

下面是目前最值得考虑的 4 条路。

### 方向 A：`M` 字母变体

**核心想法**
- 用 `M` 作为最小识别单元。
- 在 `M` 的内部或笔画连接处，融入“连接 / 拼上 / 搭上 / 齐了”的结构感。

**适合原因**
- 最适合小程序 icon：短、硬、缩小后稳定。
- 英文品牌名 `Meetu` 的首字母天然成立。
- 可以做得更时尚、更像当代互联网产品，而不是卡通品牌。

**可做的变体**
- `M` 中间出现一个“连接点 / 卡扣 / 拼合缺口”
- `M` 的两腿像两个人向中间靠拢
- `M` 的顶端做轻微错位或咬合，表达“正在发生连接”

**风险**
- 太像通用科技公司 monogram 就会失去品牌个性。
- “拼图”元素不能 literal 到像儿童玩具。

**适用度**
- 小程序 icon：**非常高**
- 海报传播：高
- 角色系统兼容：高

---

### 方向 B：`Meetu` 字标变体

**核心想法**
- 不把 logo 做成图标，而是把 `Meetu` 本身做成有识别度的定制字标。
- 通过 `e / t / u` 的关系处理，做出“连接”“会合”“搭上”的感觉。

**适合原因**
- 更时尚，传播时不需要解释图形含义。
- 对大学生群体更接近“品牌 / 厂牌 / 社群名”的传播方式。
- 可以在海报、banner、封面上直接形成强识别。

**可做的变体**
- 两个 `e` 形成一组节奏记忆点
- `t` 与 `u` 之间做轻微连接 / 勾连
- 局部加入切角、内收、错位，做“会玩但不幼态”的细节

**风险**
- 只做字标时，小尺寸 app icon 可能不够稳定。
- 需要同时配一个 `M` 或缩写 icon 才能形成完整系统。

**适用度**
- 小程序 icon：中
- 海报传播：**非常高**
- 品牌时尚度：**非常高**

---

### 方向 C：`觅` 字艺术化处理

**核心想法**
- 用中文“觅”做主图形。
- 不是书法，不是篆刻，而是把“觅”重新做成更现代、几何、年轻的中文字标。

**适合原因**
- 对中文用户更直接，更有本土识别力。
- 如果处理得好，会比英文字母更有品牌独占性。
- 对“寻找 / 探索 / 出去玩”的语义更强。

**可做的变体**
- 把“觅”简化成适合 icon 的几何笔画
- 局部加入“路径 / 连接 / 会合”的暗示
- 做成方中有动势的现代字徽

**风险**
- 一不小心就会变成“文艺品牌”“茶饮品牌”“文化展览品牌”
- 太书法会老气，太装饰会失去辨识度

**适用度**
- 小程序 icon：高
- 海报传播：中高
- 品牌独占性：**非常高**

---

### 方向 D：双系统方案（推荐）

**核心想法**
- 不强迫一个 logo 同时承担所有任务。
- 建立两层系统：
  - **主识别 icon**：`M` 或 `觅` 的缩写符号
  - **主传播字标**：`Meetu` 的定制字标

**为什么最合理**
- 这最符合 Meetu 现在的真实使用场景：
  - 小程序 icon 需要“短”
  - 海报 / banner / H5 需要“有品牌感”
- 还能保留 `觅遇仔` 作为**辅助人格资产**，而不是把 mascot 当主 logo 硬扛

**推荐组合**
- 方案 D1：`M` icon + `Meetu` wordmark
- 方案 D2：`觅` icon + `Meetu` wordmark

**适用度**
- 小程序 icon：**非常高**
- 海报传播：**非常高**
- 后续系统扩展：**非常高**

---

## 4. 我的推荐顺位

### 第一推荐：方向 D1
- **`M` 主 icon + `Meetu` 定制字标**

原因：
- 最平衡：识别、传播、时尚度、系统扩展都强
- 最适合小程序 icon
- 最容易摆脱当前“幼态 mascot 主导”的问题
- 也最容易在后续物料中形成统一体系

### 第二推荐：方向 D2
- **`觅` 主 icon + `Meetu` 定制字标**

原因：
- 更本土，更有独占性
- 但对设计要求更高，稍不小心就会走偏成“文艺 / 传统 / 老派”

### 不建议直接走的路

1. **不建议继续把 mascot 当主 logo**
- 觅遇仔适合做人格资产，不适合继续做主品牌核心识别。

2. **不建议做太 literal 的拼图**
- “拼图”可以是结构暗示，但不能画成儿童玩具。

3. **不建议 logo 一开始就上多色复杂渐变**
- logo 先要解决识别问题，再谈风格化扩展。

4. **不建议走手写 / 书法 / 可爱圆体路线**
- 会继续往“幼”“软”“不够时尚”的方向滑。

---

## 5. 建议的设计关键词

如果下一步进入出方案，建议把关键词锁成：

- **年轻**
- **时尚**
- **有识别度**
- **不低幼**
- **有连接感**
- **有点酷**
- **可缩小**
- **像一个会玩的年轻平台，不像儿童品牌**

---

## 6. 下一步建议

如果 DavidC / Fiona 确认进入执行，我建议直接出 **3 套初版方向稿**：

1. **M 连接变体**
- 小程序 icon 优先方向

2. **Meetu 定制字标**
- 海报 / banner 优先方向

3. **觅 字几何徽标**
- 中文独占性方向

然后用统一标准评估：
- 1 秒能不能认出
- 缩到 64×64 还成不成立
- 放到海报角落有没有品牌感
- 去掉颜色后还剩不剩识别
- 用户会不会觉得“太幼 / 太土 / 太像别家”
