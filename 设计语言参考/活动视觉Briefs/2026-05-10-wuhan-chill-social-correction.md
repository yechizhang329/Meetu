# 5/10 武汉 Chill 小局物料纠偏 Brief

> 背景：Jonathan 看了 Image2 产出和当前详情页后反馈不理想：设计感欠佳、重点不够突出、`¥1` 不要到处写，当前详情页内容不如之前产出。此 brief 用于纠偏，不是继续加法。

## 1. 核心判断

上一轮 `369c96b` 方向过度追求“第三空间”和工具箱感，导致：

- 视觉元素变多，重点被稀释。
- Image2 容易生成咖啡馆品牌/生活方式摆拍，而不是活动邀请。
- `¥1` 被当成显性卖点，但活动上架自然会带 1 元价格，视觉里不应反复出现。
- 详情页信息虽然完整，但阅读重心不够集中。

本轮不是再做“更丰富”，而是回到“更清楚、更聚焦、更像可报名活动”。

## 2. 基线选择

不要以 `369c96b` 继续加法。

请以 `da18f7e` 的版本作为更好的基线：它比当前版本更清楚、更直接、更接近活动上架需要。可以保留 `da18f7e` 中的生活方式邀请感，但要进一步减噪和重建重点。

## 3. 本轮目标

用户第一眼只需要理解三件事：

1. 这是一个周日下午出来坐坐的小局。
2. 是给武汉在校大学生认识新朋友的。
3. 安全、轻松、无压力，可以报名。

不要让用户第一眼先看到：咖啡馆风格、桌面摆拍、¥1、host 履历、复杂信息卡。

## 4. 封面 / Image2 Prompt 纠偏

### 4.1 封面主信息

封面只突出一个主标题：

`周日出来坐坐`

可选副标题：

`认识几个新朋友`

辅助信息只保留：

- `5.10 周日 14:00-16:00`
- `武汉街道口附近`
- `在校学生小局`

不要在封面写：

- `¥1占位`
- `奶茶/咖啡 + 小食`
- 太多安全规则
- 太多 host 标签

原因：上架卡片天然有价格；封面需要先解决“我想不想点进来”。

### 4.2 Image2 Prompt 风格

从“第三空间桌面摆拍”改为：

**清爽活动邀请卡 + 轻微真实场景暗示**

推荐画面：

- 大面积干净留白。
- 一个温暖但克制的邀请卡片主体。
- 背景可以轻微暗示白天公共空间，但不要堆桌面物件。
- 人物可以不出现；如果出现，只作为非常弱的模糊氛围，不要正脸群像。
- 不要咖啡品牌海报感，不要过多杯子/小食/窗光/桌面物件。

关键词：clean invitation card, simple hierarchy, warm but restrained, college social gathering, low pressure, readable mobile cover.

### 4.3 Prompt 必须增加的负向约束

- No cafe brand advertisement.
- No coffee product poster.
- No cluttered tabletop still life.
- No over-decorated lifestyle shot.
- No price-focused design.
- Do not show `¥1` on cover.

## 5. 详情页纠偏

### 5.1 首屏

首屏优先级：

1. 时间地点小标签。
2. 主标题：`周日出来坐坐，认识几个新朋友`。
3. 一句话解释：`不是讲座，不是相亲局，也不是酒局。就是找个舒服的地方，喝点东西，随便聊聊。`
4. 3 个以内关键标签：`在校学生` / `20人左右` / `公共场合`。

不要在首屏放：

- `¥1占位`
- 太多桌面物件
- 太多装饰 icon
- host 标签

### 5.2 内容结构

建议保留 5 个模块，顺序如下：

1. `这是什么`：一句话讲清楚活动。
2. `关键信息`：时间、地点、对象、人数、包含内容。
3. `放心来`：公共场合、女生可带朋友、不强制加微信/拍照/续摊。
4. `不知道聊什么也没关系`：host 是兜底，不是主菜。
5. `报名说明`：这里再说明 `¥1占位，主要怕临时鸽太多，不是为了收费`。

`¥1` 只在报名说明或费用卡出现一次，不要在首屏、封面、多个信息卡重复出现。

### 5.3 Host 部分

Host 要继续弱化：

- 只作为“不知道聊什么可以找我们开头”。
- 不要让 Jonathan/David 的经历变成详情页视觉重点。
- tag 数量控制，每人 3-4 个即可。

## 6. 设计语言

参考方式：

- `notion`：清晰、编辑感、克制信息层级。
- `airbnb`：温暖、可信、低压力。
- `mastercard`：仅借暖色卡片秩序，不要几何过度。

暂停使用：

- `starbucks` 作为主参考，因为它容易把 Image2 带偏成咖啡馆品牌/第三空间广告。
- `nike` 完全不用。
- Nerd Fonts 不用于 HTML 必需字体。

## 8. 验收标准

- 封面/Prompt 第一重点是活动邀请，不是咖啡空间、价格、host 或物料细节。
- `¥1` 不在封面出现，详情页最多出现一次集中解释。
- 详情页比 `369c96b` 更清楚、更短、更聚焦。
- 活动事实不变：5.10 周日 14:00-16:00，街道口附近，在校学生，20人左右最多30，奶茶/咖啡+小食，公共场合，女生可带朋友，不强制加微信/拍照/续摊。
- HTML 仍满足：单文件 inline CSS、无外链、无 `<img>`、无 `<script>`、无 `display:grid`。
