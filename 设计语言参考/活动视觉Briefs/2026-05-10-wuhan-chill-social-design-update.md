# 5/10 武汉 Chill 小局设计更新 Brief

> 给 Phoebe 的设计更新说明。参考本地 `awesome-design-md` 的 Airbnb / Notion / Pinterest / Figma 方向，不是照抄品牌，而是提取适合 Meetu 这场活动的设计方法。

## 1. 当前版本判断

当前 HTML 和 Image2 prompt 的优点是安全、清楚、无酒局/相亲/夜店误导；问题是视觉仍偏“普通暖橙信息卡”，更像上架说明，不够像一场真的会发生的周日下午小局。

这次需要从“活动信息页”升级成“有生活方式感的邀请卡”：用户第一眼不是只看到信息，而是感到“这个局真实、安全、轻松，我可以去坐坐”。

## 2. 参考方向

### Airbnb：生活方式入口
- 大面积温暖留白，内容像可进入的生活场景。
- 让“公共空间 / 桌面 / 饮品 / 人”成为主角，而不是让橙色卡片成为主角。
- 阴影更轻、更柔，不要厚重堆卡。

### Notion：编辑感和秩序
- 信息模块像“被认真编辑过的邀请说明”，不是广告海报。
- 用轻边框、清晰标题、短段落和留白建立可信感。
- 规则、安全说明、费用说明要克制清楚。

### Pinterest：年轻但不低幼
- 需要一点“不对称”和“灵感板”感觉，避免每个模块都像同款圆角卡。
- 可以用纸条、便签、桌面物件、咖啡杯、小食、手机、聊天气泡等元素制造记忆点。
- 色彩可以有局部情绪峰值，但不要整页高饱和。

### Figma：标签系统感
- 时间、地点、人数、费用、对象等信息用系统化 pill / label / check item。
- 标签要承担导视功能，不是贴纸装饰。

## 3. 新视觉原则

建议比例：70% Airbnb/Pinterest 生活方式感 + 20% Notion 信息秩序 + 10% Figma 标签系统。

关键词：周日下午、真实学生、公共咖啡空间、桌面细节、轻松认识人、安全感、朋友发来的邀请。

必须避免：夜店感、酒局感、相亲感、讲座感、职业咨询感、黑金霓虹、过度商务、过度网红、AI感很重的人脸。

## 4. HTML 更新方向

文件：`activity-detail-demos/demo-5-武汉Chill小局.html`

### 4.1 Hero 首屏
- 从“橙色大标题卡”改为“邀请卡 + 场景感”的首屏。
- 可以做一个纯 CSS 的桌面/咖啡馆场景感：奶茶杯、纸条、聊天气泡、座位圆点、浅色桌面块；如果不确定，就用抽象桌面而不是具体人像。
- 主标题保留：`周日出来坐坐，认识几个新朋友`。
- 副标题保持低压：`不是讲座，不是相亲局，也不是酒局。就是找个舒服的地方，喝点东西，随便聊聊。`
- 首屏标签控制在 3 个以内：`5.10 周日 14:00-16:00` / `街道口附近` / `20人左右`。

### 4.2 信息结构
- 不要一屏堆 6 个同款信息卡。改成“关键事实 + 安全说明 + 不需要准备什么”三段。
- 关键信息可以用 2 列 pill/card，但每张卡要更轻，边框更细，间距更大。
- `¥1占位` 不要做成过强销售 CTA；它是降低鸽子率的解释，不是卖点。

### 4.3 Host 呈现
- Host 不要像履历展示。改成“怕不知道聊什么，可以找我们开头”。
- Jonathan / David 的经历用聊天 tag 表达：
  - Jonathan：`三本到 UCLA` / `AI和技术` / `裸辞 MBA` / `滑雪健身` / `摩托 318、219`
  - David：`美国几年` / `金融` / `MBA` / `职业转型` / `创业探索` / `很多事没按计划走`
- 文案重点是“有话题可聊”，不是“我们很厉害”。

### 4.4 情绪托底
- 单独保留一个“放心来”的模块：公共场合、女生可带朋友、不强制加微信/拍照/续摊。
- 视觉上建议像 Notion 的说明块：白底、轻边框、checklist，而不是深色大卡，避免压迫感。

### 4.5 技术边界
- 继续单文件 inline CSS。
- 不依赖外链、图片、JS。
- 继续不用 `display:grid`，保证微信 webview 稳定。

## 5. Image2 Prompt 更新方向

文件：`设计语言参考/Image2-Prompts/2026-05-10-wuhan-chill-social.md`

### 主封面
- 从“活动海报”改成“生活方式邀请封面”。
- 推荐画面：周日下午咖啡店桌面俯拍或 3/4 视角；桌上有奶茶/咖啡、小食、手机、纸条；能暗示 4-6 个学生在聊天，但不要强依赖正脸。
- 文字区像一张贴在桌面上的便签/邀请卡，不要悬浮大字海报。
- 保留文字：
  - `周日出来坐坐`
  - `5.10 武汉街道口附近`
  - `在校学生｜20人左右｜¥1占位`

### 说明长图
- 做成“清爽邀请说明卡”，不是官方通知。
- 信息分组：`什么时候` / `在哪里` / `谁可以来` / `需要准备吗` / `安全感`。
- 公开小红书图里用 `不强制交换联系方式`，私域/小程序可用 `不强制加微信`。
