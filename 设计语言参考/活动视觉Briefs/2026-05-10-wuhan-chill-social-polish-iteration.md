# 5/10 武汉 Chill 小局物料小迭代 Brief

> 目标：在现有 `da18f7e` 视觉版本基础上做小幅增强，不推倒重来，不改变活动信息结构。

## 1. 这次迭代的判断

当前版本已经合格：安全、清楚、有生活方式感。新的工具和参考库加持后，本轮只做“记忆点和质感增强”。

不要把它做成大型 campaign、运动品牌广告、职业咨询海报或夜生活活动。它仍然是一个周日下午、公共空间、大学生低压力出来坐坐的小局。

## 2. 参考优先级

### 优先参考：`starbucks`

借鉴方法：

- 第三空间感：让画面更像“可以坐下来聊天的公共空间”，不是单纯桌面道具摆拍。
- 咖啡/饮品/小食的温暖生活方式氛围。
- 社区感、熟悉感、白天安全感。
- 温暖但不甜腻的奶油、咖啡、浅绿/木色辅助氛围。

不复制：Starbucks logo、深绿品牌占有、咖啡品牌化表达。

### 次优先参考：`mastercard`

借鉴方法：

- 暖色 editorial card。
- 圆角几何节奏、柔和分区、轻边框。
- 信息卡可以更“可信”和“有秩序”，不要像公告表格。

不复制：Mastercard 红黄圆形品牌符号、支付品牌感。

### 只作为微弱参考：`theverge` / `wired`

借鉴方法：

- 标题层级、信息密度控制、编辑感节奏。
- 适合说明长图，不适合主封面。

不复制：强媒体感、复杂分栏、过强科技杂志调性。

### 暂不使用：`nike`

原因：高冲击、运动感、campaign 感太强，容易压掉 Meetu 这场活动的温暖、安全和松弛。

请只更新这两个文件：

1. `activity-detail-demos/demo-5-武汉Chill小局.html`
2. `设计语言参考/Image2-Prompts/2026-05-10-wuhan-chill-social.md`

## 4. HTML 轻量增强方向

### 4.1 首屏第三空间感

当前首屏已有桌面邀请卡，可以再加强“真实公共空间”暗示：

- 可用纯 CSS 增加一点窗光、桌面阴影、座位圆点、杯垫、纸巾/小票/菜单条等抽象元素。
- 不要加入真实图片，不要用 `<img>`。
- 不要让元素变多导致拥挤，最多增强 2-3 个细节。

### 4.2 色彩细调

- 保持奶油、浅咖、暖橙为主。
- 可以引入非常轻的 muted sage / warm green 作为公共空间氛围点缀，但必须低饱和、小面积。
- 不要出现夜店绿、霓虹绿、黑金或强红。

### 4.3 信息卡质感

- `关键事实` 和 `放心来` 可以更像暖色 editorial card：更轻边框、更好留白、更稳定的标题/正文层级。
- `¥1占位` 继续解释为确认位置，不要做成销售卖点。

### 4.4 Nerd Fonts 使用边界

- HTML 线上展示不能依赖用户本地安装 Nerd Font。
- 如果需要小符号，请优先用普通 Unicode、CSS shape、或纯 CSS 图形。
- Nerd Fonts 可用于出图/设计探索或转成静态 SVG 后再用；不要直接作为 HTML 必需字体。

## 5. Image2 Prompt 优化方向

### 主封面 Prompt

从“桌面邀请卡”再推进到“第三空间邀请卡”：

- 场景不仅有桌面，也要能感到白天下午公共咖啡空间。
- 可以出现：窗边自然光、木质桌面、几杯饮品、简单小食、桌面纸条、模糊学生身影/手部动作/旁边座位。
- 文字仍然像纸条/邀请卡上的内容，而不是海报大字。
- 氛围关键词：safe third place, Sunday afternoon, warm cafe daylight, real college students, low-pressure social gathering。

### 说明长图 Prompt

参考 `mastercard` 的暖色 editorial card：

- 更强调圆角几何节奏、轻边框、清楚分组。
- 可以加入小型普通图标感元素，但不要变成图标堆砌。
- 保持可读性第一。

## 6. 验收标准

- 用户第一眼能感到：安全、真实、周日下午、公共空间、可以低压力参加。
- 不改变活动信息和报名规则。
- HTML 仍满足：单文件 inline CSS、无外链、无 `<img>`、无 `<script>`、无 `display:grid`。
- Prompt 仍明确规避：酒局、夜店、相亲、讲座、职业咨询、黑金霓虹、暧昧恋爱感。
- 交付说明里写清楚：参考了哪个系统、借鉴什么方法、没有复制什么。
