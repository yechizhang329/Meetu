## 视觉方向 v1 验收结论

PM 已确认：

- P0 主实现只走 **A 桌面便签动物园**。
- B「群聊截图动物局」和 C「标本卡动物档案」先作为后续分享变体/扩展，不在首版混用。
- 4 只代表动物先用于验证：省电猫、整活猴、边界刺猬、社交蝴蝶。
- 扩展 16 只动物时必须继续用 **动作 + 道具 + 表情 + 主色** 区分，不能只换色。
- Meetu/品牌露出保持极轻，不放活动 CTA、二维码、加群、下载 App。

## 给前端的 P0 实现建议

- 首版可以基于 `04-前端样式稿/index.html` 拆组件。
- 插画优先内联 SVG，方便按动物结果切换颜色变量。
- 页面组件和分享卡组件分离，方便后续 `html2canvas` 或 Canvas 导出。
- 先用 4 只代表动物跑通链路，剩余 12 只可先用统一占位，但后续必须补差异化动作/道具。
- 分享卡需要明确 3:4 安全区和 1:1 裁切安全区。
- 结果卡必须保留「一句话钩子 / 朋友锐评 / 自我认领短句 / 关键词贴纸」四个传播结构。
