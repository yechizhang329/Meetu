# 社交动物测试 XHS 首发文案 v2

## 1. 发布定位

这条不是产品发布，也不是 H5 功能介绍。

它要包装成一条“朋友之间会互相转发审判”的测试内容：

> 一个会让朋友认领你的社交动物测试。

核心数据目标：
- **点击**：封面一句话让用户觉得“这可能在说我”。
- **评论**：用户回来报动物名 / @朋友 / 说“这句是我室友”。
- **转发**：发群里让朋友认领，而不是单纯自己测完。
- **停留**：正文短、像人话、每段都有一个梗点，不解释产品。

## 2. 标题

### 最终推荐

**别测，会被朋友认领**

理由：
- 有轻微反向劝阻，适合小红书信息流；
- “朋友认领”直接指向传播动作；
- 不剧透测试内容，但给出结果后的社交场景。

### 备选

1. **测完会被朋友认领**
2. **你的群聊人格藏不住**
3. **这测试有点冒犯**
4. **测完我沉默了**

## 3. 正文最终版

```text
我本来只是随手点了一下。

结果它说我：
不是失踪，是进入省电模式。
白天勿扰，晚上才上线。
出门前灵魂要开两次会。

行。
它最好不是在偷看我群聊。

这不是 MBTI，也不是心理咨询。
就是 12 个大学生小场景：
有人约饭你怎么回，
群里突然安静你救不救，
认识新人你是开屏还是装死。

测完会给你一只社交动物。
最损的是结果页有一句“朋友锐评”。

那句话不是给你看的。
是给你朋友截图审判你的。

入口放评论区。
测完别急着认，先发群里，
看谁第一个说：这不就是你？
```

## 6. 评论区引导备用句

用于评论区 30-60 分钟内补互动，不建议一次性全发。

1. `省电猫先集合一下，我知道你们看到了但不一定会回。`
2. `如果你朋友测出来是临门鸽，建议约饭时间提前骗他半小时。`
3. `看到“朋友锐评”那一栏别生气，那是这测试唯一的灵魂。`
4. `评论区可以只报动物名，不用解释，懂的人会自己认领。`
5. `如果小红书打不开链接，复制到浏览器；它不是 App，不用下载。`

## 7. 配图文案对齐

建议封面单图只放：

- 主标题：`别测，会被朋友认领`
- 便签梗：`白天勿扰` / `脑内弹幕` / `出门启动失败` / `已读不回理由` / `微信营业时间未知`
- 副标题：`12个小场景 · 看你是哪只社交动物`
- 弱品牌：`Meetu · 社交动物测试`

封面不放 16 个动物名，不放二维码，不放完整结果页截图。
