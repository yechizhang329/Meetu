## 2. 发布步骤

### Step 1：上传图片

小红书 App 或 Web → 发布图文 → 选择图片，**严格按以下顺序上传 4 张**：

1. `01-cover.png`
2. `02-result-card.png`
3. `03-roast.png`
4. `04-cta.png`

封面就是 01。

### Step 2：标题

```
今日动物园挂牌：我
```

或备选（视账号风格）：

- `朋友锐评：已生成`
- `今天动物园挂的是我`

### Step 3：正文（建议 50-150 字，不剧透）

```
本来只是随手点了一下。

挂牌写着：开屏孔雀。
朋友锐评写着：你不是要 C 位，你就是自带光源。
我：？

入口在评论区。
你测完回来报品种，看看谁是孤品。
```

### Step 4：置顶评论（关键入口）

```

测完别急着认，先发群里看看。
```

`?source=xhs` 会让 H5 入口页贴纸自动切成 `小红书来的 / 先别剧透`（task #11 已上线）。

## 3. 4 张图设计意图

| 顺序 | 名称 | 核心钩子 | XHS 数据指标 |
|---|---|---|---|
| 01 | cover | `今日动物园挂牌：我` 130px 大字 + 红章「朋友锐评：已生成」+ 黄底「别当熟人面点开」 | 点击率 |
| 02 | result-card | 「开屏孔雀」品种展示 + 800px 真实分享卡（占画布 74%） | 停留 / 收藏 |
| 03 | roast | 「朋友锐评：你不是要 C 位，你就是自带光源。」+ 「自我认领：安静坐着不行，我会自己消失。」 | 收藏 / 转发 |

第 4 张是评论钩子，不在图里放任何外链/二维码（XHS 算法不喜欢图内站外引流）。
