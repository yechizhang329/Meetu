# 微信公众号首篇视觉 Brief v1

## 任务定位

公众号第一篇围绕「社交动物测试」展开。文章不是产品介绍，也不是严肃心理测评，而是一篇短、损、有梗的测试传播贴。

视觉任务不是做小红书信息流封面，而是服务公众号阅读：打开文章第一眼要有“这测试有点贴脸”的感觉，读到结尾要愿意点 H5 / 发给朋友。

## 视觉关键词

- 桌面便签动物园
- 群友证据板
- 强黑线、便签、圈画、聊天气泡
- 抽象社交动物，不对应 16 个具体结果
- 有一点侵犯性，但像朋友互损，不是羞辱审判

## 风格边界

### 可以

- 暖纸背景、黑线、手写圈画；
- 便签词、证据标记、群聊弹幕；
- 抽象疯癫一点的社交动物；
- 文案有轻微反向劝阻和朋友锐评感。

### 不要

- cute / kawaii / 儿童绘本 / 萌宠贴纸；
- 16 个动物全展示；
- QR code；
- 大 logo 或产品广告感；
- 小红书九宫格/长图解释风。

## 交付图 1：公众号头图 / 封面图

- 文件：`微信公众号首篇-头图-v1.png`
- 尺寸：`900×383`
- 用途：公众号封面与文章头部视觉。
- 主文案：`别测，会被群友拿来当证据`
- 便签词：`省电模式` / `装死中` / `出门启动失败` / `朋友锐评` / `这不就是你？`
- 画面：一只未鉴定抽象社交动物被便签/聊天气泡围住。
- 设计重点：在公众号封面裁切中仍能读到主标题；动物和便签辅助气氛，不抢标题。

## 交付图 2：文末 CTA 图

- 文件：`微信公众号首篇-文末CTA-v1.png`
- 尺寸：`900×500`
- 用途：文章末尾，引导点击 H5 / 阅读原文。
- 主文案：`测完先别破防，发群里看看。`
- 弱品牌：`Meetu · 社交动物测试`
- 画面：一张“结果卡/证据卡”被群聊便签围住，动物只做抽象符号，不展示具体结果。
- 设计重点：不像广告按钮，像文章自然结尾的梗图 CTA。

## 文案语气

保持 H5 当前语气：

- 低承诺：`测着玩，但可能有点像`；
- 朋友锐评：`这不就是你？`；
- 群聊传播：`发群里看看`；
- 不专业、不鸡汤、不营销。
