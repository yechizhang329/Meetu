## 2. 发布操作（按编辑器情况选一条路径）

### 路径 A：⭐ 推荐 —— `copy-rendered.html` 一键复制渲染后内容

**适合：公众号官方编辑器（默认富文本模式）、大部分第三方编辑器**

1. 用浏览器（Chrome/Safari）打开 `copy-rendered.html`
2. 点页面顶部蓝色按钮 **"复制到剪贴板"**（或 **"全选下方文章"** + ⌘/Ctrl + C）
3. 切到公众号后台 → 新的创作 → 图文 → 光标点进正文 → ⌘/Ctrl + V 粘贴
4. 粘贴后样式（标题、便签卡、对话气泡等）会带过来
5. 选中两张图（头图、文末图）→ 替换图片 → 上传 `微信公众号首篇-头图-v2.png` / `微信公众号首篇-文末CTA-v2.png`
6. 后台填标题/摘要/封面/原文链接（见 §4）

> ⚠️ **关键提醒**：不要复制 `copy-rendered.html` 这个 HTML 文件本身的源码。要打开页面，复制**渲染后的内容**。

### 路径 B：第三方编辑器有"源码模式"按钮

**适合：壹伴 / 135编辑器 / 秀米 / 任何有 `<>` HTML 源码切换按钮的工具**

1. 打开第三方编辑器，切到源码模式（通常是 `<>` 或 "HTML"）
2. 复制 `article-fragment.html` **全部内容**（从 `<section>` 到 `</section>`）
3. 粘贴到源码区
4. 切回可视模式 → 直接同步到公众号

### 路径 C：纯富文本兜底

**适合：公众号或第三方编辑器都不接 HTML，只能手工排版**

按 `plain-text.md` 一段一段粘贴，用编辑器自带的"加粗 / 引用 / 居中 / 高亮"近似还原视觉。

## 6. 公众号环境兼容点

- 全 inline style；零 class / 外链 CSS / JS / SVG / `<style>` 标签
- 图片宽度 `100%` 自动适配公众号容器
- 375 宽手机优先；字号 16-17px，行高 1.82
- "阅读原文"按钮文案是平台默认的 4 字，不可改 → 文中已做了 CTA 卡 + 🖐 示意 + 最底部"直达链接"三重兜底
- 不含：二维码 / 下载 / 加群 / 报名 / 大 logo
