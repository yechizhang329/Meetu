## 2. 发布操作（5 分钟）

### Step 1：上传图片素材

登录公众号后台 → 内容与互动 → 素材管理 → 图片素材 → 上传：

1. `Meetu/社交动物测试H5/07-传播包/微信公众号首篇-头图-v2.png`（900×383，头图）
2. `Meetu/社交动物测试H5/07-传播包/微信公众号首篇-文末CTA-v2.png`（900×500，文末 CTA 图）

上传完，每张图都可以拿到一个 `https://mmbiz.qpic.cn/...` 的永久链接。把链接先复制出来备用。

### Step 2：替换 article.html 里的 2 处图片 URL

用文本编辑器打开 `article.html`，把：

- `REPLACE_WITH_WECHAT_MATERIAL_URL_HEADER` → 头图的 mmbiz 链接
- `REPLACE_WITH_WECHAT_MATERIAL_URL_FOOTER` → 文末 CTA 图的 mmbiz 链接

### Step 3：新建图文消息 → 粘贴 HTML

公众号后台 → 内容与互动 → 草稿箱 → 新的创作 → 写正文。

把 `article.html` 里 `<body>` 标签里的内容（从 `<section ...>` 到末尾 `</section>`）整段复制 → 粘贴到公众号编辑器的"源码"模式（不同编辑器位置不同，通常在右上角或顶部工具栏有"</>"或"HTML"图标）。

粘贴后切回"可视模式"检查渲染。

### Step 4：填标题/摘要/封面

- **标题**：`今日动物园挂牌：你`
- **作者**：Meetu / 觅遇社 / 按实际
- **摘要**（60 字以内，摘要会出现在朋友圈/搜索预览）：
  ```
  朋友局里总有那么一类动物：白天装死 晚上上线 / 出门前灵魂开两次会 / 脑内弹幕从不停。这次我们把他们挂牌了。
  ```
- **封面图**：用 Step 1 上传的头图
- **原文链接**（关键，最底部）：
  ```
  https://a.meetu.asia/index.html?source=wechat_mp
  ```
  **注意**：`?source=wechat_mp` 会让 H5 入口页顶部贴纸自动切换成 `公众号来的 / 先别急着装死`（工程 task #11 已做，已上线）。

### Step 5：预览 → 群发/定时

手机预览，检查：

- 头图首屏可见；
- 4 行挂牌段落（今日展出/品种未知/习性可疑/朋友锐评待生成）视觉高亮；
- 便签吐槽卡（黄色歪贴）；
- "朋友锐评" 黄色高亮；
- "这不就是你？" 深色对话框；
- 文末 CTA 卡 + "阅读原文" 按钮；
- 点"阅读原文"跳 H5，入口页顶部写 `公众号来的 / 先别急着装死`。

一切正常后发出。

## 4. 公众号环境注意

- 公众号编辑器会剥离部分 class / 外链 CSS → 已全部用 inline style
- 没有 JS / 动效 / 外链字体
- 图片宽度 `100%` 自动适配公众号容器
- 375 宽手机优先；字号 16-17px，行高 1.82
- "阅读原文"按钮文案是平台默认的 4 字，不可改。文中已做了一个 CTA 卡 + 🖐 示意 + 最底部"直达链接"兜底
- 不含：二维码 / 下载 / 加群 / 报名 / 大 logo

---

## 5. 后续迭代

内容/视觉调整：

- 改文案 → 直接编辑 `article.html` 里的中文，不用动样式
- 改色 → 改 inline style 里的 hex（或对着 Phoebe2 spec §基础 Token）
- 加/删段 → 保持 `<section>` 或 `<p>` 结构；不要引入 `<div class="...">` 否则公众号可能剥掉

**重要**：禁止引入外链 JS / 外链 CSS / `<svg>` / `<style>` 标签；公众号编辑器会剥离。
