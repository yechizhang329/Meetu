## 2. 推荐路径（5 分钟）

### Step 1：浏览器打开 `copy-rendered-hook.html`

直接双击 / 拖到 Chrome / Safari 打开。

### Step 2：点黄色按钮 `复制到剪贴板`

把渲染后的富文本（含样式）写入剪贴板。

### Step 3：公众号后台 → 新的创作 → 图文 → 正文 ⌘/Ctrl+V

### Step 4：填后台 4 个字段 + 替换 1 张结果图

| 字段 | 内容 |
|---|---|
| 标题 | `今日动物园挂牌：你` |
| 摘要 | `朋友局里总有那么一类动物：白天装死 晚上上线 / 出门前灵魂开两次会 / 脑内弹幕从不停。` |

**关键：粘贴后正文里有一张"弹幕羊驼"结果图，需要做：**
1. 把 `Meetu/社交动物测试H5/07-传播包/微信公众号首篇-弹幕羊驼结果图.png` 上传到公众号素材库
2. 选中正文里那张结果图 → 替换图片 → 选刚上传的素材
3. 这是核心传播载体，**不能漏**。用户点进文章一眼能看到"我点进去能拿到一张这样的卡"，才会有点击动机

> ⚠️ 正文里**没有**任何按钮/外链。用户进 H5 = 公众号原生「阅读原文」。这条字段必填。

## 5. 关键约束

- 全 inline style，零 class / 外链 CSS / JS / SVG / `<style>`
- 强制浅色背景容器避免深色模式塌
- 字号 32 → 24 → 17 → 16 → 14 严格分层
- 红章「朋友锐评：已生成」`#ff5a3d` + -2deg 营造章戳感
- 「别当熟人面点开。」黄底 24px 是首屏唯一最大欲望点
- 三条结果摘录用浅纸底 `#fffdf5` + 橙色左边线，不卡片化
- 不含：二维码 / 下载 / 加群 / 报名 / 假按钮 / 正文外链
