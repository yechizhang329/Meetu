## 2. 推荐发布路径（5 分钟）

### Step 1：浏览器打开 `copy-rendered-simple.html`

直接双击文件 / 拖到 Chrome / Safari 打开。

### Step 2：点顶部黄色按钮 `复制到剪贴板`

会把渲染后的富文本（含样式）写入剪贴板。

### Step 3：切到公众号后台 → 新的创作 → 图文 → 正文 ⌘/Ctrl+V

样式（标题字号、引用块、横线、加粗）会带过来，是公众号原生友好的简洁排版。

### Step 4：替换 2 张图

正文里有两个占位图（头图、文末 CTA 图）。选中 → 替换图片 → 上传：

```
Meetu/社交动物测试H5/07-传播包/微信公众号首篇-头图-v2.png       (900×383)
Meetu/社交动物测试H5/07-传播包/微信公众号首篇-文末CTA-v2.png    (900×500)
```

### Step 5：填后台 4 个字段

| 字段 | 内容 |
|---|---|
| 标题 | `今日动物园挂牌：你` |
| 摘要 | `朋友局里总有那么一类动物：白天装死 晚上上线 / 出门前灵魂开两次会 / 脑内弹幕从不停。这次我们把他们挂牌了。` |
| 封面图 | 用 Step 4 上传的头图 |
| **原文链接** | `https://a.meetu.asia/index.html?source=wechat_mp` |

> ⚠️ **正文里没有任何按钮/外链。** 用户进入测试 = 点页面底部公众号原生「阅读原文」。所以"原文链接"这个字段必填，不能漏。

### Step 6：手机预览 → 群发

## 3. 简洁版做了什么

对比旧版（`copy-rendered.html` 桌面便签风），简洁版：

| 旧版（桌面便签风） | 简洁版（公众号原生友好） |
|---|---|
| 多个黑边纸卡片 | 仅 1 处灰色小标 + 1 处橙色引用 |
| 黄色歪贴便签 | 普通段落，行高放宽 |
| 黑底假按钮（不可点） | 完全去掉，只留一句"点下方阅读原文" |
| 朋友锐评胶囊 + box-shadow | 普通加粗 |
| 朋友回复深色气泡 | 橙色左边线引用块 |
| 底部"直达链接 a.meetu.asia" | 删除 |
| 段落字号 17，line-height 1.84 | 同样 17，line-height 1.95（更松） |
| 暖纸底强 | 白底 / 浅灰横线分段 |

视觉重点只剩 2 个：
1. 开头"今日展出 / 品种未知 / 习性可疑 / 朋友锐评待生成"小信息块
2. 中段「这不就是你？」橙色引用高亮

其他都是普通段落 + 横线分段，公众号深色模式下也不会塌成黑块。

## 5. 关键约束

- 所有路径的"阅读原文"链接都通过公众号后台字段设置，不在正文里做按钮
- 正文不含：二维码 / 下载 / 加群 / 报名 / 大 logo
- 简洁版按 Jonathan 反馈调整：去复杂 HTML 卡片，去深色按钮，去底部直达链接，去多色高亮
- 字号 17px / 行高 1.95 保证手机/深色模式下都可读
- 全 inline style，零 class / 外链 CSS / JS / SVG / `<style>` 标签
