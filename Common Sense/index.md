# 觅遇社 Common Sense — 索引

> Common Sense是觅遇社的共享认知系统，存储所有经过打合确认的团队共识。
> 它是所有产品决策、内容产出、设计执行的认知基础。
>
> **管理人：** Fiona (PM)
> **更新流程：** Agent提出输入 → 打合讨论 → PM评估 → 确认为共识 → 写入
> **数据流向：** Common Sense → Agent Memory（单向提供认知基础）
> **原则：** 当新指令与Common Sense矛盾时，PM必须指出并推动澄清
