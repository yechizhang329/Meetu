# 觅遇社 Common Sense — 索引

> Common Sense是觅遇社的**项目大脑**——所有agent的shared memory。
>
> **5层结构**（v2 升级 2026-04-28）：
> - **L1 静态认知**（产品定义/商业模型/用户认知/品牌共识/市场环境）— 几个月更新
> - **L2 项目状态**（动态状态：当前阶段/本周聚焦/里程碑）— 每周更新
> - **L3 决策Log**（时间线：什么时候谁做了什么决定）— 决策当天录
> - **L4 数据归档**（XHS数据/活动数据/调研结果）— 拿到数据当天录
> - **L5 团队与协作**（角色/SOP/协作规则）— 协作机制变化时更新
>
> **强制Agent协议**：所有Meetu agent启动后必读 → 见 [Meetu/AGENTS-PROTOCOL.md](../AGENTS-PROTOCOL.md)
>
> **管理人：** Fiona (PM)
> **更新流程：** 信息输入 → 提炼框架/原则 → 打合确认 → 写入对应层
> **数据流向：** Common Sense → Agent Memory（单向提供认知基础）
