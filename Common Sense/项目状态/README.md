# 项目状态

> 项目级**动态状态**——回答"觅遇社今天在哪"。
> 跟"产品定义/产品现状"区分：那个回答"产品是什么" 这个回答"项目运营到哪一步"。
>
> **更新责任：** PM (Fiona)
> **更新频率：** 阶段切换或重大节点时更新；每周对照一次本周聚焦

## 跟其他CS层的关系

- **L1 产品定义/商业/用户**：静态认知 几个月才更新一次
- **L2 项目状态**（本目录）：动态状态 阶段切换时更新
- **L3 决策Log**：时间线 决策发生时立即记录
- **L4 数据归档**：每次拿到新数据时更新
- **L5 团队与协作**：相对稳定 协作机制变化时更新

L2跟L3互相参照——决策驱动状态变化 状态变化记录在决策log。
