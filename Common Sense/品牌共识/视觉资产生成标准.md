# 视觉资产生成标准

> 本文档定义觅遇社品牌视觉资产的生成规范，适用于所有通过 AI 生图工具（Nano Banana 等）产出的视觉素材。
> 所有视觉资产产出前必须对照本文档检查，确保品牌一致性、生产流程合规、落地可用。
> 本文档应根据每次资产产出的反馈动态更新。

---

## 1. 生产模型

### PNG-first 原则

所有视觉资产生成必须采用 **PNG master + prompt + 现有物料叠加** 的模式：

- **不允许**纯文字 prompt 从零生成 — 必须搭配已有的品牌视觉参考图作为输入
- **目标**不是格式统一，而是一致性、美观性、高复用
- 每条 prompt 必须明确标注需要搭配哪些类型的参考图（如 brand color guide / mascot master / sticker sheet）

### 参考图类型

| 类型 | 用途 | 说明 |
|------|------|------|
| 品牌色彩/字体指南图 | 确保色系和字体方向一致 | 提供给生图工具作为风格锚定 |
| 觅遇仔 master PNG | mascot 变体生成的唯一权威源 | 任何涉及觅遇仔的生成必须以此为 primary reference |
| 已有贴纸表情包图 | mascot 变体的风格参考 | 展示已批准的变体渲染风格 |
| 现有品牌主视觉/广场图 | 新资产与现有资产风格对齐 | 确保新旧资产视觉上可共存 |
| UI 组件库图 | 确保装饰元素与 UI 系统兼容 | sticker、badge 等需要能嵌入实际页面 |

### prompt 书写规范

- prompt 必须**跨平台可执行** — 不引用具体仓库文件路径或 Markdown 文件名
- 所有品牌要求以文字形式完整表述，不依赖外部文档
- VISUAL INPUT 段使用通用描述（如"approved mascot master PNG"），而非具体文件名
- 每条 prompt 标注 "Will be used in" 明确落地场景

## 2. 色彩规范

### 品牌主色

- **#FF7422 暖橙** — 品牌锚定色，所有资产必须有暖橙元素存在

### 允许的辅助色

| 色彩 | 使用场景 |
|------|---------|
| 奶油色 / cream | 通用背景、柔和衬底 |
| 可可棕 / cocoa brown | 文字、深色卡片、温暖质感 |
| 柔粉 / blush pink | 女生专场、温柔氛围 |
| 淡紫 / soft lavender | 女生专场主色调 |
| 蓝灰 / muted blue-gray | 规则、收费、信任类页面的理性感 |
| 暖紫 / warm purple | 少量装饰点缀 |

### 不允许的色彩

- **薄荷绿 / mint green** — 不属于品牌色系，已在 prompt 校准中移除
- 荧光色 / neon — 与校园温暖调性冲突
- 深黑 / pure black — 过于沉重，不符合年轻感

---

## 3. 觅遇仔（Mascot）生成规则

### 角色一致性

- 所有觅遇仔变体**必须**以官方批准的 master PNG 为唯一权威源
- **不允许**靠文字描述重新想象角色设计
- 必须保留：白色身体、棕色面部面罩、橙色围巾、已批准的双拼图块逻辑
- 不允许修改：身体结构、面部特征、拼图块数量或形态

### 变体生成要求

- 每个变体 prompt 必须搭配 master PNG 作为 primary reference
- 同时搭配已批准的贴纸表情包图作为 style reference，展示已有的变体渲染风格
- 保持紧凑可爱比例、粗描边、干净轮廓
- 风格要求：精致、有品质感，**不低幼、不通用 AI mascot 风**

### 当前已规划变体

- 欢迎 / 招手版 — onboarding、欢迎 banner
- 举牌 / 引导版 — CTA、规则说明
- 庆祝 / 齐了版 — 成功状态、人齐通知
- 温和提醒版 — FAQ、费用说明、信任区

## 4. 文字规范

### 语言优先级

- **中文为主** — 视觉资产中的文字内容以中文为主体
- **英文为辅** — 仅用于少量装饰性点缀，不能反客为主

### 中文文案标准

- 优先使用搭子文化体系词汇：搭上、搭子、齐了、主理人、带搭、神搭
- 语感对标大学生日常口语，不是广告文案
- 短、有力、有画面感

| 适用场景 | 推荐文案 |
|---------|---------|
| 行动号召 | 搭上就走 / 齐了出发 / 一起搞一场 |
| 信任建设 | 放心来 / 放心搭上 / 费用透明 |
| 品质感受 | 真的好玩 |
| 身份认同 | 搭子认证 |
| 规则透明 | 规则讲清 / 先看再搭 |

### 英文装饰文案标准

- 仅用于编辑感 / 设计点缀，不承担主要信息传达
- 保持短小、图形化、高辨识度

| 推荐文案 | 用途 |
|---------|------|
| Nice to Meetu | 品牌签名 |
| trust comes first | 信任标签 |
| see / trust / join | 路径标签 |
| go with it | 行动装饰 |
| host energy | 主理人相关 |

### 禁用文案

- 参照语言体系废弃词汇表：不用"诚意金"、"开搭"、"一场遇"等
- 参照语言与表达习惯禁用词：不用"亲"、"小伙伴"、"您"、"赋能"等
- 不使用微商腔、官方腔、说教腔

## 5. 风格基线

### 整体方向

- **年轻、校园、轻松、可信**
- 优先 illustrated / hybrid graphic-ad / editorial collage / stylized UI-visual 路线
- **不走** generic stock photo 路线
- **不走** 夜店化 / 过度商业化 / 通用广告风

### 装饰系统语言

资产产出应服务于页面装饰系统，包括但不限于：

| 元素类型 | 说明 |
|---------|------|
| tilted badges | 倾斜徽章标签 |
| capsule trust tags | 胶囊信任标签 |
| speech bubbles | 对话气泡 |
| route / path dot strips | 路径点线条 |
| CTA labels | 行动号召微标签 |
| paper-tape corner tags | 纸胶带角标 |
| note style labels | 便签风格标签 |

### 搭子社交语境

- 贴纸、标签等装饰系统应体现"搭子"社交场景：**随意的、群体的、活动驱动的**
- 不是约会 / 1v1 聊天场景
- 融入微妙的连接感和运动感：路径线、连接点、桥接形状、箭头

---

## 6. 落地可用性

### 输出格式要求

- 默认考虑后续可裁切为：Banner / H5 hero / 卡片 / sticker / badge
- 优先服务实际页面 / Banner / H5 / Post 场景，不做泛泛"好看图"
- mascot 变体需要透明背景友好，便于嵌入不同页面

### 场景适配

- 每个资产在产出时需明确标注适用场景
- 不做"万能图"，每个资产有明确的页面/模块归属

### WeChat 小程序 CMS 兼容

- 用于 CMS 子页的装饰资产需要兼容微信富文本编辑器限制
- 微信 CMS 会剥离：`<style>` 标签、CSS class、`<svg>` 元素
- 所有样式必须用 inline style 实现

## 7. 质量检查维度

每次视觉资产产出后，按以下 5 个维度进行评估：

| 维度 | 检查内容 |
|------|---------|
| 品牌视觉一致性 | 色系是否在允许范围内？觅遇仔是否与 master 一致？ |
| 语言体系合规 | 文字是否用了正确的搭子词汇？是否中文为主？是否有禁用词？ |
| 用户认知匹配 | 目标用户（18-25岁大学生）能否产生共鸣？语感是否自然？ |
| 生产流程合规 | 是否遵循 PNG-first 模型？prompt 是否跨平台可执行？ |
| 实际落地可行性 | 能否直接用于目标页面/模块？裁切比例是否合理？ |
