# 品牌标准

### 品牌命名
- 中文：觅遇社 | 英文：Meetu | Mascot：觅遇仔
- 历史名称"觅途"已弃用，禁止在新内容中出现

### 品牌语气
像一个会玩的学长/学姐在跟你说话——亲切、直接、有态度，不端着不低幼，不模仿小红书网红体。

### 核心品牌资产
- Mascot master: `设计语言参考/Meetu元素参考/0 Meetu mascot master.png`（唯一权威源）
- 品牌主色: #FF7422（暖橙）
- 完整标准详见: `设计语言参考/品牌语言与术语标准.md`
- **Mascot生产模型（PNG-first）：**
  - 目标不是格式统一，而是一致性/美观性/高复用
  - 不同场景变体通过 `PNG master + Nano Banana prompt + 现有物料叠加` 产出
  - 小程序内直接使用PNG

### 设计语言共识
- 视觉方向：年轻、校园、轻松、可信
- 不走夜店化/过度商业化UI路线
- 信息页/子页可借鉴Soul的信息节奏，但不照搬其深色成人感
- 模板允许多人格家族，不要求所有页面长成一套壳

### 内容导向（2026-04-04 @jonathanzhang：不存在硬性红线，只有导向问题）
- 不主动接触餐饮商家（2026-04-03 @DavidC确认）
- 平台调性不往"约炮平台"方向走——恋爱是年轻人社交的自然动力，不刻意回避，但要把控方向感。可参考Soul的处理方式
- 避免使用广告法违规绝对化用语
- "免费"表述不准确（所有活动都有费用，最低¥0.01门槛）——这是事实纠正，不是调性导向

### 事实性纠正（硬性，与导向无关）
- "诚意金"概念已废弃——活动费用是真实定价，不是押金/deposit
- "觅途"已废弃，不在新内容中出现
