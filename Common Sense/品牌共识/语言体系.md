## 定位

**自然语言体系** — 不给关系贴标签 用大白话/口语表达 让用户自然使用 不造概念。
（v1原"搭子文化体系"定位已废弃 详见废弃词汇表）

## 核心原则

- 不发明专有词——哪个自然用哪个
- 自然口语优先——大学生怎么说我们怎么用
- 费用不需要单独命名——活动定价就是定价
- 不给关系贴标签——不用"搭子""觅友"等关系类专有词

## 词汇标准

| 场景 | 词汇 | 用法示例 | 说明 |
|------|------|---------|------|
| 报名参加 | **报名 / 加入** | "报名了周六密室 ¥60" | 自然语言 |
| 伙伴 | **大家 / 一起的人 / 同行的人** | "大家都到齐了" | 不贴关系标签 |
| 发起活动 | **开一场 / 发起** | "开了一场周六剧本杀" | 自然口语 |
| 人齐 | **齐了** | "齐了！出发" | 大白话 |
| 推荐 | **推荐 / 这个主理人值得来** | 自然语言 | 不造新词 |
| 到场 | **到了** | 自然语言 | 不造新词 |
| 用户身份 | **大学生 / 同学** | "同学们" | 自然身份称呼 |
| 主理人 | **主理人** | — | 保留 已有认知和身份感 |
| 活动定价 | 直接显示价格 | "¥60/人"或"¥0.01/人" | 不单独命名费用概念 |
