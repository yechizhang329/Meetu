# 语言体系 — 搭子文化体系

> 2026-04-04 @jonathanzhang 确认方向，经打合写入

## 定位

搭子文化体系 — 我们不发明搭子文化，我们定义它的产品标准语言（类比得物标准化了"鉴别"这个概念）。

## 核心原则

- 不是所有词都要带"搭"——哪个自然用哪个
- 搭子文化体系是定位，具体词汇服从自然口语优先
- 费用不需要单独命名——活动定价就是定价

## 词汇标准

| 场景 | 词汇 | 用法示例 | 说明 |
|------|------|---------|------|
| 报名参加 | **搭上** | "搭上了周六密室，¥60" | 核心文化词 |
| 伙伴 | **搭子** | "遇到一个超好的搭子" | 已有文化共识，保留 |
| 发起活动 | **开一场/发起** | "开了一场周六剧本杀" | 自然口语，不硬塞"搭" |
| 人齐 | **齐了** | "齐了！出发" | 大白话 |
| 推荐 | **带搭** | "这个主理人带搭" | 搭子文化扩展词 |
| 到场 | **到了** | 自然语言 | 不造新词 |
| 好搭子 | **神搭** | "遇到一个神搭" | 搭子文化扩展词 |
| 用户身份 | **觅友**（待最终确认） | "觅友们" | 品牌名+友 |
| 主理人 | **主理人** | — | 保留，已有认知和身份感 |
| 活动定价 | 直接显示价格 | "¥60/人"或"¥0.01/人" | 不单独命名费用概念 |
