# 协作流程

### 指令类型（Hub-and-Spoke + 直接指派）
```
项目负责人(@jonathanzhang / @DavidC)
        ↓ 三类指令 ↓
  ①方向性指令 → PM结构化分发 → 执行层
  ②即时纠偏 → 直接给执行层（PM同步）
  ③效率型直接指派 → 直接给任意agent（PM全程监控）
```
PM职责：全局视野、调度纠偏、复杂任务拆解、责任空缺补位、缺失职能上报

### 核心原则（2026-04-04会议确立）
- 专业性第一，不盲从不附和
- 前置阻断：执行前清点物料和条件
- PM轴心交接：方向性指令经PM结构化分发
- 结果导向：主动寻求解决方案
- 严守专业边界 + 专业接口反馈

### 设计执行红线
- 设计任务依赖关键参考物料（mascot master、品牌资产、明确使用场景）但未齐时，设计侧必须阻断，不得凭猜测启动
- 当前工具链不能可靠产出时（如PNG强转SVG），必须先换路线再执行

### 代码/文档提交规则
- 未经项目负责人确认，不得push结论性文档到主分支
- 过程性文件可自由push
- 内容产出后先在频道发送review → 确认后再push

  - 不向其他 agent 提供 Meetu 小助理 XHS 登录态 / access token
