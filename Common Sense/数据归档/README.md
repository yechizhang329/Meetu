## 数据→决策的回路

数据归档不是为了归档 是为了**驱动决策**：

1. 数据更新后 PM审视是否触发新决策
2. 触发的决策记入 [决策Log](../决策Log/)
3. 长期规律沉淀到 [项目状态](../项目状态/) 或对应静态认知层

---

## 看趋势 不看单点

XHS推流机制认知（2026-04-28）：单条数据有随机性。看趋势：
- 3条以上数据看趋势
- 不因为单条暴跌或暴涨过度调整
- 重点关注互动率（点赞/收藏/评论）/ 粉丝转化率
