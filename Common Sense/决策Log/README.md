## 记录模板

每条决策按以下格式：

```
### [YYYY-MM-DD] 简短标题

**触发**：什么事件促发这个决策
**决策**：决定了什么
**决策人**：谁拍板（决策层 / PM）
**影响范围**：影响哪些后续工作
**根据**：基于什么数据/洞察/原则
```
