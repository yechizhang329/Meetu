# Meetu 社交天气 PRD 重启 v0.1

> 状态：PM 方向收口稿。目的不是复刻排版小动物，而是回到 Meetu 的关系启动场景，定义一个统一、有传播性、可复用、能承接线下小局的状态表达功能。

---

## 1. PM 判断

这次不再围绕“纸条 / 动物 / 值班室 / 卡片”打转。

Meetu 的底层任务是：

> 帮大学生用低压力方式发出关系信号，并把信号转成聊天、邀约、小局和线下见面。

所以这个功能不能只是“情绪输出物”，而应该是：

> **用户今天的社交天气。**

它表达的不是“我是什么人格 / 我今天什么心情”，而是：

> 今天别人应该怎么靠近我、约我、带我玩。

这才是 Meetu 自己的场景。

---

## 2. 为什么是“社交天气”

### 2.1 它天然高频

天气每天都能看；状态每天都不同。

用户每天可以生成一次：

- 今天适合出去吗；
- 今天能量够不够；
- 今天能不能被约；
- 今天适合什么局；
- 今天别人怎么叫我不尴尬。

这比一次性测试更可复用。

### 2.2 它天然低压力

“我今天社交天气不太好”比“我不想社交”轻。

“今日可被捡走”比“谁来约我”轻。

天气是外部状态，不是人格诊断。用户可以否认，也可以开玩笑。

### 2.3 它天然能被朋友接住

朋友看到后能直接接：

- “那我来捡你。”
- “今天你适合吃饭局。”
- “我也是低电量多云。”
- “嘴硬雷暴是吧，懂了。”

这比“朋友鉴定区”自然。

### 2.4 它能回到 Meetu

每种天气都能对应真实小局：

- 低电量多云 → 低压饭局 / 散步 / 自习；
- 想出门无风向 → 缺 1 人的小局；
- 嘴硬雷阵雨 → 熟人二次邀请；
- 社交晴天 → 新朋友局 / 城市活动；
- 后台过载雾 → 安静陪伴局。

这不是泛情绪表达，而是 Meetu 的关系入口。

---

## 3. 外部案例只抽方法，不抽外壳

### 3.1 排版小动物给的方法

不是“做手写纸条”。

它教的是：

- 整体语言必须统一；
- 产品边界要轻；
- 输出物必须像用户自己的表达；
- 小角色要服务表达，不抢主体。

### 3.2 网易云 / Spotify 给的方法

不是“做音乐卡”。

它教的是：

- 用户愿意借第三方说自己；
- 分享的是状态和身份，不是产品能力；
- 视觉要让用户觉得“这是我”。

### 3.3 微信状态 / 表情包给的方法

不是“做状态文案”。

它教的是：

- 轻状态可以高频；
- 朋友接话成本要低；
- 角色/符号能替用户挡尴尬。

## 4. 产品定义

### 4.1 暂定名

推荐：**Meetu 社交天气**。

备选：

- 今日社交天气
- 今天适合怎么被约
- 今日可约天气
- Meetu 天气台

### 4.2 一句话定义

**Meetu 社交天气**是一个大学生日常社交状态生成器：用户用 10 秒生成一张“今天适合怎么被靠近 / 怎么被约 / 适合什么局”的社交天气图，发出去让朋友自然接话，并可承接到 Meetu 的低压小局和搭子邀请。

### 4.3 产品不是

- 不是心理测试；
- 不是人格卡；
- 不是情绪纸条生成器；
- 不是小动物 IP 图鉴；
- 不是排版小动物复刻；
- 不是纯分享图工具。

### 4.4 产品是

> 一个可分享的社交信号层。

它连接：

状态表达 → 朋友接话 → 低压邀约 → Meetu 小局。

---

## 5. 核心输出

输出不是“结果卡”，而是“天气状态”。

每张图只回答三件事：

1. 我今天的社交天气是什么；
2. 别人怎么靠近我比较安全；
3. 适合什么低压动作。

### 5.1 示例 A：低电量多云

```text
今日社交天气
低电量多云

适合：吃饭 / 散步 / 坐着发呆
不适合：被拷问 / 临时大局 / 让我做决定

如果你有一个不用动脑的局
可以顺手把我捡走
```

朋友接法：

- “我来捡你。”
- “吃饭局，走。”
- “不用动脑，我安排。”

Meetu 承接：低压饭局 / 散步局 / 自习局。

### 5.2 示例 B：想出门但无风向

```text
今日社交天气
想出门，但无风向

想去点什么地方
但不想查攻略
不想当队长
不想决定吃什么

谁有现成安排
我可以加入一下
```

朋友接法：

- “我正好缺一个。”
- “你来，我安排。”
- “别装，你就是想被带。”

Meetu 承接：缺 1 人小局 / 同城活动 / 周末局。

### 5.3 示例 C：嘴硬雷阵雨

```text
今日社交天气
嘴硬雷阵雨

我说不去
不一定是真的不去

你可以再问一次
但要问得像顺口
```

朋友接法：

- “那我顺口问一下。”
- “出来。”
- “懂了，你等人喊。”

Meetu 承接：熟人二次邀请 / 小局补位 / 轻活动。

### 5.4 示例 D：后台起雾

```text
今日社交天气
后台起雾

看起来正常
其实脑子里开了八个窗口

可以一起坐着
但先别让我解释
```

朋友接法：

- “那一起自习？”
- “不说话也行。”
- “我懂，陪你坐会儿。”

Meetu 承接：安静陪伴 / 自习 / 咖啡局。

## 6. 统一风格

### 6.1 不是天气 App

不能做成真正天气预报 UI。

它应该是“大学生社交状态图”，借天气隐喻，而不是复制天气软件。

### 6.2 视觉关键词

- 年轻；
- 有一点怪；
- 清爽但不死；
- 轻社交；
- 有行动提示；
- 低产品边界；
- 可发朋友圈 / 小红书 / 群聊。

### 6.3 视觉系统建议

统一使用“社交天气符号”：

- 云、雨、晴、风、雾、雷；
- 但符号要人格化，有一点小脾气；
- 不一定是小动物，可以是天气小体 / 小云团 / 情绪气象物；
- 所有图形都属于同一个世界，不再动物、人、小鬼混搭。

### 6.4 品牌露出

品牌必须轻。

用户分享出去时，第一眼应该是：

> 这是她今天的状态。

不是：

> 这是 Meetu 的营销图。

## 7. H5 链路

### 7.1 首页

主句：

```text
今天你的社交天气怎么样？
```

副句：

```text
生成一张别人知道怎么约你的状态图。
```

CTA：

```text
看今天的天气
```

### 7.2 Step 1：今天的能量

选项：

- 低电量；
- 有点想出门；
- 想被喊但嘴硬；
- 想认识人但怕尴尬；
- 只想有人一起待着；
- 看起来正常但脑子很吵。

### 7.3 Step 2：今天可接收的方式

选项：

- 约饭可以；
- 散步可以；
- 自习可以；
- 小局可以；
- 先聊天可以；
- 熟人带我可以。

### 7.4 Result

生成 3 张天气图：

- 轻状态版；
- 嘴硬版；
- 可约版。

动作：

- 保存；
- 换一句；
- 复制配文；
- P1：进入 Meetu 对应小局。

## 8. 为什么这个方向更适合 Meetu

### 8.1 它不是泛情绪表达

“我今天累”无法自然回到 Meetu。

“我今天低电量，但可以被约饭”可以。

### 8.2 它不是单次测试

天气是每天变化的，可以高频复用。

### 8.3 它不是纯内容工具

输出图本身就是社交信号，可以自然导向邀约、小局、搭子。

### 8.4 它有统一世界观

天气隐喻统一：晴、雨、云、雾、风、雷。

不会再出现动物员工、纸条、表单、角色卡互相拼接。

## 11. 当前 PM 结论

我建议把产品方向从“情绪纸条 / 动物状态卡”调整为：
