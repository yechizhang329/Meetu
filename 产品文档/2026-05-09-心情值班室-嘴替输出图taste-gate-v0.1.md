## 1. 单图评审

### 1.1 嘴硬鹅

配句：

```text
我没事。
真的。
我说真的。
```

判定：**通过，A-。**

为什么过：

- 眼神侧瞥 + 拍胸口 + 翅膀藏后面，确实在“过度证明自己没事”；
- 和这句文案结合后，嘴硬关系非常明确；
- 朋友接话自然：“你越说真的越不像真的”。

问题：

- 画面本身稍微偏“站姿角色图”，还不是最强的一帧梗；
- 小帽子可以保留，但后续不要继续加强岗位设定。

处理：

- 本批通过；
- final 生产时可尝试让身体更紧张一点、翅膀藏得更心虚一点。

---

### 1.2 低电量猫

配句：

```text
人在。
电不在。
```

判定：**通过，A。**

为什么过：

- 一眼就是没电，但不是死亡/生病；
- 不靠电池牌、充电线，避免了 UI 卡感；
- 用户会发，朋友也会接“今天你就是这只”。

问题：

- 基本没有明显问题；这是本批最稳的正样本。

处理：

- 作为后续嘴替图的风格参考上限之一。

---

### 1.3 DDL 仓鼠

配句：

```text
会做的。
不是现在。
```

判定：**通过，A-。**

为什么过：

- 仰躺抱头 + 纸条丢脚边，拖延姿态很清楚；
- 没有焦虑教育海报感；
- 朋友接话自然：“你完了 / 明天再说”。

问题：

- 动物略偏“可爱熊感”，仓鼠辨识度可以更强一点；
- 空白纸存在感弱，但不影响本批验证。

处理：

- 本批通过；
- final 生产时强化仓鼠小体型/脸颊/小爪子，避免像泛小动物。

---

### 1.4 后台羊驼

配句：

```text
表面：好的。
后台：不要再来了。
```

判定：**通过，B+ / 可进入下一阶段，但 final 需再修。**

为什么过：

- 前台礼貌脸 + 背后乱涂，表面/后台关系成立；
- 已经去掉软件 UI 报错感；
- 朋友能接“后台笑死 / 我也是这只”。

问题：

- 乱涂占比略大，视觉有点抢角色和文字；
- 羊驼表情还可以更“礼貌撑住”，现在偏呆萌。

处理：

- 本批通过方向验证；
- final 生产时乱涂减少 25-35%，羊驼表情更假笑/更端着一点。
