# 状态纸条 / 情绪输出物 PRD 重设 v0.1

> 状态：取代旧「心情值班室 v0.8」作为下一轮产品思考基线。旧 v0.8/v0.9 只保留为探索记录，不再指导开发。

## 0. 为什么重做

旧方案失败点不是 UI 细节，而是产品定义错误：

- 我们做成了“产品生成一张分享卡”；用户要的是“我顺手发出去的一页状态”。
- 我们把动物、值班室、标签、朋友鉴定区、H5 流程都放进来，导致每个元素都在抢表达主体。
- 用户真正愿意分享的东西通常**没有明显产品边界**：像便签、歌词卡、朋友圈状态、表情包、截图，而不是像产品结果页。

新的验收前置：

> **先验证最终输出物是否值得分享，再反推 H5。**

如果输出图本身不值得发，H5 流程、角色体系、文案池都没有意义。

---

## 1. 用户内源需求

### 1.1 她本来就在做什么

目标用户不是缺一个“生成工具”，而是已经在用以下方式表达状态：

- 发歌/歌词：让歌替自己说。
- 发备忘录/便签/账单：把情绪藏进生活记录。
- 发梗图/表情包：让角色替自己承受尴尬。
- 发微信状态/朋友圈短句：低成本挂一下今天的状态。
- 发测试结果/人格卡：借第三方标签让朋友来评论。

### 1.2 她为什么不直接说

- 直接说“我很累/我很需要关心”太重。
- 直接说“我想被评论”太尴尬。
- 直接发广告感强的卡片像给产品打工。
- 直接用 AI 文案又像不是自己写的。

所以她需要一个**可否认、可玩笑、可被朋友接住**的表达载体。

### 1.3 真需求一句话

> 我想把今天的状态发出去，但不想显得我在认真求关注；最好像我随手写的，又有一个小东西帮我挡一下尴尬。

## 2. 外部案例给我们的约束

### 2.1 Tiny Type / 排版小动物

它强在减法：
- 手写内容是主体；
- 小动物只占 10% 左右，是情绪落款；
- 品牌极小；
- 没有卡片容器、没有标签、没有结果页感；
- 最后一行反转完成笑点。

对我们的约束：
- 不要把动物做成主角设定集。
- 不要让品牌、标签、朋友鉴定区框抢戏。
- 内容必须像用户自己写的，不像产品给的金句。

### 2.2 网易云 / Spotify 分享

它强在第三方代理：
- 用户不是说“我难过”，而是“这首歌刚好是我”。
- 分享的是心情和品味，不是产品。

对我们的约束：
- 小动物应该是表达代理，不是测试结果。
- 品牌应退到看不见。
- 输出图要让用户感觉“这是我的状态”，不是“这是某产品总结我”。

### 2.3 Loopy / Chiikawa / Capoo

它们强在角色缺陷：
- 不是完美吉祥物，而是狼狈、嘴硬、弱小、荒诞、可代入。
- 用户借角色表达“不好意思直接说”的自己。

对我们的约束：
- 动物要有小脾气/小缺点/现实压力，不要职业设定过重。
- 角色可以可爱，但不能卖萌、不能服务品牌。

### 2.4 小红书状态图/梗图

它强在秒懂：
- 一句话/一张图/一个状态就够；
- 能被评论区接住：“这就是我”“我也是”“别嘴硬”。

对我们的约束：
- 输出必须能直接甩群或发 XHS，不需要解释。
- 每张图只保留一个梗点。

## 3. 新产品定义

### 3.1 暂定名

不再沿用“心情值班室”作为主叙事。候选名：

- 今天这页
- 替我写一下
- 今日状态纸条
- 小动物替我写
- 别问，纸上写了

当前更推荐：**今天这页**。

原因：
- 不是房间/系统/岗位；
- 像一个轻动作；
- 允许每天复用；
- 不限制动物、便签、账单、歌词等形式。

### 3.2 一句话定义

**今天这页**是一个把当下状态变成“可发出去的一页纸”的 H5：用户选一个生活触发器，得到几张像自己随手写出来的状态纸条，小动物只在旁边帮她把尴尬挡住。

### 3.3 产品不是

- 不是人格测试；
- 不是 AI 生图工具；
- 不是动物 IP 图鉴；
- 不是文案生成器；
- 不是社交匹配工具；
- 不是心理/治愈/诊断工具。

### 3.4 产品是

> 一个低成本状态表达弹药库。

用户不是来完成流程，而是来拿走一页能发的状态。

## 4. P0 输出物优先

P0 不先做完整 H5。先做 3 张输出样张，必须过“我会不会发”测试。

### 4.1 样张 A：生活流水账纸

**用途**：承接 Tiny Type 类型的生活真实感。

形式：
- 手写账单/清单/今日消耗表；
- 纸张横线或点阵；
- 小动物右下角 8-12%；
- 最后一行反转。

示例主题：

```text
今日能量预算
100 点

起床 -30
上课 -20
回消息 -15
假装没事 -25

剩 10？
那我怎么已经关机了
```

小动物：低电量猫右下角端着空杯/趴着。

### 4.2 样张 B：一句状态纸

**用途**：承接微信状态/小红书状态图的秒懂传播。

形式：
- 1 句大字 + 1 句小字；
- 小动物 15-25%，不是主角；
- 色块可以更鲜活，但不能像广告。

示例：

```text
本人今日电量不足

非必要别叫醒
```

### 4.3 样张 C：嘴硬纸条

**用途**：承接朋友互动。

形式：
- 极短句；
- 留给朋友评论“别嘴硬”；
- 不解释角色、不写标签。

示例：

```text
我没有。

但他们都说像。
```

小动物：嘴硬鹅在角落，翅膀挡嘴。

### 4.4 输出图硬规则

- 不出现明显 logo / banner / 产品名大字。
- 不出现“你是/你属于/测试结果/人格/标签”。
- 不出现朋友鉴定区框。
- 不出现功能按钮感、表单感、证书感。
- 小动物不是必须大；多数场景控制在 8-25%。
- 文字优先级高于角色；角色服务文字。

## 5. H5 链路（样张通过后再实现）

### 5.1 入口

不是：

```text
今天派谁出来替你说话？
```

而是：

```text
今天这页，替你写一下。
```

### 5.2 第一步：选生活触发器

用户不是回答问题，而是点一个“今天发生了什么”。

P0 触发器：

1. 钱又不知道去哪了
2. 人在，电不在
3. DDL 在追我
4. 朋友一约我就想躲
5. 被说中了，但我不认
6. 看起来没事，其实后台炸了

### 5.3 第二步：选输出形态

给 3 种纸条：

1. 流水账纸
2. 一句话状态纸
3. 小动物角落纸

也可以默认给 3 张让用户左右滑，不让她先想太多。

### 5.4 结果页

只做 3 件事：

- 这页能不能直接保存；
- 能不能换一句；
- 能不能轻微改文字。

不做：
- 角色解释；
- 结果标签；
- 朋友鉴定区框；
- 语气选择页；
- 多按钮堆叠。

## 6. 文案原则

旧文案池作废，不再作为 base。

新文案像：
- 用户自己写的便签；
- 流水账；
- 断句；
- 有点不工整；
- 最后一行翻车。

不像：
- 产品金句；
- 运营段子；
- 押韵文案；
- 完整解释；
- “我就是 xxx 型”。

### 6.1 文案公式

公式 A：流水账 + 反转

```text
今天本来还有 100 点电

起床 -30
上课 -20
回消息 -15
装正常 -35

怎么还倒欠 10 点
```

公式 B：短状态 + 嘴硬补一句

```text
我没事

只是今天不太适合被问
```

公式 C：朋友可接话

```text
我没有。

你们别说了。
```

## 7. 设计原则

### 7.1 主体关系

文字 > 纸张媒介 > 小动物 > 品牌。

### 7.2 角色定位

小动物是：
- 落款；
- 陪写员；
- 角落同谋；
- 帮用户挡尴尬的小东西。

小动物不是：
- 主角 IP；
- 测试结果；
- 分类标签；
- 品牌 mascot。

### 7.3 视觉媒介优先级

P0 优先尝试：
1. 横线纸/便签纸；
2. 备忘录/草稿纸；
3. 歌词卡式大字；
4. 群聊截图式纸条。

暂不优先：
- 完整办公室；
- 角色卡片；
- 证书；
- 海报；
- 大 logo 分享卡。

## 8. 验收标准

任何样张必须过 5 问：

1. 去掉产品名后，它像用户自己会发的东西吗？
2. 用户发它是在表达自己的状态，还是在给产品做广告？
3. 朋友看到能不能自然接话？
4. 这张图是否只讲一个梗？
5. 小动物是否降低尴尬，而不是增加产品感？

不过即打回。
