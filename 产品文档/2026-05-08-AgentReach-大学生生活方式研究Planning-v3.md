## 0. v3 核心修正

这版 planning 明确三件事：

1. **不预设产品答案**：不默认“自介卡/搭子卡/需求卡”是最优方向；它们只作为可能出现的样本形态观察。
2. **视觉语言是一等公民**：每条样本不只看标题/正文/评论，还要记录首图、视觉机制、广告感、圈层审美和可迁移设计规则。
3. **运营风险先于规模**：大样本研究必须先解决账号风险。当前 Meetu 小助理是品牌号，420-580 次只读调用会污染账号画像，需拍板执行方式。

---

## 1. 研究目标

建立 Meetu 对当代大学生的长期 common sense：

- 他们如何交朋友、找搭子、恋爱/暧昧、维持弱关系；
- 他们如何消耗课余时间：娱乐、学习、兼职、兴趣、线下活动；
- 他们如何形成圈层：二次元、乙游、追星、运动、摄影、城市生活、社团等；
- 他们在哪些场景里主动表达需求、寻求回应、组织他人；
- 他们真实使用什么语言、什么视觉、什么社群机制；
- 哪些低成本场景值得 Meetu 试，哪些只是内容热但不适合产品化。

## 2. 执行前必须拍板：调研账号策略

Lucy 提出的 P0 风险成立：v3 计划预计 420-580 次只读调用，是上一批 41 次调用的 12-17 倍。当前登录态是 **Meetu 小助理品牌号**，大规模浏览会形成账号画像。

### 方案 A：推荐
换无品牌调研小号后执行完整研究。

- 优点：不污染品牌号；可一次跑足规模；未来可持续调研。
- 缺点：需要准备登录态。

### 方案 B：保守可执行
继续用 Meetu 小助理，但拆成 4-5 个工作日，每日 ≤100 次调用。

- 优点：无需新号，能开始。
- 缺点：慢；仍有品牌号画像风险；不适合频繁深挖竞品/相似账号主页。

### 方案 C：不建议
用 Meetu 小助理一次性跑完整 420-580 次。

- 风险：行为异常、品牌号推荐流被污染、后续发布/评论/客服权重可能受影响。

**PM 建议：方案 A。若 Jonathan 需要马上开始，则先执行方案 B 的 Day 1。**

## 3. 样本规模

完整研究目标：

- 研究组：17 组（A-Q）；
- 小红书关键词：约 190-230 个；
- 小红书搜索：约 180-220 次；
- 去重目标：3,000-5,000 条笔记；
- 深读目标：220-300 条；
- 评论抓取：150-200 条；
- 评论文本：3,000-5,000 条；
- 标志性账号：40-60 个；
- 视觉样本：至少 250 条，其中每组至少标记 15-20 条。

Day 1 保守版：

- 搜索 50-70 次；
- 深读 60-80 条；
- 评论 40-50 条；
- 覆盖武汉本地化 + 社交/课余/娱乐/视觉/运营风险核心组。

## 4. 研究组 v3

### A. 认识新朋友 / 社交启动

关注问题：为什么想认识人？尴尬在哪里？用户怎么降低社交启动成本？

### B. 搭子 / 临时关系 / 弱关系协作

关注问题：搭子是朋友替代品、效率工具，还是低压社交？边界如何表达？

## 5. 样本字段 v3

### 基础数据
- 平台、关键词、标题、正文、作者类型、点赞、评论、收藏、分享；
- 发布时段；
- 互动率：评论/赞、收藏/赞；
- 是否疑似标题党；
- 是否疑似限流/广告。

### 用户需求
- 表层话题；
- 底层需求：找人、找事、找资源、找安慰、找身份、找建议、找交易；
- 行动意图：评论报到、求链接、私信、加群、收藏、转发、@朋友。

### 社交机制
- 发起关系的位置：公开帖、评论区、私信、群聊、校园墙；
- 关系强度：陌生人、半熟人、同校、同城、同圈层、熟人；
- 边界：性别、学校、城市、时间、预算、隐私、长期/短期。

### 运营语言
- 标题句式；
- 正文口吻；
- 首评机制；
- 作者回评方式；
- 评论区黑话；
- 私信/求链接承接方式；
- 可借鉴话术；
- 敏感词与替代表达；
- 用户反感点。

### 设计语言
- 首图类型：大字报 / 截图 / 人像 / 海报 / 卡片 / 长图 / 表情包 / 实拍 / 拼贴；
- 视觉角色：信任型 / 传播型 / 组织型 / 身份型 / 情绪型；
- 首屏缩略图可读性：0.5 秒是否读懂；
- 首图第一眼钩子：标题、人物、荒诞图形、利益点、冲突句、学校/城市点名；
- 图文关系：图已讲完故事，还是制造悬念；
- 文字层级：主标题字数、最大字号感、对比度；
- 版式结构：居中大字 / 左上标题 / 便签散点 / 卡片堆叠 / 聊天流 / 信息图；
- 色彩与质感：白底黑字、奶油纸、荧光色、截图灰、红章、低饱和生活感；
- 素材来源感：学生自制 / 平台原生截图 / 机构海报 / AI 图 / 设计模板；
- 广告感触发点：logo、二维码、过度精修、功能说明、商业话术、模板感；
- 可截图传播性：单独发群/朋友圈是否成立，朋友会不会接话；
- 组件化可能性：能否转成 Meetu 活动封面、H5 结果卡、公众号段落、CMS 卡片、XHS 首图。

### 产品机会
- 现有解决方式；
- 当前低效点；
- Meetu 可介入点；
- 低成本实现方式；
- 分发方式；
- 数据沉淀方式；
- 最大风险；
- 是否值得进入 PRD。
