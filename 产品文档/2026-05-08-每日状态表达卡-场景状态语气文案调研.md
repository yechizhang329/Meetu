# 每日状态表达卡 · 场景/状态/语气/文案调研结论

**日期**：2026-05-08  
**负责人**：Fiona  
**对应 PRD**：`2026-05-08-每日状态表达卡-PRD-v0.1.md`  
**目的**：验证当前 P0 规模（6 场景 / 12 状态 / 3 语气 / 200-300 文案池）是否最优，是否适配当前社媒传播和大学生主流痛点，并产出可感知 demo。

---

## 0. 结论先行

**方向成立，但 v0.1 的结构需要调。**

不是“再做一个卡片生成器”，而是做：

> 把大学生日常里那些“不想认真说、但很想被朋友接住”的状态，压缩成一张可发群/发朋友圈/做微信状态的表达卡。

当前 v0.1 的大方向对：**即时状态表达 > 长期身份表达**。但现在的 P0 模型有三处需要修：

1. **“什么都不想干”不应作为场景，而应作为状态。**  
   场景应该是外部触发器：早八、期末、宿舍、群聊、周末、聊天、被学校/活动安排。状态才是内心反应：没电、嘴硬、开摆、加载失败。

2. **12 个状态偏少，且缺几个高频痛点。**  
   样本里高频痛点不只“没电/嘴硬/想去但懒”，还包括：被管烦、宿舍无隐私、期末应激、已读乱回、周末空心、需要安慰但嘴硬。

3. **3 种语气不够，必须新增“对话/聊天截图体”。**  
   小红书和群聊传播里，最容易被接话的不是纯公告，而是“我 vs 朋友 / 我 vs 系统 / 我 vs 脑子”的短对话。

**建议 P0 调整为：**

- **7 个场景**：早八/上课、期末/DDL、宿舍/室友、群聊/已读、周末/出门、聊天/crush、被安排/被管。
- **16 个状态**：保留原 12，新增或替换 4-6 个真实高频状态。
- **4 种语气**：朋友锐评、本人嘴硬、系统公告、对话截图。
- **内容规模**：不要全量笛卡尔积。P0 做 **80-120 个有效组合**，每组 2-3 条，总文案池 **240-360 条** 更合理。

## 2. 数据里最有用的信号

### 2.1 “状态表达”是高频真实需求，但不是泛泛的“情绪”

高互动样本集中在具体生活触发器：

| 触发器 | 代表样本 | 互动信号 |
|---|---|---:|
| 被学校规训/成年人但被管 | `大学能不能还给大学生成年人类的自由` | 2.4万赞 / 2445评 |
| 上课/点名/水课 | `大学水课就是一场巨大的狼人杀` | 6561赞 / 1159评 |
| 宿舍无隐私/边界被压缩 | `私密性的缺失是大学生活里最大的bug` | 1.7万赞 / 1712评 |
| 宿舍反人类 | `找到大学宿舍反人类的原因了` | 1.0万赞 / 930评 |
| 周末不知道干嘛 | `大学生们周末都打算做什么呢` | 647赞 / 3738评 |
| 发疯文案/已读乱回 | `已读乱回发疯文学2.0` | 6.1万赞 / 3708评 |
| 文案征集/排版小动物 | `求求这种文案，大量求` | 24.4万赞 / 1.34万评 |

这里说明一个关键点：

> 用户不是抽象地想“表达情绪”，而是在一个具体触发器下，需要一个能替自己说话的壳。

所以产品不能只问“你今天什么状态”，还要问：

> 你今天是被哪个场景搞成这样的？

### 2.2 高传播内容不是“精准”，而是“能被评论区接住”

评论区最强的几类行为：

1. **报类型**：MBTI 样本里评论区大量直接报 `INFP / ENFP / INTJ`，说明“结果标签”天然适合评论区接龙。
2. **求文案**：排版小动物/文案类样本里，评论区不是讨论产品，而是互相抛文案、收集文案。
3. **报行程/报状态**：周末样本里，评论区直接回答“我今天干嘛”。
4. **补梗/接梗**：发疯文学样本里，评论区大量续写、谐音梗、抽象回复。

这对状态卡的启发：

> 一张卡必须留一个“朋友能马上回复的口子”，否则只是漂亮图片。

可用口子包括：

- `你今天是哪张？`
- `评论区报状态。`
- `这张像谁？`
- `给你室友也生成一张。`
- `谁先说像谁负责。`

### 2.3 当前主流痛点不是“孤独”二字，而是 6 类更具体的微痛点

从样本看，大学生愿意互动的不是宏大叙事，而是可以一秒代入的小痛点：

| 微痛点 | 典型表达 | 产品状态映射 |
|---|---|---|
| 人到了，魂没到 | 早八、返校、上课 | 开机失败 / 加载中 |
| 成年人但被当小孩管 | 查寝、请假、活动、家长同意 | 被管烦 / 反 KPI |
| 宿舍边界消失 | 私密性缺失、室友共处 | 结界不足 / 想独处 |
| 社交想接但不想负责 | 群聊冷场、约饭选店、组局 | 不想负责 / 别让我主理 |
| 想出去但启动失败 | 周末、citywalk、吃饭、临时约 | 想去但懒 / 出门启动失败 |
| 想表达但怕矫情 | 朋友圈文案、备忘录、微信状态 | 嘴硬 / 需要嘴替 |

## 3. 对当前 P0 规模的判断

### 3.1 场景：6 个不够精准，建议改成 7 个

v0.1 当前：

1. 上课/学习
2. 宿舍/室友
3. 群聊/社交
4. 出门/周末
5. 暗恋/聊天
6. 什么都不想干

问题：

- `什么都不想干` 是状态，不是场景；
- 样本里 `被学校/活动/规则安排` 是强痛点，但当前没有独立入口；
- `期末/DDL` 和普通上课不同，情绪密度更高，应单独拆出。

建议 P0 场景改为：

| 新场景 | 为什么保留/新增 |
|---|---|
| 早八/上课 | 点名、水课、人在教室魂不在，是高共鸣场景 |
| 期末/DDL | 压力场景独立，文案和视觉都不同 |
| 宿舍/室友 | 私密性/边界/互相打扰是强痛点 |
| 群聊/已读 | 已读乱回、冷场、回复压力是高频传播点 |
| 周末/出门 | “想出门但懒/没人约/不知道干嘛”评论率高 |
| 聊天/crush | 聊天截图、脑内开会、朋友分析天然适合卡片 |
| 被安排/被管 | 成年人类自由、查寝、活动、班会、家长同意书等强情绪 |

### 3.2 状态：12 个可以做 P0，但建议扩到 16 个

v0.1 的 12 个覆盖了社交表达，但缺生活触发器带来的真实状态。

建议 P0 状态池：

| 状态 | 用途 |
|---|---|
| 低电量 | 泛用，微信状态/朋友圈都适合 |
| 开机失败 | 早八/返校/周一 |
| 在线装死 | 群聊/社交/消息回复 |
| 嘴硬 | 小红书/朋友圈自嘲核心 |
| 想去但懒 | 周末/出门/活动 |
| 想被约但不主动 | 社交连接核心痛点 |
| 不想负责 | 群聊/约饭/组局 |
| 脑内开会 | crush/聊天/选择困难 |
| 已读乱回 | 群聊/聊天截图类高传播 |
| 表面正常 | 适合嘴硬反差 |
| 期末应急 | 5-6月时段性强痛点 |
| 宿舍结界不足 | 宿舍/室友/边界 |
| 被管烦 | 学校规则/查寝/活动安排 |
| 周末空心 | 周末不知道干嘛、高评论场景 |
| 需要朋友捞一下 | 互动钩子强 |
| 今日开摆 | 低压泛用 |

### 3.3 语气：3 个不够，必须新增“对话体”

v0.1 当前：

1. 朋友锐评
2. 本人嘴硬
3. 系统公告

建议变成 4 个：

| 语气 | 传播用途 | 示例结构 |
|---|---|---|
| 朋友锐评 | 最适合发群，让朋友接话 | `你不是困，你是人还没被召唤出来。` |
| 本人嘴硬 | 最适合朋友圈/小红书 | `我没有装死，我只是在后台运行。` |
| 系统公告 | 最适合大字报/状态卡 | `系统提示：本人今日低电量。` |
| 对话截图 | 最适合评论区/聊天传播 | `我：就回个哈哈吧 / 脑子：开会。` |

原因：本轮视觉和文案样本里，`聊天截图 / 毒舌朋友 / 已读乱回` 都有强传播表现。对话体比“公告”更像活人，也更适合朋友转发。

### 3.4 文案池：200-300 条可以，但不要全量组合

如果按 7 场景 × 16 状态 × 4 语气 × 3 条 = 1344 条，P0 会过重，而且质量不可控。

建议：

- 不做全量笛卡尔积；
- 做 **80-120 个有效组合**；
- 每个组合 2-3 条文案；
- 初始文案池 **240-360 条**；
- 冷门组合不要硬凑。

判断标准：

> 宁可少一点，但每张都像人话；不要铺满矩阵，最后像 AI 模板。

## 4. 适配当前媒体传播的产品形态

### 4.1 最适合传播的不是“编辑器”，是“状态弹药库”

用户不是来认真创作的。用户要的是：

1. 我现在有点状态；
2. 我懒得写；
3. 你帮我给出 3 张；
4. 我挑一张发出去；
5. 朋友来接话。

所以 P0 不要做重编辑。

编辑能力只保留：

- 换一句；
- 换个没那么狠的；
- 换个更嘴硬的；
- 改 1 个词。

### 4.2 输出渠道要分三种，而不是只做一张分享卡

样本里“状态表达”会进入不同媒介：

| 渠道 | 用户用途 | 建议卡片规格 |
|---|---|---|
| 微信状态/头像背景 | 自己挂着，低压展示 | 方图/横图，字少，可长期挂 |
| 群聊/朋友聊天 | 让朋友接话 | 竖图，朋友锐评更明显 |
| 小红书/朋友圈 | 晒结果/找同类 | 大字报/备忘录/结果卡，标题强 |

建议 P0 输出时给用户 3 张候选，不只是文案不同，最好用途不同：

1. **发群版**：朋友锐评大；
2. **朋友圈版**：本人嘴硬大；
3. **状态版**：标题短，适合挂微信状态。

### 4.3 当前媒体痛点适配度

| 需求 | 当前 PRD 适配度 | 调整建议 |
|---|---|---|
| 小红书停留 | 中 | 要有大字报/聊天截图式强封面，不只结果卡 |
| 群聊接话 | 高 | 强化朋友锐评和对话体 |
| 微信状态 | 中-高 | 需要更短、可挂一天的状态图 |
| 朋友圈分享 | 中 | 需要嘴硬/可否认性更强，避免像测试广告 |
| 高复用频率 | 中 | 增加“今天换一张/今日状态”机制 |

## 5. 推荐 PRD v0.2 调整

### 5.1 输入流程

从：

```text
选场景 → 选状态 → 选语气 → 生成
```

改成更口语的：

```text
今天卡在哪？ → 你现在像什么？ → 你想怎么发？
```

对应选项：

#### Step 1：今天卡在哪？

- 早八/上课
- 期末/DDL
- 宿舍/室友
- 群聊/已读
- 周末/出门
- 聊天/crush
- 被安排/被管

#### Step 2：你现在像什么？

- 低电量
- 开机失败
- 在线装死
- 嘴硬
- 想去但懒
- 想被约但不主动
- 不想负责
- 脑内开会
- 已读乱回
- 表面正常
- 期末应急
- 宿舍结界不足
- 被管烦
- 周末空心
- 需要朋友捞一下
- 今日开摆

#### Step 3：你想怎么发？

- 朋友锐评
- 本人嘴硬
- 系统公告
- 对话截图

### 5.2 输出结构

每张卡保留 4 层，但顺序调整：

1. **大标题**：一眼识别状态；
2. **状态解释**：一句本人嘴硬/认领；
3. **朋友锐评或系统吐槽**：传播金句；
4. **接话口子**：让朋友知道怎么回。

### 5.3 P0 不做

继续坚持不做：

- 大 AI 自由生成；
- 公开广场；
- 匹配/交友闭环；
- 复杂编辑器；
- 用户账号；
- “精准人格分析”。

## 7. 最终判断

**这个方向值得继续，但不是因为“卡片生成”本身，而是因为它能解决一个更内源的需求：**

> 用户想表达“我现在是什么状态”，但不想自己认真写、不想显得求关注、不想像广告，也希望发出去有人接话。

当前规模不是最优。建议把 P0 从 `6 场景 / 12 状态 / 3 语气` 调整为：

> **7 场景 / 16 状态 / 4 语气 / 80-120 有效组合 / 240-360 条文案池。**

其中最关键的不是数量，而是两条产品纪律：

1. **每张卡必须绑定真实触发器。**  
   不要只写“我今天低电量”，要知道是早八低电量、宿舍低电量、群聊低电量还是周末低电量。

2. **每张卡必须留朋友接话口。**  
   没有接话口，它就是一张图；有接话口，它才可能变成传播。
