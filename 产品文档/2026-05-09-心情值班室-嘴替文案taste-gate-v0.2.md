## 1. 4 张首批输出图主句确认

以下 4 条锁定为 Phoebe 首批 prompt 审稿基线：

### 嘴硬鹅

```text
我没事。
真的。
我说真的。
```

判定：最强。重复本身就是嘴硬破绽。

### 低电量猫

```text
人在。
电不在。
```

判定：最短、最好发、可复用最高。

### DDL 仓鼠

```text
会做的。
不是现在。
```

判定：不解释，不卖惨，嘴替成立。

### 后台羊驼

```text
表面：好的。
后台：不要再来了。
```

判定：反差明确，图像可表达。

## 2. 每角色 4 条 A 级候选确认

### 2.1 嘴硬鹅

通过：

1. `我没事。/ 真的。/ 我说真的。`
2. `我没多想。/ 我想了八次。`
3. `我没听见。/ 但我记下了。`
4. `我没记仇。/ 但记笔记。`

评语：嘴硬鹅是目前最稳定的角色。它的语气天然有嘴替空间，朋友接话最顺。

### 2.2 低电量猫

通过：

1. `人在。/ 电不在。`
2. `我看到了。/ 我电量回不动。`
3. `不要叫醒。/ 我在攒明天。`
4. `让我趴一下。/ 三分钟就够。`

评语：方向通过。`我电量回不动`略有生造感，但可以保留；它和角色强绑定，图出来后再判断是否换成更自然版本。

### 2.3 DDL 仓鼠

通过：

1. `会做的。/ 不是现在。`
2. `再等我一下。/ 这一下我说了三天。`
3. `我已经开始了。/ 在喝水阶段。`
4. `还有时间。/ 我说的是给我自己。`

评语：`喝水阶段`很好，有真实拖延细节。`还有时间`稍弱，但可作为 A- 保留。

### 2.4 后台羊驼

通过：

1. `表面：好的。/ 后台：不要再来了。`
2. `表面收到。/ 后台已读不回。`
3. `我说嗯嗯。/ 我想说嗯。`
4. `表面在。/ 里面已经回宿舍了。`

评语：这版明显比 v0.1 轻。`我说嗯嗯 / 我想说嗯`是后台羊驼里最有生活质感的一条，可作为后续扩池标杆。

## 3. 仍需注意的边界

### 3.1 不要把“后台”写成系统设定

后台羊驼可以有“后台”这个词，但不要继续发展成：窗口、系统、报警、服务器、面板、程序。否则会回到旧版 UI/办公室/软件隐喻。

更好的方向是：

- 嗯嗯 / 嗯；
- 收到 / 已读不回；
- 表面在 / 里面回宿舍；
- 说好 / 其实想撤。

### 3.2 不要过度发明词

低电量猫的“电量回不动”“攒明天”可以作为角色化语言，但后续扩池要控制比例。太多生造词会变产品腔。

### 3.3 不要把 DDL 写成励志/焦虑

DDL 仓鼠要保持“轻荒诞拖延”，不要变成焦虑共鸣长句。
