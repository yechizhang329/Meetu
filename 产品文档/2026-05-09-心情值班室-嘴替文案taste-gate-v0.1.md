## 0. 总结论

**方向通过，但不是 32/32 全通过。**

这版相对旧 v1.2 有本质进步：已经从“产品写的状态金句”转向“角色替用户说不想自己说的话”。尤其是嘴硬鹅、低电量猫和 DDL 仓鼠，已经能看出用户会发出去的嘴替感。

但 PM 视角不能接受“全部 yes”。目标用户不会对每句都买单。部分句子仍有三类问题：

1. **太工整 / 太像段子**：有写出来的巧感，不够像顺手发；
2. **太抽象 / 太产品化**：如“后台已离场”等，需要靠设定理解；
3. **太重 / 太求关心**：偏 emo，会破坏低压嘴替。

本轮判定：

- **A 级可直接进入输出图试金石**：8 句；
- **B 级可作为扩池基线**：14 句；
- **C 级需重写或降级备用**：8 句；
- **D 级不建议使用**：2 句。

## 1. A 级：可以直接给 Phoebe 做图的主句

### 嘴硬鹅

1. **G2**

```text
我没事。
真的。
我说真的。
```

为什么过：最像真实嘴硬，重复本身就是笑点，朋友接“你重复三遍了”很自然。

2. **G4**

```text
我没多想。
我想了八次。
```

为什么过：短、暴露、反转，用户发出去还能嘴硬。

3. **G5**

```text
我没听见。
但我记下了。
```

为什么过：反话逻辑非常清楚，朋友容易戳穿。

### 低电量猫

4. **C1**

```text
人在。
电不在。
```

为什么过：最短、最稳、可高频复用。

5. **C3**

```text
我看到了。
我电量回不动。
```

为什么过：有具体使用场景“回消息”，用户会发，朋友能接。

### DDL 仓鼠

6. **D1**

```text
会做的。
不是现在。
```

为什么过：嘴替精确、短、无解释。

7. **D4**

```text
再等我一下。
这一下我说了三天。
```

为什么过：生活细节+自暴，用户真实会发。

### 后台羊驼

8. **A1**

```text
表面：好的。
后台：不要再来了。
```

为什么过：最符合后台羊驼，一眼懂，适合视觉反差。

## 2. B 级：可扩池使用，但不作为首批试金石主句

### 嘴硬鹅

- G1 `我没生气 / 只是脸色按了暂停`：有画面，但“脸色按暂停”略像写出来的巧句。
- G3 `我没烦 / 烦的是它`：嘴替机制强，但要依赖图里“它”的存在。
- G6 `我不在乎 / 我只是反复想了一下`：可用，略常规。
- G7 `我没在装 / 演技不够而已`：可用，但更像朋友调侃，不像自己发。

### 低电量猫

- C2 `出门要等我开机 / 开机要先充电`：可用，但稍设备梗。
- C4 `我没事 / 只是没电`：稳，但和 C1 重叠。
- C6 `今天只接收 / 不回复`：很适合消息场景。
- C8 `请勿摇晃 / 我在低电量休息`：可用，但“请勿摇晃”略物品标签感。

### DDL 仓鼠

- D3 `我在写 / 写在脑子里`：场景明确，可用。
- D6 `我没摆烂 / 我在蓄力`：常见但有效。
- D7 `别问 / 问了就是不交`：有冲击，但要小心攻击性。
- D8 `尽量 / 这词我用得越多 越不靠谱`：真实，但偏长。

### 后台羊驼

- A2 `我在听 / 只是后台开了十八个窗口`：方向对，但“十八个窗口”接近旧产品比喻，可留作 B。
- A3 `这个笑 / 是临时拼的`：有画面，可用。

## 3. C 级：需要重写或降级备用

- **G8** `不是我 / 是和我同款的那一只`：太像产品角色设定，嘴替感弱。
- **C5** `我在 / 但勿连接`：太技术标签化，像设备提示。
- **C7** `我已不在 / 我的猫还在`：概念有趣，但读起来绕。
- **D2** `会做的 / 但更晚一点`：太平，没有鲜活感。
- **D5** `进度不重要 / 心态重要`：像网络段子，嘴替不够。
- **A4** `我说好 / 是因为我不想现在解释`：真实但偏解释。
- **A5** `我看起来还在 / 不是因为还在 / 是因为没空崩`：太长，像产品文案。
- **A6** `表面在维持 / 后台已离场`：抽象，“离场”不够生活。

---

## 4. D 级：不建议进入产品

1. **A7**

```text
我点头。
是因为已经没法摇头了。
```

问题：有点苦、压抑，嘴替可以轻一点；而且“没法摇头”会让语义偏被迫/无力，情绪过重。

2. **A8**

```text
我说我能。
是因为没人想知道我不能。
```

问题：太重，接近求关心/受伤表达，不是低压嘴替。朋友接“我想知道”会变成情绪照护，不适合 P0。
