# 心情状态表达产品重设草案 v0.1

## 0. 结论先行
旧版“心情值班室 v0.8/v0.9”不能继续修。它的问题不是视觉 bug，而是产品出发点错了：我们做的是“一个产品生成的分享卡”，用户想要的是“我可以顺手发出去代表我当下状态的一页东西”。

新方向应从“状态输出物”而不是“角色体系 / H5 流程”出发。

**新的第一原则：最终输出必须像用户本来就在朋友圈/小红书/群聊会发的东西，而不是像 Meetu 导出的产品卡。**

## 1. 外部案例拆解（按分享动机）

### 1.1 排版小动物 / Tiny Type（Jonathan 样张）
- 用户发它是在表达：我不是在认真晒账单，而是在用一页手写纸吐槽“我钱怎么又没了”。
- 让她敢发的元素：手写账单像私人笔记；品牌极小；小动物只是落款/陪伴，不抢主体。
- 朋友怎么接话：会接“我也是”“350 到底去哪了”“饭钱不止这个吧”。
- 年轻鲜活点：手写、真实账单语境、最后一行反转、emoji 击穿。
- 可借：产品边界消失、文字是主体、小动物是情绪落款、梗在最后一句。
- 不借：不要直接模仿记账场景；不要把动物做成大 IP 主角。

### 1.2 网易云/Spotify 分享卡
- 用户发它是在表达：我不直接说我难过/想你/今天很燃，我让一首歌替我说。
- 让她敢发的元素：歌/歌词是第三方代理，减少自曝尴尬；卡片天然是社交平台格式。
- 朋友怎么接话：评论歌词、歌名、回忆、歌单品味。
- 年轻鲜活点：强情绪+低自曝；用户分享的是“我的品味/我的状态”，不是产品。
- 可借：用第三方代理承接自我表达；输出物里品牌不能抢过情绪内容。
- 不借：不要做年度报告式数据卡；那会变成“我被产品总结”。

### 1.3 Loopy / Zanmang Loopy
- 用户发它是在表达：我的情绪很狼狈/阴阳怪气/嘴硬，但我不想用自己的脸说。
- 让她敢发的元素：角色有成人化的情绪重构，不是儿童吉祥物；表情包天然可借用。
- 朋友怎么接话：发同款表情包、说“这不就是你”。
- 年轻鲜活点：角色不完美，有怪表情和小脾气。
- 可借：角色要有缺点和社交人格，而不是“可爱员工”。
- 不借：不要把职业设定、岗位、制服压得太重；会像品牌 IP 设定集。

### 1.4 Chiikawa
- 用户发它是在表达：我很弱/很累/很努力但也很可爱，压力被角色软化。
- 让她敢发的元素：小角色承接压力，用户获得安慰但不被诊断。
- 朋友怎么接话：买谷/表情包/“今天也是小可怜”。
- 年轻鲜活点：弱小、压力、可爱、荒诞并存。
- 可借：角色可以承接现实压力，但不能直接说“治愈/心理”。
- 不借：不要甜萌过度，否则男生排斥，女生也会觉得幼稚。

### 1.5 BeReal / Locket
- 用户发它是在表达：我现在的真实状态/我和亲密朋友的即时连接。
- 让她敢发的元素：低修饰、低压力、即时性；私密/小圈层优先。
- 朋友怎么接话：看到你此刻在干嘛，接生活状态。
- 年轻鲜活点：反精修、反表演、接近真实生活流。
- 可借：降低“制作感”；让输出像临时捕捉，而不是精心设计。
- 不借：不要强社交/强打卡，否则会把压力加回去。

### 1.6 小红书状态梗图/状态卡
- 用户发它是在表达：今天我的精神状态就这样，不解释。
- 让她敢发的元素：一句狠话/一句自嘲/一张图说完；不需要长流程。
- 朋友怎么接话：哈哈哈、我也是、@朋友。
- 年轻鲜活点：短、狠、准、像群聊里会甩出去的图。
- 可借：输出必须先有“群聊可甩”的传播性。
- 不借：不要做解释型页面；不要让用户先回答太多题。

## 2. 反向总结：用户为什么不分享 v0.9
1. 品牌边界太强：banner、logo、标签、朋友区框都在提醒“这是产品产物”。
2. 输出不像生活中会发的媒介：不像便签、歌词卡、表情包、截图，更像产品结果页。
3. 角色抢错位置：不是“小动物帮我落款”，而是“产品让我得到一个动物角色”。
4. 文案像系统在问答：用户不是来填表，也不是来获得诊断。
5. 情绪不够具体：页面说“今天派谁出来”，但没有一个真实生活瞬间让人代入。


## 2.1 Lucy 语言侧补充：旧文案池为什么也作废
Lucy 的案例拆解补充了一个关键点：旧 96 条虽然是第一人称，但不是“用户自己写的”，而是“产品替用户写好的段子”。这仍然有产品味。

新文案原则：
- 不追求押韵、对仗、完整金句。
- 允许流水账、断句、不工整。
- 梗来自生活细节和最后一句反转，而不是“聪明句子”。
- 文字像用户脑子里冒出来的，不像运营精修。
- 小动物只帮忙降低尴尬，不负责解释用户是谁。

## 3. 新产品定义候选

### 3.1 一句话
**一个把用户当下状态写成“可发出去的一页小纸条”的工具；小动物只负责把这页纸变得没那么尴尬。**

### 3.2 用户感知
不是：
- 我在做测试；
- 我在生成 AI 图片；
- 我在选一个角色；
- 我在用 Meetu 产品。

而是：
- 这页有点像我今天；
- 我可以直接发；
- 朋友应该会懂；
- 这只小东西只是帮我把话说得没那么尴尬。

### 3.3 更准确的产品名方向
暂不锁名，但“心情值班室”可能过重。候选：
- `今天这页`
- `替我写一下`
- `今日状态纸条`
- `小动物替我写`
- `别问，纸上写了`

判断标准：名字不能像系统、房间、岗位、机构；要像一个轻动作。

## 4. 新 P0 产品形态

### 4.1 输出物优先
P0 先做 3 张“可分享样张”，不是先做 H5。

样张类型：
1. **今日开销/能量/DDL/社交电量类手写纸**：文字主导，小动物落款。
2. **一句状态大纸条**：大字 + 小动物 + 1 个生活场景细节。
3. **群聊可甩表情卡**：小动物偏大，但品牌完全隐身。

### 4.2 H5 链路降到最轻
如果样张成立，再反推 H5：
1. 用户选一个真实生活触发器：钱没了 / 人没电 / DDL追我 / 朋友约我 / 被说中了 / 今天装正常。
2. 系统给 3 页纸条，不是 3 个角色。
3. 用户只改一句话或换一页。
4. 保存/截图发出。

### 4.3 小动物的位置
- 小动物不是主功能，不是测试结果，不是身份分类。
- 小动物是“情绪落款/陪写员/旁边那只懂你的东西”。
- 大多数场景里文字 > 版式 > 小动物 > 品牌。

## 5. 设计原则重写
1. **像用户产物，不像产品产物**：品牌极小，甚至 P0 输出图不放 Meetu 字样。
2. **生活媒介优先**：便签、账单、歌词卡、备忘录、草稿纸、群聊截图，比“卡片设计”更像用户会发。
3. **单一表达点**：每张图只能有一个梗，不要角色+标签+评价区+logo 同时出现。
4. **文字是人格**：手写感/自然断行/最后一句反转比精致插画重要。
5. **朋友接话位不是画框**：接话空间通过内容钩子产生，不通过“朋友鉴定区”UI 框产生。

## 7. 立即要做的 3 个样张 brief（供下一轮）

### 样张 A：钱/电量类手写纸
- 参考 Tiny Type。
- 主体：手写状态清单。
- 小动物：右下角 8-12% 落款。
- 梗：最后一行反转。
- 品牌：无或极小。

### 样张 B：低电量状态纸
- 主体：一句大状态 `本人今日电量不足，非必要别叫醒。`
- 小动物：低电量猫趴在字边，不超过 25%。
- 视觉：干净但有一处鲜活色块。

### 样张 C：嘴硬纸条
- 主体：`我没有。` + 下面小字 `但他们都说像。`
- 小动物：嘴硬鹅在角落用翅膀挡嘴。
- 互动：朋友自然评论“别嘴硬”。
