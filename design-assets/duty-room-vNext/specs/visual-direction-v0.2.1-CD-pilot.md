## §1 C 树懒 + 咖啡 — 3 方向草案

PRD §5 C 内核: "知道任务在那, 也知道方法, 但启动不了 / 中间没连上"

### C-1: "想喝变快" (启动尝试中)

**机制描述**: 树懒**正在凑向咖啡杯**, 杯子举高靠近嘴, 但杯口还没沾到嘴唇 — "我正在尝试"

**构图**:
- 树懒身体微微前倾, 双手举杯朝嘴方向
- 咖啡杯口距离嘴 ~3-5cm (即将沾到)
- 杯沿干净 (还没喝)
- 蒸汽上升 (loading 在动)
- 表情: **眼神有期待 / 微微张嘴**

**用户读到的状态**: "树懒在努力尝试启动 / 还差一步就要喝"

**与 master quote 配合**:
- ✅ 适配: "再给我一秒, 我马上就要..." / "正在启动中"
- ❌ 不适配: PRD §5 C 锚点 "中间没连上" (这是"中间在连"不是"没连上")

**与角色名配合**:
- 命名建议: "差一点树懒" / "正在启动树懒" / "试图加速树懒"
- 风险: 名字偏积极, 用户读为"正在解决问题", 而 PRD §5 C 是"卡住"

**风险**:
- ⚠️ **不贴 PRD §5 C 内核** — 这是"启动尝试中"是动作叙事, 不是"未启动"是状态
- ⚠️ 视觉张力强 (有动作), 但语义偏离: 用户读为"努力尝试" → 偏向 "C 在解决"; 与 PRD §5 C "未启动" 反向
- ⚠️ Lucy quote 已 freeze (Fiona 23:33), 当前 master quote 走向 "中间没连上"; C-1 与已 freeze quotes 不对齐

**FAIL 标准**:
- 用户 5s 读判: 如读为"树懒在喝咖啡 / 准备喝" → C-1 视觉成立, 但语义 FAIL (因不贴 C "未启动")
- 角色识别度: ✅ (动作清晰)
- PRD §5 C 内核 fit: ❌
- master quote 配合: ❌

**适配评级**: **2/5** (视觉成立但语义偏离 PRD)

- 树懒坐着, 杯子放在腿上或桌面 (低位)

- 表情: **眼神失焦 + 嘴角微下垂 + 整体松垮**

**用户读到的状态**: "树懒喝过咖啡了, 但还是没用 / 自嘲式接受失败"

**与 master quote 配合**:
- ✅ 适配 (Lucy 已写过): "已经第二杯了, 还是没动" / "咖啡都凉了, 我也没启动"
- ⚠️ 接近 PRD §5 C 锚点但偏卖惨

**与角色名配合**:
- 命名建议: "失效树懒" / "白喝树懒" / "树懒模式 (已加咖啡)"
- 风险: 名字偏自嘲沮丧, 用户读为"摆烂"

**风险**:
- ⚠️ **接近 PRD §5 C 红线**: "不要真摆烂、不要甩锅、不要卖惨" — C-2 的"喝过 + 没用 + 翻倒空杯" 在中文社交语境读为"自嘲式摆烂"; 不至于 fail 但靠近边界

## §2 D 海星 — 3 方向草案

PRD §5 D 内核: "认真解释太累, 把状态变成一个怪但能懂的东西 / 离谱但成立 / 抽象、发疯、玩梗、精神跑偏但可读"

### D-1: "5 触手分散注意力" (multi-attention starfish)

**机制描述**: 海星 5 条触手向 5 个不同方向延伸, 每条触手末端有一个微小的细节 (不同小眼睛 / 不同方向小箭头 / 不同小符号), 中心**没有面部** — 海星天然没有前后, 强化"无主体注意力"

**构图**:
- 海星躺平, 5 触手向 5 个不同方向延伸 (不对称, 略微错位)
- 每个触手末端有个不同的小细节 (一个小眼往左看 / 一个小眼闭着 / 一个小箭头朝上 / 一个小问号 / 一个小波浪线)
- **中心没有大脸** (anatomy 上海星本来就没有, 强化"无主体")
- 颜色: 珊瑚红 + brush 笔刷
- 触手不在同一平面 (z 轴上有微差异)

**用户读到的状态**: "这只海星的注意力分散到 5 个方向 / 5 个分身在响应不同事 / 我精神跑偏但还在维持"

**与 master quote 配合**:
- ✅ 极强: "我现在朝五个方向同时响应" / "我开始海星了" / "我精神已经分到 5 个频道"

**与角色名配合**:
- 命名建议: "海星状态" / "五点海星" / "今日海星"
- 优点: 命名顺手, "海星状态" 是 Z 世代既有 social 用法

**优点**:
- ✅ **anatomy 天然资本**: 海星 5 触手 + 无前后是 D "抽象发疯"的视觉资源 (David 23:43 约束 2 "直接利用刻板印象")
- ✅ **避开"可爱怪"红线**: 没有大脸 / 没有萌眼 → 自动不可爱化
- ✅ **5 触手不同细节**是"分散注意力"的清晰视觉叙事, 不靠面部表情承载抽象
- ✅ 视觉读判门槛低: 5s 内能读出"5 个方向 / 5 个不同的小东西"

**风险**:
- ⚠️ 5 触手末端细节多, 在小卡 Block4 (140-180px) 下细节会丢失
- ⚠️ 触手末端如画"小眼睛", 容易滑向"5 个小可爱眼睛" → 萌化 (D 红线!) — 必须做成"墨点 / 简笔小符号"不是"卡通眼"
- ⚠️ 小细节如多到 5 种不同符号, 可能视觉信息过载, 用户读不出主线 — **建议触手末端只用 2-3 种细节交错** (不是 5 种全不同)

**FAIL 标准**:
- 用户 5s 读判: 如读为"5 个不同小东西 / 5 个方向" → PASS
- 用户 5s 读判: 如读为"海星 + 5 只小可爱眼" → FAIL (萌化, D 红线)
- 用户 5s 读判: 如读为"海星 + 装饰" → FAIL (没读出"分散")
- 角色识别度: ✅ (海星 anatomy 清晰)
- PRD §5 D 内核 fit: ✅ 极强 ("分散注意力" = "精神跑偏但还在")
- master quote 配合: ✅ 极强

**适配评级**: **4.5/5** (D 主推方向)

### D-2: "重叠错位海星" (glitch-overlap starfish)

**机制描述**: 海星整体**重叠两个版本**, 像数码 glitch, 中心位置错位 ~10-15px, 颜色稍稍不同 — "我有两个分身, 一个在认真, 一个已经飘走"

**构图**:
- 主体海星 (实色) 中心位置 (0,0)
- 第二个海星 (半透明 / 浅色) 中心位置 (15px, 10px) — 错位重叠
- 两个海星的 5 触手大致重合但**有 1-2 条触手指向略不同方向**
- 颜色: 主体珊瑚红, 影体浅色或互补色
- 没有面部

**用户读到的状态**: "海星出 bug 了 / 海星分身了 / 我已经分裂"

**与 master quote 配合**:
- ✅ 适配: "我现在朝两个方向" / "本体在这, 分身已经飘走" / "我开始 glitch 了"

**与角色名配合**:
- 命名建议: "glitch 海星" / "分身海星" / "出错海星"
- 风险: 名字偏技术, 用户认知门槛高 (Z 世代认 glitch, 但年长用户不一定)

**优点**:
- ✅ **抽象更直接**: 两个重叠的海星 = 直接视觉化"分裂"
- ✅ "Glitch 美学" 是 Z 世代既有审美, cultural fit 强 (David 23:43 约束 2)
- ✅ 避开萌化 (没有面部 / 没有萌系细节)

**风险**:
- ⚠️ 在打印纸感 (warm beige + matte) 母题里, "glitch 数码错位"调性可能与世界观冲突 — glitch 通常是 RGB 错位 / 数码感, vNext 母题是手绘墨水
- ⚠️ 需要做成"手绘墨水的错位" (例如纸张上画了两笔但位置不同) 才不破母题, 这增加执行难度
- ⚠️ 错位太微小读不出 (用户以为是印刷错误); 错位太大变成"两个海星" 不是"一个分裂海星"
- ⚠️ 在小卡 Block4 里错位读不出, 细节丢失

**FAIL 标准**:
- 用户 5s 读判: 如读为"两个海星" → FAIL (D-2 应该是"一个分裂海星", 不是两个独立海星)
- 用户 5s 读判: 如读为"印刷错误 / bug" → FAIL (glitch 美学不读出)
- 用户 5s 读判: 如读为"分身 / 错位" → PASS
- PRD §5 D 内核 fit: 中-强
- 与 vNext 世界观一致性: ⚠️ (glitch vs 手绘母题需手工调和)

**适配评级**: **3.5/5** (concept 强但执行风险高)

### D-3: "异常 anatomy 海星" (mutant-form starfish)

**机制描述**: 海星 anatomy 整体**反常但成立** — 例如 6 条触手 (而不是 5)、或 3 条触手 + 一只眼睛、或触手长成不同长度 + 末端不同颜色, 像生物变种 — "我不是标准状态"

**构图**:
- 海星躺平, 但触手数量异常 (6 条 / 4 条 / 3 条)
- 触手长度不一 (一条特别长, 一条特别短)
- 触手末端颜色不一 (一条触手末端是渐变色, 别的是实色)
- 中心没有面部 (沿用 D-1 anatomy)

**用户读到的状态**: "这只海星 anatomy 不对 / 它不是正常海星 / 我是变种"

**与 master quote 配合**:
- ✅ 适配: "我不是标准状态" / "我已经变种了" / "我 anatomy 出错"

**与角色名配合**:
- 命名建议: "变种海星" / "异常海星" / "海星 (野生版)"
- 风险: "变种"在中文 social 偶有负面联想 (生物学 = 突变), 不如 D-1 "海星状态"中性

**优点**:
- ✅ "anatomy 异常" 是 D "抽象发疯但可读" 的天然 metaphor
- ✅ 6 触手或 3 触手是清晰可读的"异常"
- ✅ 不需要画 multi-attention 小细节, 视觉简洁度高

**风险**:
- ⚠️ "anatomy 异常"在某些用户里可能引发不适 (生物畸形联想), PRD §5 D 红线 "精神疾病隐喻" 边界要警惕
- ⚠️ 6 触手或 3 触手如果做不到位, 会显得是"画错了 / 设计师水平差", 不是"故意异常"
- ⚠️ 触手数量异常的 anatomy 在 5 角色里是唯一"非标准生物"形态, 与 A 章鱼 (8 腿)、B 猫 (4 腿) 等标准 anatomy 形成断点

**FAIL 标准**:
- 用户 5s 读判: 如读为"anatomy 异常 / 变种" → PASS
- 用户 5s 读判: 如读为"画错了" → FAIL (设计感 vs bug 感边界破)
- 用户 5s 读判: 如读为"生物畸形 / 不适" → FAIL (PRD D 红线)
- PRD §5 D 内核 fit: 中-强 (异常成立但偏 "怪不是疯")

**适配评级**: **3/5** (concept 中等, 红线风险中)
