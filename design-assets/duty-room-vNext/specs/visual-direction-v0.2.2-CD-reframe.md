### 候选 C-α: 树懒趴桌睡着 + 旁边咖啡杯 (动物 + 道具, 状态换 sleep)

**3s 读判**: "树懒在睡 + 旁边有任务/咖啡" → "知道任务在那 + 人没启动"
**视觉清晰度**: 强 (睡 vs 不睡 是一眼能读, 比"喝/没喝"清晰 100x)

**与 master quote 配合**:
- ✅ "我都把咖啡端起来了, 中间这一步我不知道怎么走" — 不太适配 (这里树懒没端杯)
- ✅ Lucy 可改写: "咖啡是好咖啡, 但我已经睡着了" / "任务在那, 我在睡" / "我知道, 但我已经..."
- ✅ "树懒模式 + sleep on task" 是中文 social 既有印象 ("我在 task 旁边睡着了")

**与角色名配合**:
- 命名建议: "睡着树懒" / "桌前睡树懒" / "任务旁的树懒"
- 优点: "睡着" 是清晰状态, 命名顺手

**Block4 小卡 (140-180px) 读判**: ✅ 强 (树懒蜷睡 silhouette + 旁边小咖啡杯 prop, 都是 high-contrast 形状, 小尺寸不丢)

**风险**:
- ⚠️ 与 B 低能量睡觉猫 状态语义重叠 ("睡觉" 都用) — 但形态不同 (B 是猫 ball 蜷起来 / C 是树懒 sprawl 趴桌), 视觉差异强
- ⚠️ 用户可能读为"树懒累了在补觉", 偏向 B "离线" 而非 C "未启动"; 但 C 配桌 + 咖啡是 task context, B 没这些 → context 区分语义
- ⚠️ "桌面 + 课本/笔记本" 是 prop 堆叠风险 (你 23:46:55 C 不能装饰物堆叠) — 如简化为"咖啡杯一件 prop"则 OK

**FAIL 标准**:
- 3s 读为 "树懒在睡 + 旁边有任务" → PASS

**适配评级**: **4/5** ✅ 推荐

**FAIL 标准**:

## §2 D 抽象发疯 — 3 候选 (重做)

PRD §5 D 内核: "认真解释太累, 把状态变成一个怪但能懂的东西 / 离谱但成立 / 抽象、发疯、玩梗、精神跑偏但可读"

**Reframe 原则 (per Fiona 0:40:21)**: 抽象不靠 anatomy, 可来自**装扮 / 造型错位 / 身份混搭 / 画面逻辑失常**。

### 候选 D-α: 海星 + 反常装扮 (海星戴礼帽 / 海星打领带 / 海星带耳机)

**3s 读判**: "一只海星戴着礼帽" → "这不对, 海星不该戴礼帽" → "抽象 / 离谱 / 但能懂"
**视觉清晰度**: 强 ("海星 + 礼帽" 两个元素清晰可读, 抽象感来自"组合不合理")

**与 master quote 配合**:
- ✅ 强: "我现在戴着这个 (指礼帽), 别问" / "我是穿礼服的海星" / "我已经从海星升级了" / "我不解释"

**与角色名配合**:
- 命名建议: "礼帽海星" / "正装海星" / "海星先生"
- 优点: 命名顺手, "海星先生" 是 cultural surreal 命名 (大学生 Z 世代用法)

**Block4 小卡读判**: 强 (海星 silhouette + 礼帽 silhouette 都是 high-contrast 形状)

**优点**:
- ✅ **抽象来自"海星不该戴帽"的 surreal 逻辑** — 不是 anatomy 怪, 是装扮反常; 这正是 David "装扮可以表达抽象" 启发的直接 fit
- ✅ 用户 3s 读出 "海星戴礼帽 = 怪但成立"

**FAIL 标准**:
- 3s 读为 "海星戴礼帽" → PASS (抽象 metaphor 成立)
- 3s 读为 "可爱海星宝宝" → FAIL (萌化, D 红线)
- 3s 读为 "海星 cosplay" → 边界 (cosplay 是 cultural 既有, 是否 abstract 难判)

**适配评级**: **4/5** ✅ 推荐 (主推)
