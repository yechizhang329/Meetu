## §2 XHS 实证 5 条 Finding 重写视觉基线

### F1 文字主导 > 角色主导
- 10 条 7 条文字 ≥ 50% 画面
- statement headline (master quote) 是主视觉, 角色是注脚 1/3-1/2
- → vNext 结果页 Block2 角色卡需要重新分配视觉权重: **不是"大角色 + 小 quote"**, 是 **"大 quote + 角色注脚"**

### F2 meme 字幕格式 (白字黑描边顶部铺) 主流
- 样本 05 / 08 / 02
- 替代 v0.1 handwritten chat bubble
- 字号大, 字体粗黑体或圆体, 描边足以从任何背景跳出

### F3 真实动物摄影 + 反差小道具 = 全动物路线 XHS 落点
- 样本 04 卡皮巴拉墨镜 / 05 橘猫工位 / 08 橘猫话筒
- 用真实动物照片 + 拼贴 1 件人类道具 (墨镜/键盘/话筒) → "动物拟人"
- 比 v1 几何 vector animal 强 100x
- **与 vNext "全动物" 候选直接对应**

### F4 漫画+插画 XHS 主流 = 少女漫画风 (线稿 + 灰 flat + 夸张表情)
- 样本 06 低电量女宝
- 不是 Noritake 极简, 不是 irasutoya 日式纯色块, 是 **中国年轻女性熟悉的少女漫画感** (大头小身 + 哭脸/弓背夸张 + 灰 flat 着色 + 标题 emoji 装饰)
- vNext "漫画+动物" 路径锚点

### F5 配色 = 奶米 + 暖肤色 + 1-2 accent
- 主色: 奶米 `#FBF6E8` (与 v0.1 warm beige `#F1ECDF` 区别: 更白更亮, 不带土色)
- 暖肤色: 暖橙 `#C99459` 系 (动物毛色 / 角色发色)
- accent: 橙 `#E58D44` / 黄 `#F2C545` / 粉 `#FCE4E4` 1-2 个点缀
- meme 字幕色: 白底黑字 / 黑底白字 / 黄底黑字 (对比强但不饱和爆)
- **完全推翻 v0.1 摩卡棕 + 多巴胺撞色双 lane**

## §3 C/D pilot 重写 — 2-3 视觉路径

每路径锚定 XHS 样本, 标 PRD 适配度。

### Path P1 — "真实动物摄影 + 道具反差 + meme 字幕" (XHS 嘴替主流落点)

**视觉机制**:
- 真实动物照片合成 (写实拍摄, 不是插画)
- 加 1 件反差人类道具 (墨镜 / 话筒 / 键盘 / 工卡 / 文件夹)
- 顶部 meme 字幕 (白字黑描边, 大字)
- 底色: 真实场景 (办公室 / 桌面 / 水面) 或纯色

**XHS 样本锚**: 04 卡皮巴拉躺平 (10K👍) / 05 反骨摆烂橘猫 (7.5K👍) / 08 已读乱回橘猫 (61K👍)

**对 C 树懒适配**:
- 真实树懒摄影 (sleeping pose) + 旁边咖啡杯 + 课本拼贴
- 顶部 meme 字幕: "有在写论文吗？" / "缓存中"
- ✅ 强适配 C "未启动"

**对 D 猴适配**:
- 真实猴子摄影 + 顶键盘 (合成) + 拿香蕉
- 顶部 meme 字幕: "在打字吗？" / "404"
- 着装错位 (反穿 vest + mismatched 袜) 在真实摄影上**难做** (合成成本高)
- ⚠️ D 在 P1 路径下 "反常装扮" 视觉化困难; 但 "猴子 + 键盘 + 茫然" 本身就成立

**评级**: C 强 / D 中-强

**风险**:
- 真实动物图版权 / sourcing (需要可商用素材库, 不能直接 XHS 别人的图)
- 与 5 角色统一性: 如 A 章鱼 / E 刺猬 也走真实摄影路径, 摄影风格统一 (光线 / 视角 / 构图) 是新挑战
- 中文社交语境真实摄影 vs 插画的"产品记忆点": 摄影更易被读为"meme一次性", 插画更易"产品 IP"
- 章鱼水下摄影 + 海星 (David 已弃) / 树懒树上 — 5 角色是否都能找到合适真实摄影是问号

### Path P2 — "少女漫画风插画 + 大字标题 + 装饰图标" (XHS 漫画主流落点)

**视觉机制**:
- 手绘漫画线稿 (中等线条粗细, 黑色 outline)
- 灰 flat 或单色 flat 填色 (不水彩, 不 brush 阴影)
- 夸张表情 / 卡通比例 (大头小身, 但不 chibi)
- 顶部大字标题 (粉色或黑色, 描边或无描边, 手写感或粗黑体)
- 周围散落小图标装饰 (电池 / 拉伸小人 / 食物 / 表情符号)

**XHS 样本锚**: 06 低电量女宝 (22K👍)

**对 C 树懒适配**:
- 漫画线稿树懒 sprawl 趴桌, 哭脸或闭眼, 灰 flat 棕色填色
- 顶部大字: "树懒模式" + 小字 "改善小妙招"风格延展
- 周围散落咖啡杯 / 课本 / 闹钟 / spinner 小图标
- ✅ 强适配 C, 但 C 的 "卡住但不卖惨" 调性需要在哭脸表情上克制 (不夸张到沮丧)

**对 D 猴适配**:
- 漫画线稿猴子, 顶键盘, 反穿 vest + mismatched 袜
- 表情夸张 (X eyes / 茫然 zone-out), 灰 flat 棕色
- 顶部大字: "抽象猴" + 小字"输入失效"
- 周围散落 ??? / 404 / 乱码 / 香蕉小图标
- ✅ 强适配 D, "少女漫画 + 反常装扮"是 XHS 实证可行机制

**评级**: C 强 / D 强

**风险**:
- 滑向萌系日漫 (chibi / moe / 大眼) — 必须 negative 锁
- "少女漫画"性别绑定风险 — 需中性化处理 (无睫毛 / 无腮红 / 无心形)
- 5 角色一致性容易做 (同一画风延展 5 角色 OK)

**优点**: 5 角色统一性最强, 与 Lucy "F4 少女漫画风主流"直接对齐, 与 PRD §2.1 "女性 TA 早期采用"直接服务但不刻板

### Path P3 — "聊天截图 + 角色头像注脚" (XHS 嘴替原生 0-角色路径)

**视觉机制**:
- 微信/QQ 聊天 UI 截图风格 (白底 + 灰右气泡 + 绿对勾 + UI 元素)
- 主体是聊天文字内容 (master quote 作为聊天对话)
- 角色形象作为聊天小头像 (圆形 60×60px) 在气泡左侧
- 0 大角色, 100% 文字主导

**XHS 样本锚**: 09 互联网嘴替 (25K👍)

**对 C 树懒适配**:
- 聊天截图: 对方"DDL 写完了吗？" / 我 (树懒头像) "在了 没动 / 缓存中"
- ✅ 强适配 C "未启动" — 聊天对话天然带"被问 + 我答"context

**对 D 猴适配**:
- 聊天截图: 对方"你怎么穿的？" / 我 (猴头像) "??? / 我也不知道 / 反穿了"
- ✅ 强适配 D "抽象/逻辑错位" — 聊天答非所问是发疯文学 native 格式 (样本 08 同机制)

**评级**: C 强 / D 强 (但**牺牲角色视觉表达**)

**风险**:
- 角色形象退到 60px 头像, 5 角色辨识度全靠头像 — 头像设计仍是必需 (不能省视觉)
- "聊天截图" 调性偏 meme 一次性, 不是 brand IP
- 与 PRD §7.2 "Block2 当前嘴替角色卡 (角色形象 + 角色名 + style phrase + personality line + quote)" 结构冲突 — 角色卡是产品组件不是聊天截图

### §3 路径选择建议

| 路径 | C 适配 | D 适配 | 5 角色统一 | XHS 真实落点 | 角色 IP 留存 |
| --- | --- | --- | --- | --- | --- |
| P1 真实动物摄影 + meme | 强 | 中-强 | 中 (摄影 sourcing 难) | **极强** (3 样本支持) | 弱 (摄影一次性) |
| **P2 少女漫画 + 大字** ✅ | 强 | 强 | **强** | 强 (1 样本但代表性大) | **强** (插画 IP 可延展) |
| P3 聊天截图 + 头像 | 强 | 强 | 中 (头像统一可) | 强 (1 样本 25K) | 弱 (UI 不是 IP) |

**我的推荐: P2 少女漫画 + 大字标题 + 散落小图标** (主推)

P1 作为 "全动物风格" fallback (如 PM 想保留 v1 全动物方向延续, 但视觉升级到摄影 + meme 格式), P3 作为结果页**Block 备选版式** (不是 5 角色形态, 是结果页可选 layout — 适合"换个嘴替帮你说"用 chat 形式)

### §3.5 P2 主推 + P1/P3 局部混用方案 (可选)

如 PM 同意 P2 主推, **P1/P3 元素可在结果页 Block 局部混用**:
- 5 角色 main asset 走 P2 漫画 (所有角色卡都是漫画 IP)
- Block4 "换个嘴替" CTA 卡可借 P3 聊天截图风格 (角色头像作为聊天对话 sender, master quote 作为对话内容)
- "保存图" 模式可借 P1 meme 字幕格式 (白字黑描边顶部铺) 增强用户在 XHS 分享时的"原生感"

这是 vNext 在 P0 后扩展的方向, **本轮 C/D pilot 只测 P2 主推**。

- ❌ 摩卡棕主体 (XHS 实证不主流)

- ❌ 长睫毛 / 腮红 / 心形 / 粉甜女性化
