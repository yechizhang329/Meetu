## §0 设计判断起点

PRD §11.1 是这次重构的视觉核心一句话: **"设计不是先画动物再贴性格, 而是先理解每个角色的表达姿态再决定形象。"**

A/B/C/D/E 五个角色不是 "5 种不同动物 + 不同颜色", 而是 **5 种不同的"在场状态"** —— 它们存在的方式各自不同, 因此承载它们的视觉容器也应该不同。

**先回答 PM 验收点 1: 它们是什么类型的存在**

> 嘴替角色不是头像, 是用户面对外部询问时, **代表自己出场的那个分身**。

设计目标不是 "这是 TA 的卡通形象", 而是 **"当用户不想自己回答时, 这个东西在前面挡着"**。所以视觉体里必须有 "替身感 / 分身感 / 屏障感", 不是 "可爱 mascot"。

### Direction X — "拟态生物" (creature-as-state)

**形态**: 5 种**拟态半生物半物件**形态。不是猫狗鸡鸭, 而是把"那个状态"本身长成一个生物。

具体设想 (示意, 非锁死):
- A 嘴硬漏风 → 一只**外壳是装甲但缝隙在漏雾**的小生物 (硬壳 + 漏出的薄气, 可读"装得很硬但泄露了状态")
- B 离线挡门 → 一个**带"勿扰"挂牌的睡袋形生物**, 只露眼睛或只露顶, 整体卷起来 (像睡袋自己长了脸)
- C 加载未启动 → 一个**进度条形生物**, 身体是未充满的横条, 头是 spinner 图标 (但有表情)
- D 抽象发疯 → 一个**多通道存在体**, 主体在但有第二个分身已经飘到画面另一边 / 或者眼神分裂指向不同方向
- E 轻刺反骨 → 一个**带毛刺/反向毛刺的圆/刺果生物**, 但不是仙人掌那种锐利, 是 "毛茸茸但勿摸"

**视觉母题**: 手绘墨线 + 浅纸感水彩 / 局部不规则 + 内部有"机械/状态" 元素 (装甲缝、勿扰牌、进度条、分身、毛刺)

**优点**:
- 直接把"声线"翻译成"形态" — 用户不需要读名字就感到角色不同
- D 的"抽象发疯"能在形态层面就成立 (多通道存在体), 不靠名字解释
- E 的"刺"是形态特征不是表情, 不会沦为 "看起来很酷的角色"
- 不是动物, 自动避开"可爱 mascot"和"动物 vTuber"两种俗套

**风险**:
- 5 个形态完全异构, 母题统一很难; 处理不好会显得 "5 张不同风格图" (PM 验收点 2 红线)
- "拟态半生物" 用户认知成本可能偏高; 如果设计执行不到位会变成 "看不懂的乱形"
- 对设计执行依赖最高, 单点失败容易拖整组

**对 A-E 适配**:
- A: 强 (硬壳-漏雾对状态完美 mapping)
- B: 强 (睡袋-挂牌是社交边界的 metaphor)
- C: 中 (进度条形生物有点工具感, 需小心避免 "spinner icon 拟人化" 浅显)
- D: **极强** (多通道存在体是 D 主场)
- E: 强 (毛刺生物可执行)

### Direction Y — "桌面物件代言人" (object-as-spokes)

**形态**: 5 个**真实存在的桌面/校园物件**, 不长脸, 但通过姿态/装饰/状态成为代言人。物件本身就是嘴替, 不需要变成卡通角色。

具体设想:
- A 嘴硬漏风 → 一台**外壳完好但屏幕已经裂了一道缝**的小翻盖手机 (装得很好但泄露)
- B 离线挡门 → 一扇**贴着 "请勿打扰" 便签的门 / 或耳机** (戴上耳机的状态本身)
- C 加载未启动 → 一只**永远转圈的咖啡杯** (蒸汽是 spinner 形状, 但没真正动起来)
- D 抽象发疯 → 一个**正在分裂成两个 / 或者毛巾叠成奇怪形状**的物件 (桌面常见物件突然变成怪东西)
- E 轻刺反骨 → 一支**笔尖反向的笔 / 或一根橡皮筋绷着但没射出去**的物件 (蓄势但没攻击)

**视觉母题**: 物件实体感 (有重量、有阴影、有材质) + 手绘墨线轮廓 + 局部不规则细节 (缝、便签、蒸汽 spinner、毛巾褶皱、反向笔尖)

**优点**:
- "我不出场, 是这个物件代我说话" 直接对应 PRD §2.3 "替用户承担表达成本"
- 物件没有面部表情, 自动避开"被诊断/被定义"的防御 (PRD 原则 4)
- 5 个物件在桌面/校园场景都成立, 世界观天然统一 (大学生宿舍/课桌)
- 完全没有"可爱动物 mascot"风险 (D/E 红线最稳)
- 对女性用户友好但不刻板女性化 (物件没有性别标签)

**风险**:
- 缺乏"角色感", 用户可能觉得是图标不是角色 — Block2 角色卡需要靠名字 + quote + 姿态来注入人格
- 角色名要承载更多人格 (物件本身没名字, 命名压力大, 但这是文案侧问题不是设计侧)
- 对"换嘴替"的趣味性可能弱于生物方向 (用户会不会想"换个物件")
- C 的 "永远转圈的咖啡杯"和 D 的 "分裂物件"在执行上靠近, 边界要做出来

**对 A-E 适配**:
- A: 强 (裂屏手机是经典"装得很好"metaphor)
- B: **极强** (耳机/勿扰牌门是 B 主场)
- C: 强 (转圈咖啡 = 加载未启动 + 自嘲)
- D: 中 (分裂物件需要执行到位, 容易变成"奇怪物件"而非"抽象发疯")
- E: 中 (反向笔尖/橡皮筋抽象, 需要 quote 配合才读出"轻刺")

### Direction Z — "角色化道具人" (silhouette + signature prop)

**形态**: 极简 silhouette 半身像 (不画完整人脸 / 不画完整身体), 通过**单一标志性道具**和**剪影姿态**区分。是"5 种社交姿态的轮廓"。

具体设想:
- A 嘴硬漏风 → silhouette **戴着面具但面具上有裂缝**, 露出一点点真实
- B 离线挡门 → silhouette **戴着大耳机 + 帽兜**, 头压低, 整个人是个"屏蔽体"
- C 加载未启动 → silhouette **趴在桌子上**, 但手还握着笔/握着鼠标 (没启动但在岗)
- D 抽象发疯 → silhouette **同时两个轮廓重叠错位**, 像一个人但分身
- E 轻刺反骨 → silhouette **背对画面 + 手插兜**, 但侧脸有一点笑 (轻蔑但不撕破脸)

**视觉母题**: 大块剪影 + 一个 signature prop + 极简手绘墨线轮廓 + 单色 / 双色 (warm beige + 角色专色)

**优点**:
- silhouette 没有具体五官, 用户能投射自己的状态进去 — "TA 是我"感强
- 5 角色统一最容易 (都是 silhouette + prop, 母题硬绑定)
- Block4 小尺寸下 silhouette + prop 仍然可读 (不像生物形态在小尺寸丢细节)
- 不刻板女性化 (silhouette 中性)
- D/E 在 silhouette 形式下不会变成可爱怪/普通酷 (没有面部, 没有萌点入口)

**风险**:
- silhouette 容易变成"装酷"或"剪影艺术", 与 PRD §2.3 "低风险表达" 调性可能不符
- 比 X/Y 少一层"角色个性载体" — 没脸, 全靠姿态 + prop, 表达带宽窄
- D 的"两个轮廓重叠错位"如果执行不到位会显得"印刷错位 bug"

**对 A-E 适配**:
- A: 中 (面具 + 裂缝是个清晰但偏严肃的 metaphor)
- B: 强 (大耳机 + 帽兜是 B 完美 fit)
- C: 强 (趴桌但手在 prop 上)
- D: 弱 (silhouette 形式表达"分身"比生物形式难)
- E: 中 (背对 + 侧脸笑容偏抽象, 需文案配合)

### Direction W — "全动物升级版" (animal-upgraded, DavidC 22:40 强制比较)

**形态**: 5 种**真实可识别的动物**, 但绝不重复 v1.x 4 动物 (cat/goose/hamster/alpaca) 阵容; 视觉、表达、质感统一升级到一个产品的 final 水准。

具体设想 (示意, 非锁死, 选择动物时严格按角色声线 mapping, 不按"哪个动物可爱"):
- A 嘴硬漏风 → **章鱼** (8 条腿都很硬, 但身体本身是软的; 装得很硬但泄露; 章鱼变色伪装是天生 metaphor)
- B 离线挡门 → **乌龟** (天生的"离线挡门" — 缩进壳里就是边界; 不是"懒"是"入口关了")
- C 加载未启动 → **树懒** (动作慢但不是不行; 自知卡住但有自知; 慢=loading 而不是摆烂)
- D 抽象发疯 → **海星 / 章鱼变形态** (海星没有"前后"; 章鱼是异类身体; 抽象发疯靠 anatomy 异常成立)
- E 轻刺反骨 → **刺猬** (天生有刺; 蜷起来不撕破脸但提醒"别摸"; 反骨但体面)

**视觉母题**: 手绘墨线 + brush 笔刷阴影 + 浅纸感水彩底 + warm beige 暖色 + character-accent 局部点缀。**与 v1.x 关键区别**: 不再是 "圆头 + 两点眼 + 童趣贴纸感", 而是 inked editorial illustration with anatomy + posture (不是头像 icon, 是完整身体 + 姿态)。

**优点**:
- 动物作为载体在中文 social 语境强 (XHS/微博的"我的人设是 XX 动物" meme), 用户接受度天然高
- 5 种动物 anatomy 差异化天然 (章鱼 vs 乌龟 vs 树懒 vs 海星 vs 刺猬), 5 角色辨识度免费
- 不重复 v1.x 4 动物 (cat/goose/hamster/alpaca), 视觉上是新版本
- D 用海星/章鱼变形态可以承载抽象, 有 anatomy "怪"的天然资本
- "动物代我说" 在中文 social 语境是熟语, 用户自带"这是我的本命"投射

**风险**:
- **核心风险: v1.x 教训 (Jonathan 12:47 redline) 直接命中** — 用户已经在 v1.x 看过 4 动物 placeholder, 即便我们升级质量, 用户第一眼仍可能判定 "又是动物头像", 把 vNext 误读为 v1.x polish 而非 v2 重构
- 动物路线最难证明"质量已升级": 同样是动物, 怎么让用户感到"和 v1.x 不一样"? 风险在于即便质量升 50%, 也低于"重构形态" 给用户的认知冲击
- 动物形态自带"卡通 mascot" 引力; 不刻意拉开会自动滑向 cute IP 风, 进而 D 不可避免被"萌化", E 不可避免被"酷化" (PM 22:08:56 红线)
- 章鱼 / 海星 / 树懒在小尺寸 CTA 卡 (140-180px) 下 anatomy 复杂, 远不如 Y 物件 silhouette 清晰
- "刻板女性化" 风险在动物方向最高 (cute animal → 默认偏粉甜) — 需要刻意压调性
- 5 个新动物再放 36 张 receipt + 18 个组合, 工程接入复杂度同 v1.x (横躺章鱼 vs 站立刺猬 ratio 各异), v1.x 的 layout 教训会重演

**对 A-E 适配**:
- A: 强 (章鱼伪装 + 软腹是嘴硬漏风的好 metaphor)
- B: **极强** (乌龟壳 = 边界本质, B 主场)
- C: 强 (树懒慢 + 自知, C 主场)
- D: 中 (海星/变形章鱼有 anatomy 怪资本, 但会被"萌"拉走; 调教成本高)
- E: 中 (刺猬刺感天然成立, 但易被"小刺猬好可爱"消解; D/E 双双在动物路线最易被红线化)

### Direction V — "漫画人物 + 动物搭档/外化" (manga-human + animal hybrid, DavidC 22:40 强制比较)

**形态**: 主体是**简化漫画人物 (半身或上半身)**, 每个角色搭配一只**性格外化的小动物**或一个**动物式排版元素**, 形成"人 + 动物搭档" 双层人格。**不是萌系日漫的纯 IP, 也不是写实人像**, 介于两者之间, 偏 editorial 漫画。

具体设想:
- A 嘴硬漏风 → 一个**捂着嘴角的人**, 旁边一只**漏雾的小章鱼**贴在肩上 (人是嘴硬, 章鱼是漏出去的状态)
- B 离线挡门 → 一个**戴大耳机的人**, 旁边一只**缩在壳里的乌龟**当 prop (人是离线, 乌龟是边界外化)
- C 加载未启动 → 一个**趴在书桌上的人**, 旁边一只**慢动作的树懒**搭在桌沿 (人是卡住, 树懒是 loading 外化)
- D 抽象发疯 → 一个**眼神跑两个方向的人**, 旁边一只**海星形错位生物** (人是分裂, 海星是抽象具象化)
- E 轻刺反骨 → 一个**手插兜微侧脸的人**, 旁边一只**蜷起来的刺猬** (人是反骨, 刺猬是边界外化)

**视觉母题**: 手绘墨线漫画 + 黑白主调 + 单色 accent + 人物简化轮廓 (≠ 写实, ≠ 萌系少女漫画) + 动物作为性格 sidekick

**优点**:
- "人 + 动物" 双层 — 用户既能投射进人 (TA 像我), 又能感到动物在外化情绪 (我的状态被具象化), 是双倍代入
- 漫画人物处理得当能完全避开 "刻板女性化" (用 editorial 漫画风, 不画女性二次元)
- 5 角色都有"人"作主体, 角色感最强 (用户更容易把 TA 当作"我的嘴替"而不是"一个工具")
- 动物作 sidekick 而非主角, 避免动物路线的 cute mascot 引力
- 在 Block2 大图 + Block4 小图都成立 (人物半身在小尺寸下也有面部 / 姿态识别度)

**风险**:
- **执行难度最高**: editorial 漫画人物对画技要求 > 物件 > 动物; AI 生图 (image2) 在"editorial 漫画"风格上 consistency 差 (容易滑向萌系 / 美式卡通 / 写实, 5 角色面部一致更难)
- 5 角色都有"人脸" → 用户可能感到"不像我" (脸不一样), 反而比物件/动物投射难
- "人物 + 动物" 双元素让 5 角色构图复杂度翻倍, 35 张资产 (5 角色 × 7) 工作量 = X/Y/Z 的 1.5-2 倍
- 漫画人物刻板性别风险隐性存在 (画了"人脸"就有性别表达); 想做成中性需要刻意压风格
- 5 个不同角色配 5 只不同动物 = 视觉信息量翻倍, 在小尺寸 Block4 卡片极易超载, 可读性比单元素方向都低
- 与中国大陆社交语境的视觉默认风 (XHS / 小红书 illustration) 距离最远; 用户接受度需测试
- D 的"眼神跑两个方向" + 海星错位 = 双重抽象, 容易变看不懂; 比 X/Y 都难调

**对 A-E 适配**:
- A: 中 (人捂嘴 + 漏雾章鱼组合可读, 但人脸增加表情噪音)
- B: 中-强 (人戴耳机 + 龟 sidekick 信息量略多, 但 metaphor 清晰)
- C: 中 (趴桌人 + 树懒, 但 "趴桌" 在小尺寸损失大)
- D: 中-弱 (双重抽象互相打架, 调教成本高)
- E: 中 (人 attitude + 刺猬, 但人 attitude 难做"轻刺不撕破脸"的微妙度)

---

**推荐: Direction Y (桌面物件代言人)**, 备选: Direction X (拟态生物) 作为 D 角色单点 fallback

### 推荐理由

1. **PRD §2.3 直接对应**: PRD 把核心问题定为 "用户不想亲自承担表达成本"。Y 的核心命题 "我不出场, 是这个物件代我说话" 是这句话的最直接视觉翻译。X 是把状态外化成新生物, Z 是把用户外化成 silhouette — 都没 Y 这么贴。

2. **避免防御心理 (PRD 原则 4)**: Y 没有面部, 用户不会觉得 "这个角色在评价我"。X 有半生物面部, Z 有 silhouette 姿态, 都比 Y 更容易触发 "TA 在看我"。

3. **质量线统一最稳**: 桌面物件天然在同一世界观 (大学生宿舍/课桌), 5 角色画风一致风险最低。X 5 个生物形态完全异构母题统一最难; Z silhouette 母题统一容易但表达带宽最窄。

4. **不刻板女性化**: 物件没有性别。 X 的"萌生物"和 Z 的 silhouette 都有刻板风险 (前者偏可爱, 后者偏酷)。

5. **D/E 红线 (PM 22:08:56 强调)**:
   - D 不可爱化: Y 用"分裂物件 / 怪奇物件" 表达 D, 不依赖面部表情, 自然不可爱
   - E 不普通酷化: Y 用"反向笔尖 / 张力橡皮筋" 表达 E, 是结构性张力不是 attitude pose

### 单点 fallback: D 借 X 形态

Y 的最大风险是 D 弱。如执行 Y 时 D 的 "分裂物件" 调试 3-5 次仍读不出 "抽象发疯" (而是显得"奇怪物件"), 我建议:

**D 单点切到 X 形态**: 一个 "多通道存在体" 半生物。其他 4 角色仍是 Y 物件, D 是异类。

这违反 §1 "5 角色统一世界观" 但是合理的: D 在 PRD §5 里本身就是 "把状态变成怪东西", 它在系统里就是异类。视觉允许它异类反而强化 D 的产品定位。

**如要用单点 fallback 必须在 v0.2 设计稿同步给 PM 二审**, 不私自切。

## §2.5 PM 4 问对比矩阵 (DavidC 22:40 强制 W/V 比较 + PM 验收点 4)

## §3 5 角色统一世界观 (PM 验收点 2)

无论选 X / Y / Z, 5 角色必须共享:

### §3.1 视觉母题 (Y 路线锁定)

**母题**: 大学生桌面 / 宿舍角落 / 课桌 / 自习室角度的真实物件, 静态摆放, 无人物

- **画法**: 手绘墨线轮廓 + 浅纸感水彩填色 + 局部不规则细节 (≠ 数码矢量平涂, ≠ 卡通 mascot, ≠ 写实摄影)
- **质感**: matte / 哑光 / 有重量感 / 有阴影 (落在桌面或纸面)
- **色温**: warm beige #F1ECDF 系作为底盘, character-accent 仅作物件局部点缀 (杯沿、便签纸、笔尖等), 不整体平涂 accent
- **画幅**: 物件占画面中央, 4 周留白, 单物件不带场景纵深

### §3.2 差异化层 (PM 验收点 2: 差异来自姿态/道具/构图, 不来自换画风)

5 角色画风完全一致, 区别只在:

| 角色 | 物件 | 状态/破绽 | 道具 | 构图节奏 |
| --- | --- | --- | --- | --- |
| A 嘴硬漏风 | 翻盖手机 | 屏幕一道裂缝 | 无 | 中央正放, 整齐但内部破裂 |
| B 离线挡门 | 头戴耳机 / 勿扰挂牌 | 物件本身=边界 | 便签 "勿扰" | 居中正面, 静止, 无干扰 |
| C 加载未启动 | 咖啡杯 | 蒸汽是 spinner 形状 | 杯垫便签 | 中央, 蒸汽往上但停滞感 |
| D 抽象发疯 | 一个物件 + 它的另一个版本 | 同物件错位重叠 / 或异常摆放 | 多副本 | 不对称 / 错位 / 反常构图 |
| E 轻刺反骨 | 笔 / 橡皮筋 | 笔尖反向 / 橡皮筋绷紧 | 紧绷 / 张力 | 对角线, 有方向但未释放 |

### §3.3 不允许跨角色混用

- 不允许 A 用动物形态 (会破坏 Y 母题)
- 不允许 D 用真实摄影写实 (会破坏 §3.1 画法)
- 不允许 E 用面部表情表达 attitude (Y 母题没有面部)

## §4 Block2 当前嘴替角色卡方向 (PM 验收点 3)

PRD §7.2 要求展示: 角色形象 + 角色名称 + 风格短语 + 一句人格描述 + 一条角色 quote。**不展示 "它适合你"。**

### §4.1 卡片视觉结构 (Y 路线)

```
┌─────────────────────────────────┐
│                                 │
│    [物件大图  约占 60% 高度]      │   ← 角色形象主区, 让物件本身 "在场"
│                                 │
├─────────────────────────────────┤
│  角色名 (handwritten title)      │   ← 角色名称
│  风格短语 / personality line    │   ← 一句人格状态, 不解释
│  ─────                          │
│  「quote 文字」 (italic / 手写)  │   ← 一条 quote, 像角色自己说的
│                                 │
└─────────────────────────────────┘
```

### §4.2 关键视觉决定

1. **物件大图占主导**: 不是 "小角色头像 + 大段说明", 是 "物件就是主体, 文字像物件下方的标签"
2. **角色名用手写字体, 不用 Sans-serif 标题**: 让名字本身有"角色在签名"的感觉, 不是产品组件标题
3. **quote 用 italic 或 hand-written, 不与正文同字体**: 与 personality line 视觉区分; quote 是"角色在说话"
4. **没有 "适合你" / "推荐使用" / "TA 帮你" 这类文案出现**: 卡片不解释适配
5. **没有 emoji 装饰**: 与 v1.2 教训一致 (Final 红线 §0 F2)

### §4.3 让用户感到"TA 在替我说" (PM 验收点 3)

- 物件状态本身是用户当下状态的镜像 (例: 用户选 S2 + B → 看到一个戴着耳机贴勿扰的物件 → 用户立即想"对, 我现在就是这个状态")
- quote 不是产品文案而是物件 "替自己说" 的声音 (例: B 的物件 quote 是 "信号好像不太行" 而不是 "我不想理你")
- 物件下方留一行小字 "本次出场: B" (不是 "你被分配到 B 角色"), 强调"出场代理"而不是"角色推荐"

## §5 Block4 备选嘴替 CTA 卡片方向 (PM 验收点 3)

PRD §7.4 要求每张卡: 角色形象 + 角色名称 + 风格短语 + 可选 quote preview。

### §5.1 小尺寸约束

CTA 卡通常宽 ~140-180px, 高 ~200-260px (假设手机 H5)。物件需要在小尺寸下仍可读为"它是谁"。

### §5.2 卡片视觉结构

```
┌──────────────────┐
│                  │
│  [物件 缩略]      │   ← 占卡片 50-55%, 不被压成 icon
│                  │
├──────────────────┤
│ 角色名 (手写)     │
│ 风格短语 (一行)    │
│ "quote..." (1行) │   ← 极短 quote preview, ≤14 字
└──────────────────┘
```

### §5.3 不变成"普通头像列表" (PM 验收点 3 关键)

- **不裁切成圆形 / 方形 mask**: 物件以原比例显示, 顶部对齐或居中
- **不用统一裁框**: 5 角色物件比例本身不同 (手机 vs 笔 vs 杯), 不强制等宽等高 → 反而强化"它们不一样"
- **角色名用手写字体, 不用 system label**: 与 Block2 一致
- **quote preview ≤ 14 字**: 长 quote 在小尺寸读不下, 用 "..." 省略反而破坏代入感
- **无 hover/focus state 用 saturated bg**: 选中态用 character-accent 在物件下方一道下划线 (不淹掉物件)

### §5.4 让用户一眼感到"换的是谁"

- 物件辨识度 > 名字辨识度 (用户记得"那个戴耳机的"比记得"角色 B"更容易)
- 5 个 CTA 横排时, 每个物件视觉重量接近, 不让某个物件喧宾夺主
- quote preview 用 "TA 会说的话" 的极短截取, 不是 "TA 的功能"
