## 1. 三套方向通用底层（不变）

Fiona 加强口径：**3 套都要是"心情值班室嘴替系统"的完整表达**，不是独立风格堆砌。

通用底层：
- 4 个角色（嘴硬鹅 / 低电量猫 / DDL 仓鼠 / 后台羊驼）不变
- 嘴替机制不变（角色替我说一句话）
- 用户路径不变（首屏 → 选场景 → 结果页 → 保存分享）
- 输出图 4:5 (1080×1350) 不变
- 字体系统每套独立确定，但必须可商用

**三套方向的差异 = 对"嘴替"这一产品定义的不同视觉语言诠释**：
- A：**微信状态宇宙观**（状态框 + 可爱挂件 + 超短文案）
- B：**抽象情绪画报**（饱和色块 + 角色挂件 + 梗字体 + 抽象边框）
- C：**角色语录本**（复古本子 + 对话气泡 + 动物"作者署名" + 页码感）

B 不默认走 UI 梗图（iPhone 弹窗 / 群聊截图），改走"画报感"，避免梗图惯性。

## 2. 方向 A：微信状态宇宙

### 2.1 一句话定义
> 整套 H5 = 微信状态的宇宙；每个角色是一种"状态挂件"；用户进来是**"今天挂哪个状态"**。

### 2.2 为什么 18-24 女大学生会愿意发
- 直接嫁接她们**真实已经在用**的分享载体（微信状态）
- 输出图可直接**做微信状态背景图**（4:5 或 1:1 都兼容）
- "挂件 + 状态"是她们熟悉的语言（微信状态支持挂件已三年）
- 角色作为挂件 = 萌系陪伴 + 不尴尬

### 2.3 色调
- 每个角色绑定**一种饱和度较高、但不刺眼的情绪底色**：
  - 低电量猫：**薄荷湖绿** `#9DD4C5` 配暖橙挂件
  - 嘴硬鹅：**奶黄** `#FFE8A3` 配米白挂件
  - DDL 仓鼠：**蜜桃粉** `#FFC8B5` 配鹅黄挂件
  - 后台羊驼：**雾霾紫** `#C9B8E8` 配奶白挂件
- 微信状态式**渐变气泡**：每个底色配 10-15% 饱和度浅色渐变过渡
- 桌面背景 / 便签 全部扔掉

### 2.4 字体策略
- 主字体：**阿里巴巴普惠体 Heavy**（免费商用 / 比 STHeiti 有力度 / 比仓耳今楷免费）
- 辅助：**霞鹜文楷** Light（只用于作者署名 / 角色小号，不做主句）
- emoji：**默认微信表情**（复制即用，不是 emojione / twemoji）
- 禁止：STHeiti / PingFang 系统黑体（太 office）

### 2.5 输出图版式（1080×1350 4:5）
```
┌─────────────────────────┐
│ [饱和色渐变底]           │
│                         │
│   [角色挂件]             │  ← 角色以"挂件"姿态置中，半身
│                         │
│  "人在。电不在。"         │  ← 阿里普惠体 Heavy 超大
│                         │
│ ─────                    │  ← 状态常见的弱分隔线
│ — 低电量猫 · Meetu      │  ← 作者署名，轻
└─────────────────────────┘
```
关键差异：**没有桌面 / 没有便签 / 没有胶带**，完全是"状态气泡"的视觉语法。

### 2.6 H5 三页 UI 变化（不再统一暖纸米）

| 页 | 主视觉载体 |
|---|---|
| 首屏 | 微信状态一样的**状态选择器**（水平滑动 4 个角色，每个角色独立饱和色卡） |
| 选场景 | 8 个场景 = 8 个**状态候选气泡**（气泡式，不是便签；文字超短） |
| 结果页 | 中央大号**状态挂件**（全屏饱和底 + 角色 + 文字），下方按钮 |

三页各自有独立色调/布局/视觉节奏，不是"同一张桌面切三次"。

### 2.7 哪里不像产品截图
- 整张图去掉所有"界面装饰"（桌面/便签/胶带/回形针/笔迹）
- 保留的只有：**饱和底 + 角色 + 文字 + 极轻署名**
- 看起来像"用户朋友截图给我的"，不像"某 App 导出的"

### 2.8 风险
- 极度依赖阿里普惠体 / 霞鹜文楷的实际字体渲染效果
- 角色挂件姿态 task #31 已出可能不完全匹配"挂件感"，可能需要补极轻微修（单角色 1 call）
- Dave H5 theme 需改（但 task #32 架构保留：首屏/选择/结果三页 + 按钮层级 + 硬约束 2 条）

## 3. 方向 B：抽象情绪画报

### 3.1 一句话定义
> 整套 H5 = 一张会翻页的"情绪画报"；每翻一页是一个角色+一句嘴替；画报自带抽象边框/文字环绕/饱和色块。

### 3.2 为什么 18-24 女大学生会愿意发
- "画报"感在 XHS 高阶美学爆款里非常流行（杂志封面 / Cover Art / Zine）
- 抽象文案本身就是爆款（"抽象文案"3.8 万赞），配上画报封面语法 = 直接上 XHS
- 比方向 A 更"有设计感"（Jonathan 要的），比方向 C 更饱和

### 3.3 色调
- **每个场景 + 角色组合 = 一张独立色卡**（而不是固定 4 色）
- 色卡候选：**Risograph 印刷色**（荧光粉 `#FF2E8B`、冷蓝 `#2E5FFF`、铁锈红 `#C9452E`、柠檬黄 `#FFE500`、松石绿 `#19B3A6`）
- 色块高饱和但是**颗粒纸质纹理**（像老杂志印刷），避免纯色油腻
- 文字可多色（双色 / 三色并存）

### 3.4 字体策略
- 主字体：**思源宋体 Heavy**（开源免费商用 / 有情绪）+ **仓耳今楷**（正式商用需购买，作 P1 升级位）
- 画报副标题：**汉仪玄宋 Bold** 备选
- 文字排版允许**竖排 / 倾斜 / 裁切出界**（画报语法，非标准网页）
- 禁止：任何圆体 / 黑体 / 手写体

### 3.5 输出图版式（1080×1350 4:5）
```
┌─────────────────────────┐
│ [Riso 饱和色块]          │  ← 不是纯色，是色块+颗粒
│  ┌──┐                   │
│  │#01│    "人在。"        │  ← 编号（像杂志目录）
│  └──┘                   │
│         "电不在。"        │  ← 文字可倾斜 / 出界
│                         │
│       [角色剪影]          │  ← 角色半身，被色块/文字部分覆盖
│                         │
│ vol.03 / 心情值班室       │  ← 杂志式页脚
└─────────────────────────┘
```

### 3.6 H5 三页 UI 变化

| 页 | 视觉载体 |
|---|---|
| 首屏 | **画报杂志封面**（大字 "Vol.01 · 今日值班" + 4 角色 Riso 剪影） |
| 选场景 | **画报目录页**（8 个场景像杂志目录，编号 + 题目 + 轻描述） |
| 结果页 | **翻到某一页**（像真翻开一本画报，角色 + 文字 + 色块） |

### 3.7 哪里不像产品截图
- 整套视觉是"杂志 / Cover Art"语言，不是"App UI"语言
- 用户发出去像发了一张 Zine 封面，不像发了一张产品结果图

### 3.8 风险
- Riso 颗粒色块需要真正的颗粒纸纹理，否则就是"饱和色油腻"
- 思源宋体 Heavy 在移动端小号渲染要注意字距
- **最大风险：美学门槛偏高，审美不匹配的用户觉得"像设计师在炫技"**——Fiona msg `9ee724ff` 的警告：不要变成"设计师生意感"

## 4. 方向 C：值班室语录本（复古本子）

### 4.1 一句话定义
> 整套 H5 = 一本可以翻页的 "心情值班室" 语录本；每页是一个角色 + 他/她的一条语录（嘴替句）；像小时候传阅的手写笔记本，或老一点的摘抄本。

### 4.2 为什么 18-24 女大学生会愿意发
- 手写笔记本 / 摘抄本 / 黄色便签美学在 XHS 常青（"自存抽象文案"3.7 万赞，很多是手写/摘抄）
- 比方向 A 更复古、更私密、更像"我自己的小本子"
- 比方向 B 更温暖、更可爱、更亲近
- 作者署名 = 动物本人（"— 低电量猫 2026.5.9"）制造**语录卡的仪式感**

### 4.3 色调
- **本子纸色**：米黄 `#F5E8C8` / 偏白 `#FAF5E8`（保留，但不像 v0.3 那么压迫）
- **本子封面色**：深胡桃 `#6E4A32` / 深绿 `#3E5743` / 暗红 `#7E3B3B`（不同场景不同本子）
- **笔迹色**：深蓝 `#2C3E7A` 或 暗棕 `#5A3826`（像真笔墨）
- **点缀**：贴纸 / 荧光笔色块 `#FFE500` / `#FF9F85` 少量点缀

### 4.4 字体策略
- 主字体：**站酷快乐体**（完全免费商用 / 有手写感 / 年轻不 office）
- 辅助：**霞鹜文楷** Regular（署名 / 日期 / 页码）
- 文字排版**模仿真手写**：微倾斜、局部加粗、偶尔划线、偶尔批注红圈
