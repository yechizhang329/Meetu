## 1. Loopy（露比）

**用户发它是在表达什么？**  
"今天我也是这样." Loopy 单角色但有 100 种姿势：仰躺、瘫桌、捂脸、奔逃、哭、嘲讽、惊呆。每个姿势就是一个状态。用户发的不是 Loopy，是 Loopy 在做的那个动作。

**图里哪个元素让她敢发？**  
**没有产品框 / 没有水印 / 没有出处**。Loopy 表情包是裸的 PNG，原始截图就发，看不出"从哪个 app 来"。这是产品边界感的对立面。

**朋友看到怎么接话？**  
"你今天怎么这么 Loopy" / "我也是" / "呜呜" — 朋友直接 mirror 状态。关键在于角色名变成了形容词。

**视觉上哪里年轻/鲜活/有个性？**  
- 黑线偏粗（比 v0.9 还粗）
- **单色填充**（粉色 = 露比 / 黄色 = 朋友 Pinkfong），整张图就 1-2 个主色
- 角色姿势夸张但不是 chibi，是"成年人摆烂"
- **永远没有完整背景**，纯白底或纯色底直接发

**我们能借什么 / 不能借什么？**  
- ✅ 借：单色底 + 单色角色 + 黑线 / 一只动物多状态变形 / 没有产品边界感
- ❌ 不借：粉色作为绑定色（女大已审美疲劳）/ 韩系特征明显（Meetu 偏中性大学风）

## 2. Capoo（咖波）

**用户发它是在表达什么？**  
"我今天有点儿不正经" / 反讽 / 阴阳怪气 / 以小欺大。Capoo 的张力是它的"小猫但是有刀"——可爱的反面是恶意。

**图里哪个元素让她敢发？**  
**它跟主流"萌系"是反的**——所以发 Capoo 的人在表达"我不要可爱我要怪"。这是身份信号。

**朋友看到怎么接话？**  
"哈哈哈哈哈我也想这样" / "笑死" — 朋友 reaction 是笑，不是同情或感叹。重点：**笑点是图自带的，不是文案给的**。

**视觉上哪里年轻/鲜活/有个性？**  
- 双色（蓝猫 + 黄/绿/红辅）
- 表情极简（两个黑点眼）但姿势暴力
- **大量"超出画面边界"构图** — 角色一半在外
- 用粗黑边框框住，刻意做出梗图感

**我们能借什么 / 不能借什么？**  
- ✅ 借：双色（暖纸米 + 1 个角色色压主） / 角色超出画面 / 不对称构图 / 一点"坏脾气"
- ❌ 不借：暴力 / 攻击性（Meetu 是嘴硬不是拍桌）

## 3. Chiikawa（吉伊卡哇）⭐ 与 Meetu 最近

**用户发它是在表达什么？**  
"我又苦又累又没用又有点想哭但我假装没事". 这就是 **Meetu 心情值班室的核心情绪光谱**。Chiikawa 的角色全部在 "弱小 / 卑微 / 哭兮兮 / 但还在努力" 这个区间。

**图里哪个元素让她敢发？**  
- 角色比她"更惨"——所以分享是 self-projection 的投射保护
- 角色还在保持小尊严（嘴硬：「ま、まだだよ」 / 「きっと、なんとか」）
- **画面留白足，朋友可以加自己的话**

**朋友看到怎么接话？**  
"你怎么哭兮兮的" / "你今天就是吉伊卡哇" / "抱抱" — 朋友 mirror 情绪并且参与。

**视觉上哪里年轻/鲜活/有个性？**  
- 米白底 + 角色单色（粉/黄/灰）
- **手绘感线条**（不是工业级粗黑边）
- 字号大、字数少、留白多
- **永远不画完整场景**，最多一个台阶 / 一棵树 / 一个杯子

**我们能借什么 / 不能借什么？**  
- ✅ 借：弱角色调性（"我没电"≈"ま、まだだよ"）/ 留白多 + 角色站在留白中 / 嘴硬但弱
- ⭐ Meetu 已经走在这个方向上，但**线条太工整**，需要更"手画"
- ❌ 不借：哭兮兮的眼泪（Meetu 是嘴硬，不是哭）

## 4. 玛卡巴卡 / Makka Pakka

**用户发它是在表达什么？**  
"我不想跟你们说话." 玛卡巴卡的核心是"自言自语 + 拒绝沟通 + 不解释"。被中文互联网二次创作成"高傲社恐"的代表。

**图里哪个元素让她敢发？**  
**它什么也不解释**。一张图一个表情一个动作一句胡言乱语。这给了用户"你看不懂没关系，我也没要你看懂"的态度。

**朋友看到怎么接话？**  
朋友不接话也行，发这个就是表达"我现在不想说话"。**这是反社交的社交货币**——分享是为了说"别找我"。

**视觉上哪里年轻/鲜活/有个性？**  
- 永远是真实截图（电视剧 vibe），有视频颗粒感
- 字幕带 BBC 蓝条
- **完全没有产品味**，因为本来就不是产品

**我们能借什么 / 不能借什么？**  
- ✅ 借：「不解释 / 自言自语」作为语气基线（已经是 Meetu 第一人称语气）
- ✅ 借：分享 ≠ 表达"看见我"，可以是表达"别看见我"
- ❌ 不借：截图复古风（Meetu 是设计原创）

## 5. LINE Friends Brown 系（Brown / Cony / Sally）

**用户发它是在表达什么？**  
极广光谱：开心 / 哭 / 翻白眼 / 干杯 / 摆烂 / 困 / 聚会 / 拒绝。Brown 系是**情绪通用接口**。

**图里哪个元素让她敢发？**  
- 100+ 状态贴纸库——总有一个像我今天
- 单角色但情绪覆盖足
- **官方贴纸有一致美学**，所以多张混发不违和

**朋友看到怎么接话？**  
往往用另一张 Brown 贴纸回应——构成"贴纸对话"。这是表情包社交的核心。

**视觉上哪里年轻/鲜活/有个性？**  
- 圆润不卖萌（Brown 是"沉默熊"，不甜）
- 黑线 + 棕白二色
- **同一姿态库 ×4 角色** = 工业化复制可识别

**我们能借什么 / 不能借什么？**  
- ✅ 借：1 角色 ×N 状态的资产生产逻辑（Meetu 4 角色 × 6 场景 = 24 状态贴纸库）
- ✅ 借：圆润但不卖萌的中间路线
- ❌ 不借：官方贴纸的"完成度"——太完整反而不自由

## 6. 网易云分享卡

**用户发它是在表达什么？**  
"今天的我和这首歌一样." 把歌词当自己的状态宣言。

**图里哪个元素让她敢发？**  
- **黑底白字大字号**——视觉冲击力强，朋友圈缩略图也能看清
- 不带网易云产品框——只在底部一行小字署名
- **文字是主体，视觉是包装**——图就是字的载体

**朋友看到怎么接话？**  
评论区接歌词 / 接经历 — "我也好喜欢这首" / "这就是你今天" — 因为图里的话足够通用。

**视觉上哪里年轻/鲜活/有个性？**  
- **不是清爽米黄底**，是几乎纯黑或暗紫
- 大字号（48-72pt） + 极简版式
- **几乎没有装饰**——整张图就是"一句话 + 一点视觉信号"

**我们能借什么 / 不能借什么？**  
- ⭐ 借：**字 = 主体，视觉 = 包装**（Meetu 当前是反过来：角色主体，字辅助）
- ⭐ 借：底色不一定要米黄；可以**让角色色把整张图压住**（如低电量猫整张图大半橙色）
- ⭐ 借：极小品牌字（不是顶部 banner），底部一行 12px 即可
- ❌ 不借：黑底（与 Meetu 暖系不合）

## 7. 小红书"班味"梗图

**用户发它是在表达什么？**  
"上班好累 / 同事好烦 / 今天又被甲方折磨". 班味梗图是**集体抱怨容器**。

**图里哪个元素让她敢发？**  
- 极致暴露（"我是没救了"、"我恨周一"）但用幽默包住
- **图里的话越离谱越好**——离谱是社交豁免权
- 字数少、字大、留白足

**朋友看到怎么接话？**  
"我也是" / "你完了" / "求生欲呢" — 评论里全是镜像状态。**朋友不需要安慰，只需要 me too**。

**视觉上哪里年轻/鲜活/有个性？**  
- **不对称构图**：常常是上半部一张随手图（自拍 / 屏幕 / 桌面）+ 下半部加一句话
- 字体常用粗黑（汉仪糯米团、字魂超玩魔方等）
- **故意做粗糙**——抖动字、错位、重叠 — 这是反"产品光泽"

**我们能借什么 / 不能借什么？**  
- ⭐ 借：上图下字的 60/40 不对称分配（替代当前 v0.9 的"角色居中 + 文字下方"对称布局）
- ⭐ 借：故意"粗糙感"（手画线条 / 字稍微歪一下 / 角色不正中）
- ❌ 不借：粗黑暴力字体（Meetu 仍要保持温度）

## 8. 朋友圈 / 微信状态 / WeChat status

**用户发它是在表达什么？**  
"我现在这样." 极简。状态 ≠ 故事 ≠ 解释，状态就是状态。

**图里哪个元素让她敢发？**  
- **门槛极低**——不需要构图，不需要发图，可以纯文字 + 一个 emoji
- 系统给的状态标签（emoji + 文字）规范化但不僵化
- **状态会自动失效**（24 小时 / 当日）—— 没有"永久公开"焦虑

**朋友看到怎么接话？**  
点击 emoji 进入对应群体 / 给状态点赞 / 评论一句 — 互动门槛极低。

**视觉上哪里年轻/鲜活/有个性？**  
- emoji + 文字组合本身就是一种新视觉语言
- 字号大、内容短、不解释
- **不是图 = 视觉，文字 + 一个符号 = 视觉**

**我们能借什么 / 不能借什么？**  
- ⭐ 借：低门槛感 — 用户不应该觉得自己在"完成一次创作"
- ⭐ 借：emoji 加文字的简洁组合（Meetu 可以是"角色图标 + 一句话"）
- ❌ 不借：完全去图（Meetu 的核心是动物代理，不能纯文字）

## 9. XHS 高互动状态贴纸 / 手帐

**用户发它是在表达什么？**  
"我今天有这种感觉." 不是宣言，是日记。

**图里哪个元素让她敢发？**  
- 像她自己手做的——视觉门槛低
- **不像产品发布**——没有官方水印，没有版式约束
- 手帐美学包含"不完美"作为标志

**朋友看到怎么接话？**  
"你也开始记了 / 一起记" / "好可爱"——朋友 mirror 行为而不只是 mirror 情绪。

**视觉上哪里年轻/鲜活/有个性？**  
- 米色底 / 奶油底 / 浅燕麦
- **混合纸纹质感 + 手写字 + 简笔画 + 拼贴**
- 一张图里 3-5 个小元素错位拼贴（不是 1 个角色居中）
- 关键词常加 highlighter / underline / 圆圈

**我们能借什么 / 不能借什么？**  
- ⭐ 借：拼贴感（角色 + 道具 + 手写字小注 + 关键词 highlight 错落分布）
- ⭐ 借：手写字小注解（v1 已写过但没真正用上）
- ⭐ 借：关键词 highlighter（黄色 marker underline）
- ❌ 不借：纯手帐风（会显得太"个人记账"，不够"梗"）

## 10. iMessage Tapback / Apple Notes Status

**用户发它是在表达什么？**  
（截图发给朋友）"看，连系统都觉得我今天这样." 苹果 UI 截图 = 中性权威感。

**图里哪个元素让她敢发？**  
- **苹果美学的克制 = 高级感**——大字 / 黑白 / 留白
- 不需要任何额外修饰
- 截图本身就是社交货币（"我用 iPhone"作为身份信号）

**朋友看到怎么接话？**  
"哈哈哈哈"或者发回另一张截图。**截图对话**是低门槛社交。

**视觉上哪里年轻/鲜活/有个性？**  
- SF Pro / 苹方 + 大字号
- 大留白
- **黑白二元 + 极少彩色 accent**
- 永远不对称（系统截图都是局部）

**我们能借什么 / 不能借什么？**  
- ⭐ 借：大字号 + 留白（让"一句话"成为主体）
- ⭐ 借：极少彩色 accent（仅 1-2 处亮色）
- ❌ 不借：黑白基底（Meetu 暖纸米更合适）

## 11. ❌ 反例：SaaS 插画 / Notion 默认 / "扁平 IP"

**用户发它是在表达什么？**  
什么都不表达。这是**装饰物**。

**为什么不会被分享？**  
- 一眼像 B 端产品
- 角色没有人格 / 表情统一 / 姿势礼貌
- "干净" = 安全 = 没有态度
- 所有插画都长得一样（unDraw / Storyset）

**Meetu v0.9 现在踩了哪些坑？**  
- 暖纸米 + 黑字 + 微小 accent = 视觉气质偏 Notion 个人页
- 选项条 6 行白卡 = SaaS 表单
- 候选卡 stack 等距 = 配置 dashboard
- 角色被使用得太"礼貌"

**避坑硬规则**：
1. 禁止任何元素居中且对齐（破对称是态度信号）
2. 禁止任何"完成度"很高的版式（要让画面"差一点点")
3. 禁止把角色当装饰物用（角色必须做一个姿势/动作，不能站着）

## 12. ❌ 反例：MBTI / 16Personalities / 测试结果证书卡

**用户发它是在表达什么？**  
"我被分类成 X 型". 但**这种分享会越来越少**——因为：
- 分类感强 → 发出去显得幼稚 / 自我中心
- 证书感 → 像在炫耀什么
- 朋友 reply"那又怎么样"

**为什么 v0.9 离这个反例最近？**  
- 顶部黄色 banner + 角色名 + 岗位 = 像证书顶部
- 标签条「焦虑 / 拖延 / DDL」= 像测试维度
- 朋友鉴定区有 border = 像表单字段

**避坑硬规则**：
1. **绝对不要带角色名 / 岗位 / 标签条**作为图的顶部信息（顶部任何"分类信号"都让图退回测试结果）
2. 不写"今日值班 ___"——这是产品标签
3. 不把朋友鉴定区做成可见的框

## 总规律提取（设计含义清单）

### 用户敢发的图都有 6 件事

1. **没有产品边界感** — 没顶部 banner / 没标签条 / 没水印 / 没"分类"信号
2. **字 ≥ 视觉的 50%** — 文字是主体（网易云 / 小红书班味），不是角色辅助
3. **底色或主色被一种情绪压住** — 不是平衡的米黄，是黑底 / 橙底 / 单色 dominate
4. **不对称构图 + 一点点粗糙** — 居中对称 = 产品；偏右 + 角色出框 = 状态
5. **一句话足够离谱 / 嘴硬 / 自嘲** — 平稳的话不会被分享
6. **朋友能 mirror，不需要解释** — 文案要"我也是"而不是"是这样吗"

### 我们 v0.9 各打分（10 分制）

| 项 | v0.9 | 目标 |
|---|---|---|
| 没有产品边界感 | 3 | 8+ |
| 字 ≥ 视觉 50% | 4 | 7+ |
| 主色被情绪压住 | 3 | 7+ |
| 不对称构图 + 粗糙 | 2 | 7+ |
| 文案离谱/嘴硬/自嘲 | 5（待 Lucy 接入后再评） | 8+ |
| 朋友能 mirror | 5 | 8+ |

**v0.9 综合分约 22/60；目标 45+/60。**

### 设计含义（给 share-first 样张方向）

1. **去掉顶部黄 banner、品牌字、标签条** — 让图看起来"不是从 app 导出来的"
2. **底色由角色色 dominate** — 比如低电量猫这张：60% 画面是低电橙底色，角色和文字在橙底上
3. **字号大、字数少** — 主句 ≥ 56px / 4:5 卡上视觉占比 ≥ 30%
4. **角色不正中** — 偏左 / 偏下 / 出框；让构图有"被偷看到"的感觉
5. **保留朋友鉴定区 placeholder，但删 border** — 看起来是空气而不是表单
6. **品牌字降到 12px 底部一行** — 像水印，不像 banner

### 风险词（再加 3 条进 negative）

- NO product banner / app frame
- NO tag pills / category labels above subject
- NO certificate / badge / score header
