## 1. 三页设计与"为什么用户会继续点"

### 1.1 Page 1 — 首屏：值班室桌面

**视觉骨架**：
- 暖纸米桌面（`#F2EAD8`）+ 主便签居中（`#FAF1DC` 暖白 + 胶带）
- 主便签写"今天这句 / 让谁替你说？"（嘴替主句字体，56pt，2 行）
- 便签下橙色细线（accent）暗示句尾未完
- 4 只动物（鹅/猫/仓鼠/羊驼）横排坐姿，60×60，桌面边缘
- 极轻文字"4 位今日值班 · 在场等你"
- 主按钮：橙色胶囊"叫一只出来替我说"（240×56，桌面贴纸感，不是 SaaS CTA）
- 桌面物件 2 个：左下笔迹 / 右下回形针
- 底部极轻"第一次会有人替你说"

**为什么用户会继续点**：
1. **不像 landing**：没有 hero 大图、没有产品标题、没有 SaaS 蓝紫色调
2. **承诺具体**：一句"今天这句让谁替你说"10 秒读完即懂——"它要替我说一句话"
3. **角色已在场**：4 只动物从首屏就坐在桌角，不是"点了才出现"，给出"它们在等我"的陪伴感
4. **按钮像物件**：橙色胶囊微旋转、有阴影，像桌面贴纸而不是 download 按钮，让点击像"拿一张便签"

### 1.2 Page 2 — 选场景：八张便签

**视觉骨架**：
- 顶部"哪句话你今天不想自己说"（不是"选择今天的场景"）
- 8 张便签 2 列 × 4 行，每张 145×130，3 种纸色（暖白/浅黄/卡其）随机分布
- 每张便签：第 1 行场景概括（28pt 主句字体）+ 第 2 行嘴替片段（20pt 浅棕辅助字）
- 不是所有便签都有胶带（i % 3 != 0 才贴），制造自然不规则
- 桌角小猫（pose1，70px 趴姿）坐着等
- 底部极轻"选一句你想被替着说的"

**为什么用户会继续点**：
1. **不是测试题**：8 张便签是用户语言（"被说中了 / 我没事"），不是功能分类（"S1 嘴硬否认"）
2. **每张都像她想过的话**：用户读完会想"哎这就是我今天"
3. **物理感强**：3 种纸色 + 不规则胶带 + 微阴影，像撒在桌面上的便签而不是选项卡
4. **角色未走开**：桌角猫坐着等，强化"它在等我选"的陪伴

### 1.3 Page 3 — 结果 / 嘴替工作台：递话窗口

**视觉骨架**：
- 顶部"今天它替你说"（不是"你的结果是"）
- 大便签预览 300×410，居中略歪 1°，胶带在右上角
- 角色（低电量猫 main）嵌在便签内上半，宽度 55%（不是叠在桌面上，是嵌在便签里）
- 嘴替主句"人在。/ 电不在。"56pt 占便签下半（视觉主角）
- 极轻角色名"— 低电量猫"在便签左下角
- 主按钮：橙色"保存这张"220×52
- 次按钮：换一句 / 换一只（米白卡片，132×40，并排）
- 4 个语气 chips（更嘴硬 / 更摆烂 / 更礼貌 / 更装没事）极轻可滑
- 桌面物件 2 个：左下回形针 / 右下半截胶带
- 底部极轻"心情值班室"

**为什么用户会继续点**：
1. **图是主角**：大便签占屏 50%+，让用户先看到"它替我说的图"
2. **保存动作低压**：主按钮像桌面贴纸而不是 download 按钮
3. **可控但不复杂**：换一句 / 换一只 = 再发一张便签，不是"重置测试"
4. **不被审视**：没有"你是 X / 你属于 Y"，只有"今天它替你说"

## 2. xhs 真实样本：5 规则 + 3 反例（不大报告）

> 来源：xhs CLI 搜索 "便签 文案" / "大字报 排版" / "便利贴 文字" / "情绪 emo 文案 卡片" 4 类关键词，热门 + 图文。

### 2.1 5 条可借鉴规则

1. **3:4 / 4:5 是绝对主流封面比例**：1200×1600 / 2484×3320 / 1242×1656 都是 3:4。说明 H5 输出图沿用 4:5 / 1080×1350 是对的。
2. **"情绪 + 文案"组合远胜"美图 + 标题"**：单图爆款（如「混乱是你成长的一部分」7.2 万赞）核心是手写或便签字体直接呈现一句完整情绪话，不靠风景/插图美学。这印证 v0.2 的"嘴替句作为视觉主角"方向。
3. **手绘小动物 / 简笔画 + 一句话** 是高互动模板（"手绘情绪盒子文案"5.9 万赞 / "暗示自己不开心的小众情绪文案"3.8 万赞）。我们的 4 角色 + 嘴替句正是这个组合，不需要再发明形式。
4. **"合集 / 第 X 弹"** 是高复用模式（"情绪盒子文案第一弹—200 条"6567 赞）。说明用户接受"持续来一句"的预期——支持我们 P1 之后扩 backup 的策略。
5. **作者昵称低存在感**：高赞内容主图基本不带作者水印 / logo 在主视觉上。说明我们的 H5 输出图"心情值班室"落款必须极轻，水印化（已落实）。

### 2.2 3 个反例（绝对不抄）

1. **"设计师小蓝"类教学账号封面**：标题 + 多版式拼贴 + 教学箭头，赞高（5.9 万）但是设计师生意感强，**完全相反方向**——我们的图给用户发，不是给设计师收藏。
2. **"版式设计研究所"类报纸排版**：纯排版炫技，没有情绪入口，不是用户会发的图。
3. **MBTI 16 型 + 测试结果卡**：彩色色块 + 标签 + 分数，已被 Jonathan/Fiona 多次否定，**整套测试 H5 视觉语言禁止借鉴**。

## 3. 字体候选 3 个对比（含授权 / 可落地性）

### 3.1 嘴替主句字体（视觉主角，最大字号）

| 候选 | 落地路径 | 授权 | 视觉感 | v0.2 推荐度 |
|---|---|---|---|---|
| **A. 站酷快乐体（Zcool KuaiLe）** | 国家字体局 / Google Fonts CDN | ✅ 完全免费商用（CC0 / 站酷字库声明免费商用），可作 web font 加载 | 圆润、卡通、童趣强、笔画粗厚 | ⚠️ 偏可爱化，不够"用户随手感"，可能太"产品想要的手写风" |
| **B. 霞鹜文楷（LXGW WenKai）** | GitHub `lxgw/LxgwWenKai` | ✅ SIL OFL 1.1 完全免费商用 | 仿宋楷书、笔画精致工整 | ❌ Dave 当前用的就是这个，Jonathan 已否定（"太书法、太规整、太'产品想要的手写感'"） |
| **C. ⭐ 仓耳今楷 02（TsangerJinKaiBlack-W04） / 阿里巴巴普惠体 H** | 仓耳官网（个人免费 / 商用需购买） / 阿里普惠体（免费商用） | ⚠️ 仓耳今楷需购买商用授权（$~3000+/year）；阿里普惠体免费商用 | 楷体方正中带手写感，识别度高 | 仓耳今楷视觉最匹配但授权风险大；阿里普惠体作为 B 级备选 |
| **D. ⭐ 系统级中黑（STHeiti Medium / PingFang SC Medium / Hiragino Sans GB）** | macOS / iOS / Android 系统自带 | ✅ 系统级，零授权风险，零字体加载成本 | 中性黑体，干净，依赖**字距 / 行距 / 微旋转 / 文字层次**做出设计感 | ✅ **v0.2 推荐**：先用系统中黑落地，靠字距/行距/微旋转/排布做"用户随手感"，留出"换字体"的 P1 升级位 |

**v0.2 字体落地决策**：

> 嘴替主句先用 **STHeiti Medium / PingFang SC Medium 系统级**（v0.2 mockup 实际使用）+ 字距字重微调 + 微旋转，不依赖手写字体本身就能传"随手"感。
>
> 这条解 Jonathan 痛点 B 的方式不是"找更好看的手写字体"——是 **"先排除依赖字体取胜"**，把设计感重心放到字距、行距、微旋转、便签框体、桌面物件、空白节奏上。
>
> 如果 Fiona / Jonathan 仍要"更具手写感"，**P1 推荐路径**：买仓耳今楷或拿阿里普惠体作正式手写字体方案，**不要用 LXGW WenKai**。

## 4. 给 Dave 的实现约束 spec（颜色 / 阴影 / 便签 / 按钮 / 动效 / 角色尺寸）

### 4.1 颜色 token

```ts
const COLORS = {
  // 桌面背景
  desk: '#F2EAD8',          // 暖纸米主桌面
  // 便签纸（3 色随机分布）
  noteWhite: '#FAF1DC',     // 暖白便签
  noteYellow: '#F0E2BA',    // 浅黄便签  
  noteKhaki: '#E8D9B0',     // 卡其便签
  // 文字
  inkDark: '#4A371E',       // 主文字（不用纯黑）
  inkLight: '#826E50',      // 辅助文字
  // 点缀色
  orangeAccent: '#E8A04F',  // 暖橙（猫围裙色，主按钮 / accent）
  // 桌面物件
  tape: 'rgba(220, 205, 175, 0.62)',         // 半透明胶带米白
  paperclip: '#8C785A',                       // 回形针
  shadow: 'rgba(74, 55, 30, 0.18)',           // 通用阴影
};
```

### 4.2 阴影 / 飘浮感

```css
/* 便签飘浮阴影 */
.note { box-shadow: 0 2px 6px rgba(74, 55, 30, 0.12), 0 1px 2px rgba(74, 55, 30, 0.08); }
/* 主按钮阴影 */
.btn-primary { box-shadow: 0 3px 8px rgba(74, 55, 30, 0.20); }
/* 次按钮阴影 */
.btn-secondary { box-shadow: 0 1px 3px rgba(74, 55, 30, 0.10); }
```

### 4.3 便签组件（核心）

- **形状**：`border-radius: 3px`（不是 8 / 16，**真实便签是直角微圆**）
- **尺寸**：
  - 首屏主便签 `290×220`
  - 选场景便签 `145×130` 2 列
  - 结果页大便签 `300×410`（4:5 比例）
- **胶带**：56×20 半透米白矩形 + 内部 4px 间距细线条（纤维感）
  - 80% 概率出现，不是每张都贴
  - 位置在便签上沿，左/右随机
  - 微旋转 -8° ~ +8°
- **微旋转**：每张便签独立微旋转 -3° ~ +3°（避免一致僵直）
- **纸张纹理**：`background-color` + 内部 8-15 个 1px 深棕点（伪纸纤维）
- **3 色随机**：以 row index seed 决定，避免每次 reload 闪变

### 4.4 按钮规则

- **主按钮（保存这张 / 叫一只）**：
  - 橙色 `#E8A04F` 实心
  - `border-radius: 28px`（胶囊，强调贴纸感）
  - 字色 `#FFFCF0` 暖米白
  - 微旋转 `-1°`（贴纸感，不是规整 SaaS 按钮）
- **次按钮（换一句 / 换一只）**：
  - 米白 `#FAF1DC` 卡片
  - 浅棕边框 `#B4A078` 1px
  - `border-radius: 10px`
  - 微旋转交替（`+1.5°` / `-1.5°`）
- **chip（语气标签）**：
  - 透明背景 + 浅棕边框 1px
  - `border-radius: 12px`，padding `4px 8px`
  - 字号 12px，颜色 `#826E50`

### 4.5 角色尺寸 / 嵌入规则

| 用途 | 尺寸 | 嵌入方式 |
|---|---|---|
| 首屏 4 动物坐姿 | 56-60px 高 | 直接 paste 到桌面（透明 PNG） |
| 选场景桌角猫 | 70px 高 | paste 到桌面右下 |
| 结果页大便签内 main 角色 | 便签宽度 **55-65%**（≈ 165-195px 宽） | **嵌在便签内**（不是叠在桌面上）→ 物理嵌套：动物在便签上 / 便签压在桌面上 |
| H5 输出图 1080×1350 角色 | 便签宽度 60-70% | 同结果页规则 |

**关键修正**：之前 Jonathan 反馈"猫偏小" → 不是把猫放大占屏 70-85%，而是**让猫嵌在便签里 60% 便签宽度**，便签本身占屏 50%+，物理上猫的视觉权重就够，且没有"贴在屏幕上"的感觉。

### 4.6 动效（最小集，可分两阶段实现）

**P0 必做**：
- 按钮 tap 反馈：scale 0.96，ease-out 120ms
- 切换页面：300ms ease-in-out fade（不要 slide / 不要弹跳）

**P1 可加**：
- 换一句 / 换一只时，便签做"被撕下 + 新便签飘下"动画（200ms）
- 桌角动物加微呼吸（2s 循环 0.98-1.02 scale）

**禁止**：
- 弹跳 spring 动画（违和、像 SaaS）
- 持续旋转 / shimmer / loading 动画
- 弹窗 / popup 强干扰

### 4.7 桌面物件（每屏最多 2 个 — Fiona 硬约束 #1）

桌面物件**只服务"这句被递出来"叙事**，不为好看堆物件：

- 回形针：12×24 浅棕描线
- 半截胶带：50×16 半透米白 + 纤维线
- 笔迹（pen mark）：24-36px 浅棕折线
- **不要**：花朵、爱心、星星、彩带、卡通贴纸、emoji 装饰

每屏只用 2 个，且互相不重叠，分布在屏幕角落。
