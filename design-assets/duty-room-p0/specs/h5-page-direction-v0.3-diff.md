## v0.2 → v0.3 4 点修订

### Fix 1：首屏 4 动物 — 从等距 icon 行 → 自然在场

**v0.2 问题**：4 只动物 `60×60` 等距横排在便签下方，PM 点出"还是有'选 IP'的感觉"。

**v0.3 修复**：动物自然散布桌面，每只独立姿态/尺寸/位置，"像桌面上的小东西"。

| 角色 | v0.2 | v0.3 |
|---|---|---|
| 嘴硬鹅 | 横排 #1，60px 站立 | **趴在主便签纸右下边**，80px 半身露出（`partial="left"` 切右半身） |
| 低电量猫 | 横排 #2，60px 趴姿 | **桌面左下趴姿**，95px 完整 |
| DDL 仓鼠 | 横排 #3，60px 坐姿 | **中下偏右独立坐**，70px（**比其他略小，制造"远一点"**） |
| 后台羊驼 | 横排 #4，60px 站立 | **远右上靠角落**，110px 半身（`partial="bottom"` 只露上半身） |

caption 也从 "4 位今日值班 · 在场等你"（仍像功能描述）改为 "**它们今天已经在了**"（更自然）。

### Fix 2：选场景 — 从 2×4 网格 → 自然便签流

**v0.2 问题**：8 张 145×130 等大方卡 2 列对齐，PM 点出"仍偏 2×4 问卷卡片"。

**v0.3 修复**：尺寸/位置/旋转/纸色全部不规则，首屏露 5 张，下方露 2 张暗示滚动。

| 维度 | v0.2 | v0.3 |
|---|---|---|
| 排布 | 2 列 × 4 行整齐网格 | **完全不规则布局**（各 note 独立坐标） |
| 尺寸 | 全部 145×130 | **变化**：175×110、130×105、145×110、160×130、130×100、150×110、155×95 |
| 纸色 | 3 色（暖白/浅黄/卡其） | **4 色**（+ 暖桃 `#F4E0C8`） |
| 胶带 | 三分之二贴胶带 | **一半贴 / 一半没贴**，更不规则 |
| 字号 | 全部 28pt + 20pt 副 | **大便签 28pt + 20pt / 小便签 20pt + 14pt**，文字适配 |
| 首屏可见 | 8 张全部 | **5 张完整 + 2 张露顶部**，下方有"↓ 还有 3 张"滚动提示 |
| 渐变淡出 | 无 | **底部 40px 渐变到桌面色**，自然过渡 |

### Fix 3：结果页 — 修文字裁切 + 安全区

**v0.2 问题**：`人在 / 电不在` 在大便签底部被切掉，PM 点出"必须修，结果页核心就是那张图"。

**v0.3 修复**：

| 维度 | v0.2 | v0.3 |
|---|---|---|
| 便签尺寸 | 300×410 | **310×420**（高度+10，留更多安全区） |
| 便签起始 y | ny=84 | **ny=76**（向上 8px，给文字下沉空间） |
| 角色占便签宽 | 55% (165px) | **50% (155px)**（更小，让文字主角更突出） |
| 角色起始 y | ny+22 | **ny+24**（保持） |
| 文字起始 y | ny+cat_h+50 = 切到底部 | **ny+cat_h+38**（更早开始）+ **行高 60px** |
| 文字到底部安全距 | 0（切到边） | **60px+ 安全距**（角色名落款不被压） |
| 角色名 "— 低电量猫" | ny+nh-22（贴边） | ny+nh-22（保持，但便签变高所以有更多空间） |

**核心修复**：把 `人在。/ 电不在。` 视为页面输出图主角，按 1080×1350 分享 PNG 的安全区比例反推 H5 预览大便签的内容布局，**严格预留 35% 便签高度给文字 + 安全 padding**。

### Fix 4：按钮层级 — 收到 2 个主动作

**v0.2 问题**：主按钮 `保存这张` + 次按钮 `换一句 / 换一只` + 4 个 chips（更嘴硬/更摆烂/...），PM 点出"现在有点多，像功能区"。

**v0.3 修复**：

| 元素 | v0.2 | v0.3 |
|---|---|---|
| 主按钮 1 | `保存这张` 220×52 橙色单按钮 | **`保存这张` 156×48 橙色** |
| 主按钮 2 | 不存在（在次按钮中） | **`换一句` 156×48 浅橙**，与主按钮并排同级 |
| 次按钮 | `换一句` + `换一只` 132×40 米白卡片并排 | 全部移除 |
| 三级动作 | 不存在 | **`换一只 ›` 文字链**（弱入口下沉） |
| chips | 4 个独立 chip（更嘴硬 / 更摆烂 / 更礼貌 / 更装没事） | **折叠为单行小字** "更多语气：嘴硬 · 摆烂 · 礼貌 · 装没事" |

**层级口径**：
- L1（强引导）：`保存这张`（橙）+ `换一句`（浅橙）— 用户看到结果后最常做的两件事
- L2（弱入口）：`换一只 ›`（文字链）— 不常用，需要时找得到
- L3（折叠）：4 种语气（小字单行）— 不喧宾夺主，但视觉上知道"还可以调"
