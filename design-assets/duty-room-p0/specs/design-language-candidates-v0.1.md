# 心情值班室 设计语言候选假设 v0.1

> 注：这是基于已有数据 + Common Sense + 视觉判断的**候选假设**，不是调研结论。
> 来源：`Common Sense/用户认知/用户画像.md` + `用户心理模型.md` + `数据归档/XHS账号数据.md`，Lucy 文案池 v1.2 已冻结口径，加上视觉师对当前 Z 世代女大学生 IP 偏好的常识判断。
> 目的：帮助团队快速收敛 1 个主方向，再决定是否需要补 XHS 真实样本验证。

---

## 已沉淀的硬规则（先列出，3 候选必须各自满足）

来自此前讨论 + Common Sense + Fiona 收束：

**红线（5 条）**
1. **禁"被审视/被诊断/被分类"**：文案禁"你是/你属于/你被判定"；视觉禁证书/报告/测试结果感
2. **禁"在社交"明示**：产品是自我状态表达物，朋友互动是结果不是 UI 明示
3. **禁萌系卖力可爱 / 禁 mascot 招手 / 禁 chibi**
4. **禁渐变 / 玻璃拟态 / 大投影 / SaaS 默认表单感**
5. **禁完整办公室插画 / 禁多物件堆料 / 禁角色设计图鉴感**

**正面词（5 个）**
1. **轻** — 物件少、色少、面少、留白多
2. **真** — 像同学随手做的，不像设计师作品集
3. **低压** — 像累了的同事，不像吉祥物在卖萌
4. **可被借** — 用户能截图发出去给朋友接话
5. **统一** — H5 / 分享卡 / XHS 物料 / 公众号图同一种人设

## 候选 A：「轻手帐 / 状态便签系」

### 一句话定义
> 像贴在课表/笔记本上的一张今日状态便签——纸感底色、手写感字、一个手绘小标记，告诉你"今天的 mood 是 ___"。

### 视觉关键词
- **底色**：奶油米 `#FAF4E6` / 极浅麻 `#F2EAD8` / 偶尔点燕麦灰
- **画法**：细黑线（2-4px）+ 大量留白 + 手绘点缀（小爱心、波浪线、便签角折）
- **角色**：可有可无；如果有，是简笔小动物贴纸尺寸（占画面 < 30%），不是主角
- **字体**：手写感中文（如 Reach 楷 / 字魂手写体），重点字段下加 underline
- **强调**：薄荷 `#A8D5BA` / 鼠尾草绿 / 莓粉 `#F2C5C5` 任选一作 accent，覆盖率 < 5%

### 语言关键词
- 手帐口吻 / 短句 / 口头化 / "今天好像有点" / "记一下" / "明天再说"
- 偶尔附颜文字（不滥用）：`(꒪˙꒳˙꒪ )` / `( ˘•ω•˘ )`
- 不用感叹号；句末多用 `…` `。` 或留白

### UI 规则
- **栅格**：8px；圆角 8-10px（更轻）；卡片无投影或仅 1px 浅色描边
- **按钮**：浅米底 + 黑细描边 + 黑文字 主 CTA；次 CTA 纯文字按钮（带 underline）
- **动效**：120ms ease-out；可加 1 px 翻页/折角的极简过渡

### 角色形象规则
- **存在感低**：每张图角色尺寸压到全画面 30% 以下
- **简笔贴纸感**：3-5 笔画完，带"被剪下来贴上去"的白色描边或便签胶感
- 不画细节（不画毛、不画影、不画专业的眼神）

### 分享图规则
- 4:5 主底是大片纸感留白，中下方贴一个角色贴纸 + 留白触发器位
- 顶部一行手写感 "今天值班 ___"
- **值班黄不刷大块**，仅出现在 1 个小标签贴纸里

### 5 项打分（10 分制）

| 维度 | 分 | 备注 |
|---|---|---|
| 女大学生接受度 | **9** | 手帐文化在女大学生中渗透率极高，是她们日常表达 |
| 男生排斥风险 | **5** | 中等。手帐感稍偏女性化，但极简纸感不至于排他到看就划走 |
| 广告感风险 | **2** | 极低。手帐看起来就是个人发的 |
| 传播潜力 | **6** | 中等。便签美但记忆点弱，需要文案做记忆锚点 |
| 被分类/被诊断感 | **1** | 极低。便签本来就是"我自己写的状态" |

### 3 个正向锚点
1. **小红书"今日心情手帐"赛道**（机制：用户自己当编辑，把今天写进一张轻便签）
2. **网易云日推/分享卡**（机制：把听感包装成可截图的轻表达物）
3. **手账打工人 / 班级周报 IP** 系（机制：把日常办公打工的低压感装进轻纸感版式）

### 3 个反例红线
- ❌ 卡通日记本（带星星、彩虹、kawaii 装饰）
- ❌ 韩系 ins 风（高饱和、立体投影、复杂图层）
- ❌ 公众号文章封面排版（标题 60pt + 副标题 + 装饰）

### H5 / 选项页 / 结果卡 / 分享图 / 文案 五落点

| 位置 | 长什么样 |
|---|---|
| **H5 首页** | 像一本翻开的笔记本左页：极简标题 "今天派谁出来替你说话？" + 一行手写副文 + 一个小动物简笔 + 大留白 + 黑底主 CTA "开始今日值班" |
| **选项页** | 6 个场景做成"贴纸条"横向排列；每条 1 行文字 + 1 个简笔小图标；点击不弹窗，原地标记被选中（出现一个小钩） |
| **结果卡** | 单页面背景仍是奶油纸；中间贴一张角色贴纸（无文字） + 下面手写感的 "今日值班：___"；3 候选卡用上下滑动而不是横向卡片墙 |
| **分享图** | 4:5 纸感底 + 中部贴角色 + 下半留白给"朋友鉴定区"；顶部小手写标签 "今日值班单"；底栏极简水印 |
| **文案** | 短句 + 手帐感口吻；多用 "今天好像有点 ___" / "记一下" / "我没在生气，只是" |

### 我作为视觉师的判断
- ⭐ 整体最稳，不容易踩雷
- 风险：可能太"通用"，失去心情值班室"动物员工"这个锚定的辨识度

## 候选 B：「校园通知条 / 值班单系」

### 一句话定义
> 像今天贴在宿舍楼下公告栏 / 教室门口的一张「今日值班通知」——纸底、印刷感粗黑线、一个动物员工小图章，告诉你"今天 ___ 在岗"。

### 视觉关键词
- **底色**：暖纸米 `#F2EAD8`（统一锁，与之前 v3 草稿一致）
- **画法**：粗黑线（5-7px）+ 印刷感 + 公告/通知排版（顶部带值班黄横条 + 居中"通知"标识）
- **角色**：动物员工小尺寸（占画面 40-50%）+ 1 个梗道具 + 1 个工位线
- **字体**：方正风雅宋 / 思源黑加粗，模拟印刷通知感；保留少量手写感
- **强调**：值班黄 `#F2C744` 作为"通知专用色"，覆盖率 5-10%

### 语言关键词
- 公告口吻 + 反差幽默：`今日值班：低电量猫 / 备注：电量 3%，请勿叫醒`
- 类似学校通知体的开头："兹通知" "今日由 ___ 当值"
- 反差点是公文格式 + 自嘲内容

### UI 规则
- **栅格**：8px；圆角 4-8px（偏方正）；可带细描边模拟"公告纸"感
- **按钮**：黑实心主 CTA / 描边次 CTA；按钮文字像盖章感
- **动效**：120ms；轻微"贴上去"的 fade-in
- **背景**：纸底 + 偶尔加一道虚线/折痕

### 角色形象规则
- 动物员工 + 制服 + 岗位牌（可保留之前 v1 master sheet 思路）
- 但每张图只画 1 个角色 + 1 个梗道具，不画完整办公室
- 像盖在通知纸上的一个"今日当值小图章"

### 分享图规则
- 4:5 顶部 60-80px 黄色横条 "今日值班通知" + 中部角色员工 + 下半留白触发器
- 像一张课程表 / 签到表 / 公告通知

### 5 项打分

| 维度 | 分 | 备注 |
|---|---|---|
| 女大学生接受度 | **6** | 中等。"公告/通知"形式偏硬，但动物员工是软化器；女生未必反感但不会主动收藏 |
| 男生排斥风险 | **3** | 低。校园通知形式对男生友好 |
| 广告感风险 | **5** | 中。"通知"形式如果做不好会像产品发布栏 |
| 传播潜力 | **8** | 高。通知体的反差感容易出梗（类似"温馨提示" "请勿打扰"），易截图易模仿 |
| 被分类/被诊断感 | **3** | 中低。"通知"是被动告知，不是主动分类 |

### 3 个正向锚点
1. **校园贴纸告示文化**（机制：用公文/通知格式承载小幽默）
2. **"温馨提示"梗图**（机制：把严肃格式装进自嘲内容）
3. **班级值日表 / 晨读签到表**（机制：把"今天轮到 ___"包装成视觉物）

### 3 个反例红线
- ❌ 政府公告 / 居委通知（太严肃、纸老虎）
- ❌ 微信公众号头图模板（过分海报感）
- ❌ 印刷品过度做旧 / 仿古风（伪复古、文艺青年味）

### H5 / 选项页 / 结果卡 / 分享图 / 文案 五落点

| 位置 | 长什么样 |
|---|---|
| **H5 首页** | 顶部是黄底"今日值班通知"横条 + 主标题"今天派谁出来替你说话？" + 大留白 + 黑实心 CTA "签到查看今日值班" |
| **选项页** | 6 场景做成"今日选项 / 请勾选"列表；每行带动物小图章 + 文字；选中后图章变实心 |
| **结果卡** | 居中一张"今日值班 / Today's Officer：___"通知卡 + 角色员工图 + 一行金句 + 3 个候选切换 tab |
| **分享图** | 上 60px 黄条 + 角色 + 中部留白 + 底部水印 |
| **文案** | 公告式 + 自嘲反差："今日由低电量猫值班，电量 3%，请勿叫醒" |

### 我作为视觉师的判断
- 优点：传播性强、视觉差异化最大、能出梗
- 风险：通知体本质上仍带"系统下发"感，与"自我表达"价值观有摩擦；文字依赖度高
- 备选作为分享图风格用，不一定作为整体 UI 语言

## 候选 C：「情绪小角色贴纸 / 状态贴系」

### 一句话定义
> 像 Loopy / 班尼路熊那种，把一只可记忆小动物 + 一个状态文字做成可贴可发的「情绪贴纸」——纸感底、圆润动物、一句替你说的话，朋友看了就想"这不就是你"。

### 视觉关键词
- **底色**：奶油米 / 燕麦灰 / 浅樱粉（每个角色 1 个柔色背景）
- **画法**：粗细中等黑线（4-5px）+ 角色更圆润；可带极轻 1px 白色描边模拟"贴纸切割"
- **角色**：占画面 60-70%（主角化）；每只动物有强烈记忆点（标志姿势、标志道具）
- **字体**：圆润中文（OPPO Sans / 苹方 Medium）；贴纸感
- **强调**：每角色 1 主辅色；不刷大色块；点缀少量颜文字

### 语言关键词
- 替我说话句式 + 短梗：`我没电` `我嘴硬` `我装的`
- 角色第一人称（不是给用户分类）："我今天值的是不想出门的班"
- 不解释、不分析、不诊断

### UI 规则
- **栅格**：8px；圆角 16px（贴纸感强）；卡片可有极轻投影（0/1px shadow）
- **按钮**：圆角 16-20px 黑实心主 CTA；可带 1 个角色头像 icon
- **动效**：120ms；候选卡切换时角色弹一下（弹度极小，2-3px）
- **背景**：纸底 + 轻量贴纸 pattern（角落散落几个小符号）

### 角色形象规则
- 6 个角色每个**独立成一套贴纸**：3 个表情 + 1 个标志道具 + 1 个标志金句
- 不需要"完整办公室世界观"；每个角色像独立 IP
- 风格统一靠：黑线粗细 / 字体 / 留白比例 / 配色逻辑

### 分享图规则
- 4:5 角色占主体（中上部）+ 一句金句 + 大留白 + 朋友鉴定区
- 像一张"情绪贴纸卡"

### 5 项打分

| 维度 | 分 | 备注 |
|---|---|---|
| 女大学生接受度 | **8** | 高。Loopy/班尼路熊路线是 Z 世代女生当前主流口味，但风险是过线变 mascot |
| 男生排斥风险 | **6** | 中高。圆润动物 + 一句话句式偏可爱化；男生不至于排斥但接受度差距明显 |
| 广告感风险 | **3** | 低。贴纸感强但不像广告 |
| 传播潜力 | **9** | 极高。贴纸 = 表情包 = 病毒传播载体，最适合 XHS / 朋友圈反复使用 |
| 被分类/被诊断感 | **2** | 低。角色第一人称，不是给用户打标签 |

### 3 个正向锚点
1. **Loopy / 卡颂动物 IP**（机制：少量造型 + 大量金句 + 可贴可发）
2. **班尼路熊 / 玛卡巴卡**（机制：呆萌不卖力，圆润但不甜腻）
3. **emo 颜文字 + 一句话状态条**（机制：极简符号 + 自嘲文字 = 可发表达物）

### 3 个反例红线
- ❌ kuromi / Sanrio 高甜系（过线变小女生卖萌）
- ❌ 抖音油腻可爱（眼角加泪滴 + 红腮红 + 小心机表情）
- ❌ 男凝萌（瓜子脸 + 撩头发 + 偶像化角色）

### H5 / 选项页 / 结果卡 / 分享图 / 文案 五落点

| 位置 | 长什么样 |
|---|---|
| **H5 首页** | 中部一只主角色（默认是嘴硬鹅 / 低电量猫轮播）+ 一句金句 + 黑实心 CTA "今天派谁出来" |
| **选项页** | 6 场景做成"贴纸卡"网格（2×3）；每张贴纸是一个小道具 + 一行短文字 |
| **结果卡** | 1 张大角色贴纸卡（角色 + 金句）+ 下方 3 个候选小贴纸切换 tab |
| **分享图** | 4:5 角色贴纸为主 + 朋友鉴定区 + 极小水印 |
| **文案** | 角色第一人称："我没电" "我嘴硬" "我今天不想营业" |

### 我作为视觉师的判断
- 优点：传播力最强、最适合做长期 IP / 周边、女接受度仅次于 A
- 风险：角色一旦过线就变 mascot；男生排斥风险最高；制作成本最高（每只动物都要单独 IP 化）

## 我（视觉师）的推荐排序

> 推荐排序的逻辑：在"风险可控 + 调性统一 + 落地成本"三维度做平衡，且与 PRD v0.8 已锁的"动物员工值班室"世界观对接。

### 🥇 推荐 1：**A 轻手帐 / 状态便签系（占 60%）+ C 情绪贴纸（占 40%）的混合**

具体配方：
- **整体 UI 用 A 的语言**：奶油米底 + 极简手写 + 大留白 + 细黑线 → 让产品看起来不像测试工具
- **角色资产用 C 的语言**：每个动物员工做成"贴纸级"小图，但克制大小（占画面 30-40%，不主角化）
- **不取 B 的"通知"格式**：通知体反差幽默虽然强，但与"自我状态表达"价值观有冲突，容易让用户感觉"被告知"

**为什么这是推荐**：
- A 的 UI 语言对女接受度 9 / 男排斥 5 / 被分类感 1，都是最稳分；
- C 的角色贴纸保留传播潜力 9 + 角色记忆点；
- A + C 组合让产品**整体像便签 / 局部有可记忆角色**，正好对接 PRD §10 "用户拿走它代替自己说话"的核心诉求；
- 与 Lucy 已冻结的"嘴硬 / 摆烂 / 礼貌勿扰"角色第一人称文案池天然契合。

### 🥈 推荐 2：纯 C「情绪小角色贴纸」单走

如果团队判断"角色 IP 化"是更长期的战略资产（要做表情包 / 周边 / 后续 IP 衍生），可以纯走 C。代价是男接受度下降到 6、视觉风险变高（容易过线变 mascot），需要 Phoebe 严格把控每张图不卖萌。

### 🥉 推荐 3：纯 B「校园通知条」

不太推。视觉差异化最大但与"自我表达"价值观摩擦也最大；可保留为分享图变体之一（"通知风" 4:5 模板），但不作为整体设计语言。
