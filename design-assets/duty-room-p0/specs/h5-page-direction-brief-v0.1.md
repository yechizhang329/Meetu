## 0. 设计 DNA（贯穿 3 页 — 解叙事一致问题）

> **心情值班室 = 一间值班室；用户来值班窗口报今天的状态；动物员工替她说一句话；这句话被写在一张随身便签上递给她。**

整套 H5 不是"测试 H5"，不是"结果卡 H5"，是 **"递话窗口 H5"**：

- **物理逻辑统一**：3 页全部发生在"同一张暖纸米色桌面 / 值班室桌面"上。所有图、文、按钮都"放在桌面上"，而不是"画在屏幕里"。这一条直接破解 Jonathan 提到的"贴图感"——**贴图就是叙事一部分**：动物原本就贴在桌面上，便签纸原本就压在桌面上，没有 z-index 0 的"无缝贴合"问题。
- **角色固定姿态**：动物从首屏开始就在桌角值班，不"突然出现"。换场景换句时角色微动作，不重新加载。
- **一句话 = 一张便签**：嘴替句永远写在"便签纸"上，不是写在"产品文字层"。便签是物理框体，不是装饰。
- **"值班室" = 不被审视**：用户不被测试、不被评分、不被分类，只是来"叫一只"。

### 设计 DNA 一句话

> 整张 H5 是一张被写满的便签桌面。每一页只是这张桌面上不同的状态。

## 1. 解 Jonathan 三个痛点（直接对应回答）

### 痛点 A：贴图感（猫周围矩形纸纹块、像图贴上去）

**方案**：不消除贴图，而是 **让贴图成为叙事**。
- 每个角色都"贴"在便签纸 / 拍立得 / 桌面纸片上，纸片本身有手撕边、胶带、压痕。
- 角色 PNG 的纸纹边界 = 便签纸边界。视觉上"猫贴在纸上 → 纸压在桌面上"是合理的物理嵌套。
- 实现：Canvas 先画"便签纸"（暖色卡纸 + 手撕边 + 微旋转 + 胶带 + 微阴影） → 再 drawImage 角色 PNG 到便签纸内 → 再叠手写字。三层都是"桌面物件"。

### 痛点 B：字体不满意（"好看的手写字体"不是"用户随手写的话"）

**当前**：Dave 用 LXGW WenKai（霞鹜文楷），偏书法体，太"漂亮"。
**方向**：换成更"随手"的字体，且区分 **嘴替句** 和 **辅助文字** 两类字号字体。

| 用途 | 字体方向 | 字号 / 字重 |
|---|---|---|
| **嘴替主句**（如"人在 / 电不在"） | 用户手写感 / 不工整 / 略歪：**站酷快乐体 / 仓耳今楷 / 有爱体 / 字魂手写体** 备选 | 极大字号（占便签纸 60%+），中等字重，行间距紧 |
| **场景标题 / chip / 按钮** | 不抢戏的圆体：**OPPO Sans / 思源黑体 + 微 italic** | 中字号，常规字重 |
| **极轻落款 / 角色名** | 极小，弱化 | 最小字号，60% 不透明 |

**确认动作**：v0.1 brief 阶段先列字体候选，最终字体由 v0.2 视觉稿对比 + xhs 真实样本校对决定。**先排除 LXGW WenKai 作为嘴替主句字体**（太书法、太规整、太"产品想用手写感"）。

### 痛点 C：留白过大 / 设计感缺失

**问题诊断**：Dave 当前导出图是"中央对齐 + 四边大留白"的标准海报模板逻辑。留白不是空，是**没物件**。
**方案**：留白填充用 **桌面物件** 而不是装饰图形：
- 一张被划掉的便签
- 半截胶带
- 一个回形针
- 钢笔墨水迹
- 一张被压住的小纸条（写"这只在值班"）
- 桌角的角色（小尺寸坐姿）

物件不是"满"，是"陪伴"。每张图最多 2-3 个桌面物件，避免重新变成杂乱拼贴。设计感来自 **物件密度的克制 + 物件之间的物理逻辑**（胶带真的压住便签 / 回形针真的别住一角），不是更多视觉元素。

## 2. 三页骨架（375 移动端宽度）

### 2.1 Step 0 — 首屏：值班室桌面

**布局**：
```
┌─────────────────────────────┐
│ [极轻品牌：心情值班室 · 今日开门]  │ ← 顶部，弱到几乎看不到
│                             │
│   [桌面：暖纸米 #F2EAD8]      │
│                             │
│      [一张便签纸：略歪]       │
│      ┌─────────────┐        │
│      │ 今天这句     │        │ ← 嘴替主句字体，超大
│      │ 让谁替你说？  │        │
│      └─────────────┘        │
│      [胶带压在便签角]         │
│                             │
│      [桌角：4 只动物坐姿小图]  │ ← 排成一排，全部已在场
│      🦢  🐱  🐹  🦙          │
│                             │
│      [按钮：叫一只出来]       │ ← 不是大色块，是"桌面贴纸"
│                             │
│ [极轻落款：第一次会有人替你说] │
└─────────────────────────────┘
```

**这页让用户继续点的原因**：
- **不像 landing**：没有大 hero、没有标题，桌面上只有"被你看到的便签"。
- **承诺具体**：一句"今天这句让谁替你说"，10 秒读完即懂。
- **角色已在场**：4 只动物从首屏就在桌角，不"等你点了才出现"，给用户"它们在等我"的陪伴感。
- **按钮像物件**：不是 SaaS 风的 CTA 按钮，是桌面上的"贴纸"，让点击像"拿起一张便签"。

### 2.2 Step 1 — 选场景：八张便签

**布局**：
```
┌─────────────────────────────┐
│ [极轻提示：哪句话你今天不想说]  │
│                             │
│   [桌面：暖纸米]              │
│                             │
│   ┌────────┐ ┌────────┐    │
│   │被说中了  │ │人还在   │    │ ← 8 张便签 2 列布局
│   │但我不   │ │电先下班 │    │   每张随机微旋转
│   │承认     │ │了      │    │   每张不同纸色（暖白/浅黄/卡其）
│   └────────┘ └────────┘    │
│   ┌────────┐ ┌────────┐    │
│   │会做的    │ │表面好的 │    │
│   │不是现在  │ │后台别来 │    │
│   └────────┘ └────────┘    │
│   ... (4 more)              │
│                             │
│   [桌角：1 只角色坐着等]      │ ← 不抢戏，强化陪伴感
│                             │
└─────────────────────────────┘
```

**这页让用户继续点的原因**：
- **不是测试题**：8 张便签是"用户语言"，不是"S1 嘴硬否认 / S2 拒绝营业"功能分类。
- **每张便签都像她想过的话**：用户读完会想"哎这就是我今天"。
- **物理感**：便签微旋转 + 不同纸色 + 微阴影，像真的"撒在桌面上的便签"，不像选项卡。
- **角色未走开**：桌角动物坐着等，给"它在等我选"的陪伴。

### 2.3 Step 2 — 结果 / 嘴替工作台：递话窗口

**布局**：
```
┌─────────────────────────────┐
│ [极轻：今天让它替你说]        │
│                             │
│   [桌面]                    │
│                             │
│   [大便签：嘴替主图预览]      │ ← 1080×1350 输出图缩略
│   ┌────────────┐            │
│   │ [角色]      │            │   - 角色嵌在便签内
│   │ 人在        │            │   - 文字写在便签上
│   │ 电不在      │            │   - 便签有撕边/胶带
│   └────────────┘            │
│                             │
│   [底部桌面物件区]            │
│   - 主按钮：保存这张（贴纸感）  │
│   - 次按钮：换一句 / 换一只    │ ← 像桌面上的小卡片
│   - chip：更嘴硬 更摆烂...     │ ← 极轻，可滑动
│                             │
│   [极轻落款：心情值班室]      │
└─────────────────────────────┘
```

**这页让用户继续点的原因**：
- **图是主角**：大便签预览占屏 50%+，让用户先看到"它替我说的图"，再考虑动作。
- **保存动作低压**：主按钮像桌面贴纸，不像 download 按钮。
- **可控但不复杂**：换一句 / 换一只是"再发一张便签"，不是"重置测试"。
- **不被审视**：没有"你是 X 型 / 你属于 Y 类"，只有"今天它替你说"。

## 3. 视觉 token 候选（v0.1 阶段，不锁死）

| token | 候选值 | 用途 |
|---|---|---|
| 桌面底色 | `#F2EAD8` 暖纸米 | 主背景 |
| 便签纸色 | `#FAF1DC` 暖白 / `#F0E2BA` 浅黄 / `#E8D9B0` 卡其 | 3 色随机分布避免单调 |
| 嘴替主句字 | 站酷快乐体 / 仓耳今楷 / 有爱体（待 xhs 抓样比对） | 主句 |
| 辅助字 | OPPO Sans / 思源黑体 | chip / 按钮 / 落款 |
| 主色 | 暖橙 `#E8A04F`（猫围裙色） | 极少量点缀 |
| 阴影 | `0 2px 6px rgba(74,55,30,0.10)` | 便签飘浮感 |
| 胶带色 | 半透明米白 + 微淡纹路 | 便签压角 |
| 角色 PNG 大小 | 便签纸宽度 70-85% | 占比要够，不再"猫偏小" |
